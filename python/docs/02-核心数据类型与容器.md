# 02. 核心数据类型与容器

Python 面试中，`list / tuple / set / dict / str` 是最高频的一组基础知识。

## 1. 总体对比

| 类型 | 有序 | 可变 | 是否允许重复 | 典型访问方式 | 常见用途 |
|---|---|---|---|---|---|
| `list` | ✅ | ✅ | ✅ | 索引 | 动态序列 |
| `tuple` | ✅ | ❌ | ✅ | 索引 | 固定记录、多返回值 |
| `set` | 不应依赖顺序 | ✅ | ❌ | 成员判断 | 去重、集合运算 |
| `dict` | ✅（现代 Python 保留插入顺序） | ✅ | key 不重复 | key | 键值映射 |
| `str` | ✅ | ❌ | ✅ | 索引/切片 | 文本 |

⚠️ “有序”要说清楚。`dict` 在现代 Python 中保留插入顺序；`set` 的遍历顺序不应作为程序逻辑依赖。

# 2. list 列表

```python
nums = [1, 2, 3]
```

### 常见操作

```python
nums.append(4)          # 尾部添加一个元素
nums.extend([5, 6])     # 批量扩展
nums.insert(0, 100)     # 指定位置插入

nums.remove(2)          # 按值删除第一个匹配项
x = nums.pop()          # 默认删除并返回最后一个元素
nums.clear()            # 清空
```

### `append` 和 `extend`

```python
a = [1, 2]
a.append([3, 4])
print(a)  # [1, 2, [3, 4]]

b = [1, 2]
b.extend([3, 4])
print(b)  # [1, 2, 3, 4]
```

| 方法 | 含义 |
|---|---|
| `append(x)` | 把 `x` 整体作为一个元素加入 |
| `extend(iterable)` | 把可迭代对象中的元素逐个加入 |

### 常见复杂度

| 操作 | 平均/典型复杂度 |
|---|---:|
| `lst[i]` | O(1) |
| 尾部 `append` | 均摊 O(1) |
| 尾部 `pop()` | O(1) |
| 中间插入/删除 | O(n) |
| `x in lst` | O(n) |

🧠 列表支持快速随机访问，是因为底层可理解为动态数组；但中间插入删除往往需要移动后续元素。

# 3. tuple 元组

```python
point = (10, 20)
```

元组最重要的特点：**元组本身不可变。**

```python
t = (1, 2, 3)
# t[0] = 100  # TypeError
```

### 单元素元组

```python
a = (1)    # int
b = (1,)   # tuple
```

逗号才是形成单元素元组的关键。

### 为什么用 tuple？

- 表示语义上固定的一组值；
- 可用于多返回值；
- 某些满足条件的 tuple 可哈希，因此可作为 dict key；
- 明确告诉读代码的人：这组结构不应该被直接修改。

### 易错点：tuple 中可以放可变对象

```python
t = ([1, 2], 3)
t[0].append(4)
print(t)  # ([1, 2, 4], 3)
```

这并没有“修改 tuple 保存的第一个引用”，而是修改了那个引用指向的列表对象。

# 4. set 集合

```python
s = {1, 2, 3}
s.add(4)
s.remove(2)
```

集合常见特点：

- 元素唯一；
- 适合成员判断；
- 支持交、并、差等集合运算。

```python
a = {1, 2, 3}
b = {3, 4, 5}

print(a | b)  # 并集
print(a & b)  # 交集
print(a - b)  # 差集
print(a ^ b)  # 对称差集
```

### `remove` vs `discard`

```python
s.remove(100)   # 不存在会抛 KeyError
s.discard(100)  # 不存在也不会报错
```

### 去重

```python
nums = [1, 2, 2, 3]
unique = list(set(nums))
```

⚠️ 这种写法**不保证保留原顺序**。如果需要保序去重，可用：

```python
unique = list(dict.fromkeys(nums))
```

# 5. dict 字典

```python
user = {
    "name": "Tom",
    "age": 22,
}
```

### 常见操作

```python
user["city"] = "Shanghai"
user["age"] = 23

print(user["name"])
print(user.get("score"))         # key 不存在返回 None
print(user.get("score", 0))      # 可提供默认值

user.pop("age")
del user["city"]
```

### `d[key]` vs `d.get(key)`

| 写法 | key 不存在时 |
|---|---|
| `d[key]` | 抛 `KeyError` |
| `d.get(key)` | 返回 `None` 或指定默认值 |

### 遍历

```python
for key in user:
    print(key)

for key, value in user.items():
    print(key, value)
```

### 字典 key 的要求

key 必须是**可哈希对象**。常见可哈希对象包括：

- `int`
- `str`
- `bytes`
- 只包含可哈希元素的 `tuple`
- `frozenset`

列表、集合、普通字典通常不能作为 key。

# 6. str 字符串

字符串不可变。

```python
s = "hello"
# s[0] = "H"  # TypeError
s = "H" + s[1:]
```

### 高频操作

```python
s.strip()
s.split(",")
"-".join(["a", "b", "c"])
s.replace("old", "new")
s.startswith("he")
s.endswith("lo")
```

### 为什么大量字符串拼接推荐 `join`

如果要拼接很多片段：

```python
result = "".join(parts)
```

通常比循环里不断 `result += part` 更合理，因为字符串不可变，反复创建新字符串可能带来额外开销。

# 7. 高频面试题：list 和 tuple 的区别

🎯 **推荐回答**：

1. list 可变，tuple 不可变；
2. 两者都支持有序存储、索引、切片和重复元素；
3. list 更适合需要频繁增删改的动态序列；
4. tuple 更适合表达固定记录；
5. 满足可哈希条件的 tuple 可以作为 dict key，而 list 不可以。

🔍 **追问**：tuple 一定可哈希吗？

不是。例如：

```python
t = ([1, 2], 3)
# hash(t)  # TypeError
```

因为它内部包含不可哈希的 list。

# 8. 高频面试题：dict / set 为什么查找通常很快？

🎯 **回答思路**：

它们通常基于哈希表实现，通过对象的哈希值快速定位候选位置，因此平均成员查找可以接近 O(1)。最坏情况仍可能退化，因此不要把 O(1) 理解成绝对保证。

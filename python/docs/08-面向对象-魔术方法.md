# 08. 面向对象与魔术方法

## 1. 类和对象

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def introduce(self):
        return f"I am {self.name}"

p = Person("Tom", 22)
```

- **类（class）**：描述一类对象应该有哪些属性和行为；
- **对象（instance/object）**：类创建出来的具体实例。

💡 可以把“类”理解成蓝图，“对象”理解成按照蓝图创建的具体实体。

---

## 2. `self` 是什么

`self` 表示当前实例本身。

```python
p.introduce()
```

可以近似理解为：

```python
Person.introduce(p)
```

`self` 不是 Python 语法强制规定的名字，但社区约定都写作 `self`。

---

## 3. 面向对象的几个核心思想

### 封装

把数据和相关操作放到对象内部，通过清晰接口访问。

### 继承

子类复用父类行为，并可增加或覆盖功能。

```python
class Animal:
    def speak(self):
        return "..."

class Dog(Animal):
    def speak(self):
        return "wang"
```

### 多态

不同类型对象提供相同接口，调用方可以用统一方式调用。

```python
def make_sound(animal):
    print(animal.speak())
```

这里真正重要的不是“子类覆盖父类方法”本身，而是**调用方不必关心具体对象类型，只关心它能不能提供所需行为**。

Python 里还经常体现“鸭子类型”：

> 如果一个对象表现得像鸭子，那么调用方往往只关心它是否具备所需方法，而不强制要求继承某个具体类。

### 抽象

隐藏复杂实现，只暴露必要接口。可以使用 `abc` 模块定义抽象基类。

## 4. 实例属性与类属性

```python
class Person:
    species = "human"  # 类属性

    def __init__(self, name):
        self.name = name  # 实例属性
```

```python
p1 = Person("A")
p2 = Person("B")

print(p1.species)
print(p2.species)
```

### 易错点：可变类属性会被实例共享

```python
class Team:
    members = []
```

不同实例访问的可能是同一个列表。

如果每个实例需要独立列表，应放在 `__init__`：

```python
class Team:
    def __init__(self):
        self.members = []
```

## 5. 实例方法、类方法、静态方法

```python
class Demo:
    count = 0

    def instance_method(self):
        return self

    @classmethod
    def class_method(cls):
        return cls

    @staticmethod
    def static_method(x, y):
        return x + y
```

| 类型 | 默认第一个参数 | 主要用途 |
|---|---|---|
| 实例方法 | `self` | 操作实例状态 |
| 类方法 | `cls` | 操作类状态、替代构造器 |
| 静态方法 | 无强制参数 | 和类语义相关但不依赖实例/类状态 |

### 类方法常见用途：替代构造器

```python
class User:
    def __init__(self, name):
        self.name = name

    @classmethod
    def from_string(cls, text):
        return cls(text.strip())
```

## 6. `__new__` 和 `__init__`

这是高频题。

- `__new__`：负责**创建实例**，返回新对象；
- `__init__`：对象创建后负责**初始化实例**。

可以粗略理解：

```text
__new__  -> 创建对象
    ↓
__init__ -> 初始化对象
```

```python
class A:
    def __new__(cls, *args, **kwargs):
        print("new")
        return super().__new__(cls)

    def __init__(self):
        print("init")
```

🎯 **面试回答**：`__new__` 是创建实例的过程，通常返回该类实例；`__init__` 接收已创建好的实例并初始化属性。大多数普通类只需要重写 `__init__`。

## 7. `super()`

```python
class Parent:
    def __init__(self, name):
        self.name = name

class Child(Parent):
    def __init__(self, name, age):
        super().__init__(name)
        self.age = age
```

`super()` 用于按照方法解析顺序（MRO）调用父级实现，不应该简单理解成“永远直接调用父类”。在多继承中 MRO 尤其重要。

查看 MRO：

```python
print(Child.mro())
```

## 8. 私有属性到底私有吗

```python
class User:
    def __init__(self):
        self._age = 20
        self.__password = "123"
```

约定：

- `_name`：表示“内部使用”，是约定，不强制；
- `__name`：触发名称改写（name mangling），降低子类命名冲突风险，但并不是绝对安全的访问控制。

因此不要说“Python 的双下划线属性完全无法从外部访问”。

## 9. `property`

让方法以属性风格访问：

```python
class Person:
    def __init__(self, age):
        self._age = age

    @property
    def age(self):
        return self._age

    @age.setter
    def age(self, value):
        if value < 0:
            raise ValueError("age must be >= 0")
        self._age = value
```

调用：

```python
p.age = 20
print(p.age)
```

适合在保持属性式 API 的同时增加校验或计算逻辑。

## 10. `__slots__`

```python
class Person:
    __slots__ = ("name", "age")

    def __init__(self, name, age):
        self.name = name
        self.age = age
```

常见作用：

- 限制实例允许的属性集合；
- 在特定场景下减少大量实例的内存开销。

⚠️ 不要把它简单说成“有了 `__slots__` 一定没有 `__dict__`”。继承关系等因素会影响结果。面试基础回答只需说明其主要用途，并知道它与实例属性存储有关。

# 11. 常见魔术方法

魔术方法一般形如 `__xxx__`，用于让自定义类接入 Python 的各种语法协议。

| 魔术方法 | 作用 |
|---|---|
| `__init__` | 初始化实例 |
| `__new__` | 创建实例 |
| `__str__` | 面向用户的字符串表示 |
| `__repr__` | 面向开发/调试的表示 |
| `__len__` | `len(obj)` |
| `__iter__` | 获取迭代器 |
| `__next__` | 迭代下一个元素 |
| `__getitem__` | `obj[key]` |
| `__setitem__` | `obj[key] = value` |
| `__call__` | 让实例可调用 |
| `__enter__` / `__exit__` | 上下文管理器 |
| `__eq__` | `==` |
| `__lt__` | `<` |

### `__str__` vs `__repr__`

```python
class User:
    def __init__(self, name):
        self.name = name

    def __str__(self):
        return f"User: {self.name}"

    def __repr__(self):
        return f"User(name={self.name!r})"
```

通常：

- `__str__` 更偏用户可读；
- `__repr__` 更偏调试、开发者可读，最好尽量明确、无歧义。

## 12. 高频面试题

### Q1：面向过程和面向对象的区别？

面向过程关注“步骤怎么执行”，通常把问题拆成函数和流程；面向对象关注“由哪些对象承担职责”，把数据和行为组织在对象内部。二者不是绝对互斥，实际项目往往结合使用。

### Q2：类方法和静态方法有什么区别？

类方法通过 `cls` 获得类对象，适合访问类状态或实现替代构造器；静态方法没有隐式 `self/cls`，更像放在类命名空间中的普通函数。

### Q3：什么是多态？

不同类型对象通过统一接口被调用，各自完成自己的实现。Python 中鸭子类型让多态并不一定要求显式继承关系。

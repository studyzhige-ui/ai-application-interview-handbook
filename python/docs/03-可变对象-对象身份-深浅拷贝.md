# 03. 可变对象、对象身份与深浅拷贝

这一章是 Python 面试里非常高频的一组知识点，因为它把“变量、对象、引用、参数传递、拷贝”串在了一起。

## 1. 可变对象与不可变对象

💡 **新手理解**：

- **可变对象**：对象创建后，内容还可以原地改变；
- **不可变对象**：对象创建后，值本身不能原地修改，如果看起来“改了”，通常其实是变量重新引用了新对象。

常见分类：

| 类型 | 是否可变 |
|---|---|
| `int` | ❌ |
| `float` | ❌ |
| `bool` | ❌ |
| `str` | ❌ |
| `tuple` | ❌（tuple 本身） |
| `list` | ✅ |
| `set` | ✅ |
| `dict` | ✅ |

### 不可变对象示例

```python
x = 10
print(id(x))
x += 1
print(id(x))
```

`x += 1` 并不是把整数对象 `10` 原地改成 `11`，而是让 `x` 改为引用新的整数对象。

### 可变对象示例

```python
lst = [1, 2]
old_id = id(lst)
lst.append(3)
print(id(lst) == old_id)  # 通常 True
```

列表对象本身仍然是同一个，只是内部内容改变了。

## 2. `==` 和 `is`

```python
a = [1, 2]
b = [1, 2]
c = a

print(a == b)  # True
print(a is b)  # False
print(a is c)  # True
```

| 运算符 | 比较什么 |
|---|---|
| `==` | 值是否相等，通常会调用相等比较逻辑 |
| `is` | 是否是同一个对象（identity） |

⚠️ 不要依赖“小整数缓存”“字符串驻留”等实现细节写业务逻辑：

```python
# 不要这样判断数值是否相等
if x is 100:
    ...
```

数值比较应该用 `==`。

## 3. 赋值不是拷贝

```python
a = [1, 2]
b = a
b.append(3)
print(a)  # [1, 2, 3]
```

这里 `a` 和 `b` 指向同一个对象。

可以画成：

```text
a ──┐
    ├──> [1, 2]
b ──┘
```

## 4. 浅拷贝

浅拷贝会创建一个新的**最外层对象**，但内部元素如果是对象引用，仍可能和原对象共享。

```python
import copy

a = [[1, 2], [3, 4]]
b = copy.copy(a)

print(a is b)        # False
print(a[0] is b[0])  # True
```

修改外层：

```python
b.append([5, 6])
print(a)  # 原列表通常不受影响
```

修改共享的嵌套列表：

```python
b[0].append(100)
print(a)  # [[1, 2, 100], [3, 4]]
```

常见浅拷贝方式：

```python
b = a.copy()
b = list(a)
b = a[:]
```

---

## 5. 深拷贝

深拷贝会递归复制需要复制的内部对象，使副本更独立。

```python
import copy

a = [[1, 2], [3, 4]]
b = copy.deepcopy(a)

b[0].append(100)
print(a)  # [[1, 2], [3, 4]]
print(b)  # [[1, 2, 100], [3, 4]]
```

### 对比

| 对比项 | 赋值 | 浅拷贝 | 深拷贝 |
|---|---|---|---|
| 创建新的最外层对象 | ❌ | ✅ | ✅ |
| 嵌套可变对象通常独立 | ❌ | ❌ | ✅ |
| 成本 | 低 | 较低 | 更高 |
| 常见用途 | 共用同一对象 | 复制一层结构 | 需要相互独立的复杂对象 |

⚠️ 深拷贝不应该无脑使用。复杂对象可能很大，复制成本高，而且某些资源对象并不适合被复制。

## 6. 函数参数到底是值传递还是引用传递？

Python 常被概括为**对象引用传递 / call by sharing**。

更直观地说：调用函数时，形参会引用传入的那个对象。

### 可变对象

```python
def add_item(lst):
    lst.append(100)

nums = [1, 2]
add_item(nums)
print(nums)  # [1, 2, 100]
```

函数内部修改了同一个列表对象。

### 重新绑定不会改变外部变量

```python
def reset(lst):
    lst = [999]

nums = [1, 2]
reset(nums)
print(nums)  # [1, 2]
```

这里函数内部只是让局部变量 `lst` 改为引用另一个列表，没有改变外部名字 `nums` 的绑定。

### 不可变对象

```python
def add_one(x):
    x += 1

n = 10
add_one(n)
print(n)  # 10
```

因为整数不可变，`x += 1` 实际上让局部变量 `x` 指向新对象。

🎯 **面试回答**：

> Python 既不适合简单说成纯值传递，也不适合说成传统意义的引用传递。更准确的理解是传递对象引用。形参与实参最初引用同一个对象；如果函数原地修改可变对象，外部能看到变化；如果只是给形参重新赋值，则不会改变调用者变量的绑定。

## 7. 高频陷阱：可变默认参数

```python
def add_item(x, items=[]):
    items.append(x)
    return items

print(add_item(1))  # [1]
print(add_item(2))  # [1, 2]
```

原因：默认参数对象在**函数定义时**创建一次，后续调用会复用同一个默认列表。

正确写法：

```python
def add_item(x, items=None):
    if items is None:
        items = []
    items.append(x)
    return items
```

## 8. 高频面试题

### Q1：浅拷贝和深拷贝有什么区别？

🎯 **简洁回答**：浅拷贝只复制外层结构，嵌套对象仍可能共享引用；深拷贝会递归复制内部对象，使副本更独立。浅拷贝成本较低，深拷贝隔离性更强但成本更高。

### Q2：为什么 `a = b` 不算拷贝？

因为只是新增一个名字引用同一个对象，没有创建新对象。

### Q3：tuple 不可变，为什么里面的 list 还能改？

tuple 不允许替换它保存的元素引用，但如果某个元素引用的是可变对象，可以修改那个内部对象。

## 1. 先能读懂最小程序

### 1.1 从上到下执行，先计算右边，再赋值给左边

把下面代码保存到 `hello.py`，在终端运行 `python hello.py`。这里假设已经安装 Python 3；`python --version` 可以查看版本。

```python
name = "小林"                 # 把名字 name 绑定到字符串对象“ 小林 ”（实际内容没有两侧空格）
count = 2                     # 把名字 count 绑定到整数对象 2
message = name + "，你好！"    # 先把两个字符串连接，再让 message 指向结果
print(message)                # 调用 print，把 message 的内容显示出来：小林，你好！
print(count + 1)              # 先计算 2 + 1，再输出结果 3
```

`"小林"`、`2` 这样的直接写法叫 **Literal（字面量）**。`count + 1` 是 **Expression（表达式）**，计算后得到一个结果。`name = ...` 是赋值语句；`=` 不是数学里的“相等判断”，判断相等使用 `==`。

`#` 后面是注释，供人阅读，不参与执行。引号标识字符串的边界，不属于字符串的内容。`print(...)` 中的括号表示调用函数；括号里的内容是交给函数的参数。

### 1.2 点号、方括号和缩进分别做什么

```python
items = [10, 20]               # 创建列表；方括号里的两项是它的元素
items.append(30)               # 调用列表的 append 方法，把 30 追加到末尾
print(items[0])                # 方括号用于取元素：输出索引 0 处的 10

if len(items) > 0:             # len 返回元素数量；if 判断数量是否大于 0
    print("列表有内容")        # 缩进表示：这一行属于 if 条件成立时执行的代码块
```

**Method（方法）** 可以先理解为“某类对象提供的操作”，`对象.方法(...)` 就是在让这个对象执行操作。`append` 表示追加，`len` 表示取长度。冒号表示后面开始一个代码块，常用四个空格缩进；缩进不是纯排版，而是语法。

⚠️ 错误理解：“看起来差不多的符号可以互换。”正确理解：`=` 负责绑定名字，`==` 负责比较；`items[0]` 取元素，`items.append(30)` 调用方法，它们的职责不同。

## 2. 先定义对象、类型、变量，再解释它们的关系

### 2.1 对象：程序中实际被操作的数据实体

**Object（对象）** 是 Python 表示数据的基本单位。整数 `10` 是对象，字符串 `"hello"` 是对象，列表 `[1, 2]` 也是对象；后面会看到，函数和类本身同样是对象。

可以从三个角度观察一个对象：

| 角度 | 中文含义 | 你在问什么 | 常用观察方式 |
|---|---|---|---|
| Identity | 身份 | 是不是原来的那个对象？ | `is`、`id()` |
| Type | 类型 | 它属于哪类对象，支持什么操作？ | `type()`、`isinstance()` |
| Value | 值／内容 | 它表示什么数据？ | 输出内容；通常用 `==` 比较 |

### 2.2 类型：规定对象可以表示什么、可以怎样操作

**Type（类型）** 不是变量名旁边的标签，而是对象的属性。例如 `int` 表示整数类型，`str` 表示字符串类型，`list` 表示列表类型。

```python
number = 10                   # number 指向 int 对象
text = "10"                   # text 指向 str 对象；看起来是数字，实际是文本
print(number + 2)             # 整数相加，输出 12
print(text + "2")             # 字符串连接，输出 '102'
```

同样的 `+`，由参与运算的类型决定含义。后面说“某对象可变”“某对象可以迭代”，也都是在描述这个类型支持的行为。

### 2.3 变量：当前作用域中绑定到对象的名字

本教材把 **Variable（变量）** 首先解释为名字绑定：`a` 是名字，对象才是被操作的实体。**Reference（引用）** 表示“能够找到某个对象的关联”，不是对象内容的另一份副本。

```python
a = [1, 2]                    # 创建一个列表对象，让 a 引用它
b = a                         # 查到 a 引用的对象，再让 b 也引用它；没有复制列表
b.append(3)                   # 通过 b 找到同一个列表，并原地追加 3
print(a)                      # a 看到的也是这个列表，输出 [1, 2, 3]
```

```text
名字 a ──┐
         ├──引用──> 同一个 list 对象 [1, 2, 3]
名字 b ──┘
```

这不是 `b` 把结果“传回给” `a`，而是两条访问路径从一开始就通向同一个对象。

### 2.4 容器为什么还需要再画一层

列表可以保存多个元素。对 `list`、`tuple` 这类保存对象引用的容器，可以继续画：

```text
变量名 nums
    │ 引用
    ▼
list 对象
    ├─ 元素位置 0 ──保存引用──> int 对象 10
    └─ 元素位置 1 ──保存引用──> int 对象 20
```

这里的 **Slot（槽位）**，先理解为“容器里保存一项元素引用的位置”。于是必须区分三种动作：**改名字的绑定、改容器保存的引用、改被引用对象的内部内容**。第 02 章用它解释 tuple，第 03 章用它解释拷贝。

这是对象关系示意，不是所有类型都具有同样的物理内存布局。CPython 中可以用“指针指向对象”帮助理解引用，但 Python 代码并不需要手工读写地址；字符串的内部存储也不能套成“每个字符一个对象指针”。

## 3. 类型和值相同，是否就是同一个对象

### 3.1 先把三个问题分开问

```python
a = [1, 2]                    # 创建第一个列表
b = [1, 2]                    # 再创建一个内容相同的列表
c = a                         # c 与 a 引用同一个列表
print(type(a) is type(b))      # True：两个对象的类型相同，都是 list
print(a == b)                 # True：两个列表按元素比较，内容相等
print(a is b)                 # False：它们仍然是两个不同的列表对象
print(a is c)                 # True：a 与 c 才是同一个对象的两个名字
```

**类型相同＋值相等，不能推出身份相同。** 就像两张内容完全相同的纸，仍然可以是两张纸。

`==` 使用类型定义的相等规则，不必总是“逐字节比较”。对普通列表，它比较元素；对自定义类型，相等规则可以由 `__eq__` 定义，第 08 章再展开。

### 3.2 `id()` 与内存地址的准确关系

`id(obj)` 返回代表对象身份的整数。**在两个对象都仍然存活的前提下**，身份编号相同说明它们是同一个对象；同一对象存活期间，编号保持不变。

```python
a = []                        # a 保持对列表的引用，因此列表仍然存活
b = a                         # b 引用同一个对象
print(id(a) == id(b))          # True：同一个对象具有相同的身份编号
print(a is b)                 # True：直接判断身份，通常比比较 id 更表达意图
```

在 **CPython（Python 的一种实现）** 中，`id()` 对应对象的内存地址。所以“同一进程、同一时刻、两个存活对象的地址完全相同”可以判断为同一个对象。但是旧对象销毁后，其地址／身份编号可能被新对象复用；不同进程里的相同地址数值也没有这种可比性。不要把两次历史输出中的相同数字，当作跨时间的唯一身份证。

⚠️ 业务里比较数字或文本的值，用 `==`；不要依赖小整数缓存、字符串驻留等对象复用优化来使用 `is`。

## 4. 动态类型与强类型，回答的是不同问题

### 4.1 动态类型：名字是否必须预先固定一种类型

```python
x = 10                        # 此时 x 绑定 int 对象
x = "hello"                   # 重新绑定：x 现在引用 str 对象
x = [1, 2]                    # 再次重新绑定：x 现在引用 list 对象
```

这不是原来的整数对象“变成字符串又变成列表”，而是名字 `x` 的绑定改变了。Python 在运行时根据参与操作的对象确定类型相关行为，不要求先把 `x` 声明成只能保存整数的变量。

### 4.2 强类型：不兼容类型之间是否随意转换

```python
# "1" + 1                     # 错误示例：str 与 int 不能直接这样相加，会抛 TypeError
print(int("1") + 1)           # 明确把文本转成整数再求和，输出 2
print("1" + str(1))           # 明确把整数转成文本再连接，输出 '11'
print(1 + 1.5)                # 合法的数值混合运算，输出 2.5
```

**TypeError（类型错误）** 表示当前操作不接受这样的类型组合。强类型不是“绝不发生任何隐式转换”；例如整数和浮点数可以按数值规则一起运算。它也不是一个与“动态／静态”完全同维度的严格分类标准，面试时给出具体行为比只背标签准确。

🎯 面试回答：

> Python 是动态类型、通常被描述为强类型的语言。类型属于对象，名字可以重新绑定到不同类型对象；但不兼容类型不会随意混用，例如字符串与整数不能直接相加，需要明确转换。

## 5. `type()` 和 `isinstance()`：精确类型还是类型家族

```python
print(type(1))                # <class 'int'>：返回对象 1 的具体类型
print(type(True))             # <class 'bool'>：True 的具体类型是 bool
print(type(True) is int)      # False：bool 不是恰好那个 int 类型
print(isinstance(True, int))  # True：bool 是 int 的子类，属于 int 的类型体系
```

`isinstance(x, T)` 的问题是“`x` 是 `T` 或其子类的实例吗”；`type(x) is T` 的问题是“`x` 的具体类型恰好就是 `T` 吗”。**Subclass（子类）** 是从另一类继承行为的类型，完整机制在第 08 章；此处先记住“家族成员”和“恰好同类”的区别。

多数面向可扩展对象的代码适合 `isinstance`；当规则确实要求“必须是整数且不能把布尔值算进去”时，就需要考虑这个区别，而不是机械选一个写法。

## 6. 条件判断：不是除了 None 以外一律写 `not`

### 6.1 Truthy / Falsy 是“在条件中被视为真／假”

常见假值包括 `False`、`None`、数值零，以及空字符串、空列表、空元组、空字典、空集合。对象不必本身就是布尔值，也可以参与条件判断。

```python
items = []                    # 空列表
print(bool(items))            # False：把它的真值判断结果显式显示出来
if not items:                 # not 对真值取反；空列表在这里使条件成立
    print("没有元素")         # 输出：没有元素
```

对于已知是列表的 `items`，`if not items` 很自然地表示“列表为空”。但它并不在所有场景都等价于“值不存在”。

### 6.2 根据你真正要区分的状态选择表达式

| 真实意图 | 常见表达式 | 不能混淆的边界 |
|---|---|---|
| 值恰好是缺失标记 None | `value is None` | `0`、`False`、`""` 不一定是缺失 |
| 值不是 None | `value is not None` | 保留合法的零值与空值 |
| 已知容器为空 | `not items` | 前提是类型和业务语义已明确 |
| 数字等于零 | `count == 0` | 直接表达数值比较 |
| 对象恰好是布尔值 False | `flag is False` | 比一般“假值”更严格 |
| 所有假值都走这个分支 | `not value` | 会同时包含 None、零、空容器等 |

```python
limit = 0                     # 这里约定 0 是一个合法配置值
if limit is None:             # 只在未提供配置时使用默认值
    limit = 10
print(limit)                  # 0：没有把合法的零误替换成 10
```

`None` 是表示“没有值”的单例对象，所以用 `is None` 表达身份判断。不要把 `None`、空字符串、空列表、数值零解释为同一种业务状态。

### 6.3 `and`、`or` 会短路，也不一定返回 bool

```python
name = ""                     # 当前名称为空字符串
shown = name or "匿名"         # name 为假值，才求右边；shown 得到字符串“匿名”
print(shown)                  # 匿名
print(0 and 1 / 0)            # 0：左边已是假值，不再计算右边，所以没有除零错误
```

**Short-circuit（短路）** 是“结果已经能确定时，不再计算后续部分”。`and`、`or` 返回选中的操作数；`not` 返回布尔值。因此 `value or default` 也会覆盖合法的 `0`、`False` 和空值，只有业务确实需要这样时才用。

## 7. 索引：取某一个位置上的元素

**Sequence（序列）** 是按位置组织数据的对象，例如列表、元组、字符串。**Index（索引）** 是位置编号，从 `0` 开始，不是元素本身。

```text
元素：  10   20   30   40   50
正索引： 0    1    2    3    4
负索引：-5   -4   -3   -2   -1
```

```python
nums = [10, 20, 30, 40, 50]    # 五个元素的列表
print(nums[0])                # 10：第一个元素
print(nums[-1])               # 50：倒数第一个元素
print(nums[2])                # 30：索引为 2，即第三个元素
# print(nums[5])              # 错误：索引越界，抛 IndexError；最后一个正索引是 4
```

索引取的是一个元素；这个元素自己也可能是列表等复杂对象。字典的 `d[key]` 虽然同样用方括号，却是按键查找，不是按第几个位置取值，第 02 章会区分。

## 8. 切片：按范围和步长取出一个子序列

格式是 `sequence[start:stop:step]`：从 `start` 开始，**不包含 `stop`**，每次移动 `step` 个位置。

```python
nums = [10, 20, 30, 40, 50]    # 索引依次为 0 到 4
print(nums[1:4])              # [20, 30, 40]：选索引 1、2、3，不包括 4
print(nums[::2])              # [10, 30, 50]：正向每隔两步取一次
print(nums[::-1])             # [50, 40, 30, 20, 10]：反向步长为 -1
print(nums[:2])               # [10, 20]：正向从开头取到索引 2 之前
print(nums[3:])               # [40, 50]：正向从索引 3 取到末尾
print(nums[100:200])          # []：这种越界切片会截取到有效范围，不像单个索引那样报错
```

省略边界时，默认起止位置由步长方向决定；负步长不是简单把正向默认的 `0` 和长度照搬过来。步长不能为零。第 02 章再解释为什么 list 切片会复制外层引用、为什么 `[::-1]` 需要考虑空间。

## 9. 解包：把一组元素分别绑定到多个名字

**Unpacking（解包）** 不是把一个对象“拆坏”，而是从可迭代对象逐个取值，再给相应名字赋值。

```python
a, b = 1, 2                           # a 绑定 1，b 绑定 2；右边是两个值组成的元组
first, *middle, last = [1, 2, 3, 4]    # first=1，middle=[2, 3]，last=4
print(first, middle, last)             # 1 [2, 3] 4
x, y = [10, 20]                        # 两个名字接收两个元素
x, y = y, x                           # 先取得旧的 y、x，再绑定，交换后 x=20、y=10
```

不带星号时，左右数量要匹配；`x, y = [1, 2, 3]` 会因为值太多而抛 `ValueError（值错误）`。正确选择是增加一个接收名字，或者用 `x, *rest = [1, 2, 3]` 收集其余元素。带星号的接收目标得到列表；同一层解包只能有一个这样的星号目标。

## 10. 读后续代码还需要的控制流程

### 10.1 `if / elif / else` 选择一个分支

```python
score = 75                    # 要判断的分数
if score >= 90:               # 先判断是否至少 90 分
    print("优秀")             # 满足时执行这一分支
elif score >= 60:             # 上一个条件不满足，才继续判断是否及格
    print("及格")             # 本例输出：及格
else:                         # 前面的条件都不成立时执行
    print("继续练习")         # 不是本例选中的分支
```

### 10.2 `for` 逐项处理，`while` 按条件重复

```python
for number in [1, 2, 3]:       # 每次把一个元素绑定到 number，然后执行循环体
    print(number * 2)          # 依次输出 2、4、6

remaining = 3                 # 还剩三次
while remaining > 0:          # 每轮开始前检查条件
    print(remaining)           # 依次输出 3、2、1
    remaining -= 1            # 等价于本例的 remaining = remaining - 1
```

`break` 提前退出最近一层循环；`continue` 跳过本轮剩余代码，进入下一轮。`range(3)` 表示可依次取得 `0、1、2` 的整数范围，不是已经装满这三个数的列表。`%` 取余数，例如 `4 % 2 == 0` 用来判断偶数。

### 10.3 先认识“定义函数”与“导入工具”

```python
import math                   # 导入标准库模块 math，后续通过 math.名字 使用其中的工具
print(math.sqrt(9))           # 调用平方根函数，输出 3.0

def add(a, b):                # 定义函数；a、b 是这段代码接收输入时使用的局部名字
    return a + b              # return 把结果交还调用处，并结束本次函数调用

result = add(2, 3)            # 调用函数，把返回结果绑定到 result
print(result)                 # 5
```

现在只要能读懂 `def`、参数、`return`、`import`，就能理解第 03 章的共享引用实验；第 04 章系统讲函数调用，第 09 章系统讲模块加载。遇到异常时，程序会沿调用关系寻找处理者；没有处理者，本次执行会终止并显示错误。完整异常处理也放在第 09 章。

## 11. 学完语言基础，再看为什么工程中选择 Python

### 11.1 生态、集成与迭代效率

AI Application（AI 应用）往往需要连接模型、数据处理工具、检索系统和外部 API。Python 的 AI／ML（机器学习）／Data（数据）工具、SDK（开发工具包）、Notebook（交互式笔记本）与模型推理工具便于组合，也适合快速实验和作为不同系统之间的“胶水层”。

很多请求的主要过程是等待 HTTP（网络请求）、DB（数据库）、Redis、Vector DB（向量数据库）、LLM Provider（模型服务方）或 Tool API（工具接口）返回。这类 **I/O-bound（输入输出等待密集）** 工作，与一直进行计算的 **CPU-bound（处理器计算密集）** 工作不是同一种瓶颈；线程与 `asyncio` 如何利用等待时间，在第 11、12 章解释。

### 11.2 不是所有服务都必须用同一种语言

| 语言 | 常见考虑因素，而不是绝对排名 |
|---|---|
| Python | 模型／数据生态、实验效率、AI 编排和 I/O 服务集成 |
| Java | 静态类型、大型工程工具、JVM（Java 虚拟机）生态、企业服务与已有组织资产 |
| Go | 编译与部署方式、goroutine／channel（并发任务与通信机制）、网关和网络基础设施 |

Java 与 Python 都通常被描述为强类型语言；真正要比较的还包括静态／动态检查方式，不要把“强类型”误当 Java 独有优势。部署复杂度、运行时开销和性能也要针对实际工作负载测量。

一个系统可以让 Python 负责 RAG／Agent／模型交互，Go 负责 Gateway（网关），Java 保留既有交易与业务服务，再通过 HTTP、RPC（远程过程调用）、MQ（消息队列）协作。这里的系统名先作为使用场景，不要求第一章就理解后续九个模块。

### 11.3 优势背后的 Trade-off（取舍）

动态类型使迭代灵活，但大型项目更需要 Type Hint（类型提示）、Static Checker（静态检查器）、Schema Validation（数据结构校验）和测试。纯 Python CPU-heavy（计算量大的）部分可能需要 native library（本地编译库）、process pool（进程池）或拆成独立服务。传统带 GIL 的 CPython 对纯 Python 多线程 CPU 并行还有限制；不能把“能写 async”当作性能万能解。

最终判断链是：**业务瓶颈 → 团队现有技术栈 → 是否依赖 Python 特有工具 → 吞吐／延迟／内存要求 → 部署与运维成本**。语言选择是约束下的决策，不是优劣口号。

本章依据：[Python 数据模型](https://docs.python.org/3.14/reference/datamodel.html)、[内置类型与真值判断](https://docs.python.org/3.14/library/stdtypes.html)、[控制流与函数入门](https://docs.python.org/3.14/tutorial/controlflow.html)。内存地址的说明限定于 CPython；示例主体适用于 Python 3.11+。

## 13. ⚠️ 易错点

- Python 动态类型 ≠ 没有类型；
  正确理解：对象有类型，名字可以重新绑定到不同类型的对象。
- `is` ≠ 一般值比较；
  正确写法：比较数值、文本内容通常用 `==`；判断是否是那个 `None` 对象用 `is None`。
- `id()` 的实现细节不要上升成语言规范；
  正确理解：语言保证存活对象的身份编号；CPython 用地址实现它，销毁后编号可能被复用。
- “Python 适合 AI”不能只回答“语法简单”；
  正确回答：补充生态、数据工具、SDK、实验效率与 I/O 集成，并说明适用边界。
- Python / Java / Go 不是非此即彼，真实系统可以多语言协作；
  正确理解：可以按服务职责选择语言，再通过清晰接口协作。
- 语言选择要由 workload、生态和团队约束决定。
  正确理解：workload 是实际工作负载；先区分等待与计算，再讨论性能和交付成本。

## 14. 本章自测

<details>
<summary>1. `a = b` 是否复制了对象？</summary>

通常没有，它只是让两个名字绑定到同一个对象。是否产生新对象要看具体表达式和操作。

</details>

<details>
<summary>2. 为什么 Python 在 AI Application 中常见，但不能推出所有 AI 后端都应该用 Python？</summary>

Python 的 AI 生态和迭代效率很强，但语言选型仍受吞吐、延迟、团队栈、已有基础设施、部署方式和 CPU-heavy 比例影响；不同服务完全可以采用不同语言。

</details>

<details>
<summary>3. Python 为什么既是动态类型又是强类型？</summary>

动态类型表示名字不需要预先声明固定类型；强类型表示不兼容对象不会被任意隐式转换，例如字符串与整数不能直接相加。

</details>

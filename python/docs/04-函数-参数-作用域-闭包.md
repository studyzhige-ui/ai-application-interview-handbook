# 04. 函数、参数、作用域与闭包

函数相关知识是 Python 面试的核心区域，很多问题会从参数继续追问到作用域、闭包和装饰器。

## 1. 函数基础

```python
def add(a, b):
    return a + b
```

函数也是对象，因此可以被赋值、作为参数传递、作为返回值返回。

```python
def greet(name):
    return f"Hello, {name}"

f = greet
print(f("Tom"))
```

这也是装饰器、高阶函数能够存在的基础。

---

## 2. 参数类型

```python
def demo(a, b=10, *args, c=20, **kwargs):
    ...
```

常见参数：

| 类型 | 示例 | 说明 |
|---|---|---|
| 普通位置/关键字参数 | `a` | 可按位置或关键字传 |
| 默认参数 | `b=10` | 未传时使用默认值 |
| 可变位置参数 | `*args` | 收集为 tuple |
| 仅关键字参数 | `c=20` | 必须使用关键字传递 |
| 可变关键字参数 | `**kwargs` | 收集为 dict |

### `*args`

```python
def total(*args):
    print(args)

total(1, 2, 3)
# (1, 2, 3)
```

### `**kwargs`

```python
def show(**kwargs):
    print(kwargs)

show(name="Tom", age=22)
# {'name': 'Tom', 'age': 22}
```

🎯 **面试回答**：`*args` 接收任意数量的位置参数并打包成元组，`**kwargs` 接收任意数量的关键字参数并打包成字典。

---

## 3. 调用时的 `*` 和 `**`

它们不只用于定义函数，也可用于调用时解包。

```python
def add(a, b):
    return a + b

nums = [10, 20]
print(add(*nums))

params = {"a": 10, "b": 20}
print(add(**params))
```

💡 定义时：**收集参数**；调用时：**展开参数**。

---

## 4. 位置参数和关键字参数

```python
def user(name, age):
    print(name, age)

user("Tom", 22)
user(age=22, name="Tom")
```

关键字参数的好处是语义明确，也可不依赖参数顺序。

---

## 5. 仅位置参数与仅关键字参数

现代 Python 支持 `/` 和 `*` 来限制调用方式：

```python
def func(a, /, b, *, c):
    pass
```

- `/` 前的 `a`：只能按位置传；
- `b`：位置或关键字均可；
- `*` 后的 `c`：只能按关键字传。

这类问题不一定高频，但知道语义即可。

---

## 6. return

函数遇到 `return` 后结束执行。

```python
def f():
    return 1, 2

x = f()
print(x)  # (1, 2)
```

“返回多个值”本质上通常是返回一个 tuple，然后利用解包：

```python
a, b = f()
```

没有显式 `return` 时，函数默认返回 `None`。

---

## 7. LEGB 作用域规则

Python 查找变量通常按 LEGB 顺序：

```text
L - Local：当前函数局部作用域
E - Enclosing：外层函数作用域
G - Global：模块全局作用域
B - Built-in：内置作用域
```

示例：

```python
x = "global"

def outer():
    x = "enclosing"

    def inner():
        x = "local"
        print(x)

    inner()

outer()  # local
```

---

## 8. `global`

如果需要在函数内部重新绑定全局变量：

```python
count = 0

def inc():
    global count
    count += 1
```

⚠️ 不要滥用 `global`。大量共享可变全局状态会让程序更难维护和测试。

---

## 9. `nonlocal`

用于修改外层函数作用域中的变量：

```python
def outer():
    count = 0

    def inner():
        nonlocal count
        count += 1
        return count

    return inner
```

`nonlocal` 不会去找全局变量，它针对的是**最近的外层函数作用域**。

## 10. 闭包 Closure

💡 **新手理解**：一个内部函数在外部函数已经执行结束后，仍然能够“记住并使用”外部函数中的变量，这种结构就是闭包的重要表现。

```python
def make_multiplier(n):
    def multiply(x):
        return x * n
    return multiply


double = make_multiplier(2)
print(double(10))  # 20
```

虽然 `make_multiplier(2)` 已经结束，返回的 `multiply` 仍然保存了对 `n` 的访问能力。

### 闭包常见用途

- 保存状态；
- 函数工厂；
- 装饰器；
- 延迟执行时携带上下文。

## 11. 闭包中的“晚绑定”陷阱

```python
funcs = []
for i in range(3):
    funcs.append(lambda: i)

print([f() for f in funcs])
# 常见结果：[2, 2, 2]
```

原因：lambda 执行时才去查找 `i`，循环结束后 `i` 已经是 2。

一种常见解决方法：用默认参数在定义时捕获当前值。

```python
funcs = []
for i in range(3):
    funcs.append(lambda i=i: i)

print([f() for f in funcs])
# [0, 1, 2]
```

## 12. 默认参数何时求值？

默认参数表达式在**函数定义时**求值，而不是每次调用时重新求值。

这解释了可变默认参数陷阱：

```python
def add(x, lst=[]):
    lst.append(x)
    return lst
```

正确写法通常是：

```python
def add(x, lst=None):
    if lst is None:
        lst = []
    lst.append(x)
    return lst
```

## 13. 高频面试题

### Q1：`*args` 和 `**kwargs` 的区别？

`*args` 收集额外位置参数为 tuple；`**kwargs` 收集额外关键字参数为 dict。

### Q2：`global` 和 `nonlocal` 的区别？

- `global` 指向模块级全局变量；
- `nonlocal` 指向外层函数作用域中的变量。

### Q3：什么是闭包？

🎯 **回答框架**：闭包通常指一个内部函数捕获并保存了其外层作用域中的变量，即使外部函数已经返回，内部函数仍能访问这些变量。闭包常用于状态保存、函数工厂和装饰器。

### Q4：为什么默认参数不能随便写 `[]` 或 `{}`？

因为默认参数在函数定义时只创建一次，可变对象会被后续调用共享。

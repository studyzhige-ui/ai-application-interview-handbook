# 12. 常见数据结构与复杂度

Python 面试里经常把语言基础和数据结构一起问。你不需要一开始就学得特别深，但常见结构、适用场景和基本复杂度要能说清楚。

## 1. 为什么要看复杂度

复杂度不是精确运行时间，而是描述输入规模增大时，算法资源消耗如何增长。

常见时间复杂度：

| 复杂度 | 直观理解 | 例子 |
|---|---|---|
| O(1) | 基本不随 n 增长 | 数组按索引访问 |
| O(log n) | 增长很慢 | 二分查找 |
| O(n) | 与 n 线性增长 | 遍历列表 |
| O(n log n) | 常见高效排序级别 | 比较排序 |
| O(n²) | 双重遍历常见 | 朴素两两比较 |

⚠️ 面试说“某操作是 O(1)”时，通常指平均、均摊或典型情况，要结合具体结构和实现。

---

## 2. 数组 / 动态数组

Python 的 `list` 可以从面试角度理解为动态数组，而不是链表。

特点：

- 内部元素引用连续组织；
- 按索引访问快；
- 尾部追加通常高效；
- 中间插入删除需要搬移后续元素。

| 操作 | list 典型复杂度 |
|---|---:|
| `lst[i]` | O(1) |
| `append()` | 均摊 O(1) |
| `pop()` 尾部 | O(1) |
| `insert(0, x)` | O(n) |
| `x in lst` | O(n) |

### 为什么 append 是“均摊 O(1)”？

动态数组容量不够时，偶尔需要扩容和搬移元素，这一次操作可能较贵；但扩容不会每次发生，把多次 append 平均起来，通常视为均摊 O(1)。

---

## 3. 链表 Linked List

链表节点通过指针/引用连接，内存通常不连续。

```text
[value | next] -> [value | next] -> [value | next]
```

### 数组 vs 链表

| 对比 | 数组 | 链表 |
|---|---|---|
| 内存布局 | 连续/紧凑 | 节点分散 |
| 随机访问 | O(1) | O(n) |
| 已知节点位置的插入删除 | 可能搬移 | 改引用即可 |
| 缓存友好性 | 通常较好 | 通常较差 |

⚠️ “链表删除一定 O(1)”不够准确。只有已经拿到待删除节点及必要前驱信息时，修改链接本身才可 O(1)；如果先要查找节点，整体仍可能 O(n)。

---

## 4. 栈 Stack

后进先出：LIFO。

Python 中可以直接用 list：

```python
stack = []
stack.append(1)
stack.append(2)
print(stack.pop())  # 2
```

典型用途：

- 函数调用栈；
- 括号匹配；
- DFS；
- 表达式解析；
- 撤销操作。

---

## 5. 队列 Queue

先进先出：FIFO。

不要频繁用：

```python
lst.pop(0)
```

因为删除头部通常 O(n)。

更推荐：

```python
from collections import deque

q = deque()
q.append(1)
q.append(2)
print(q.popleft())  # 1
```

`deque` 适合两端插入删除。

---

## 6. 哈希表 Hash Table

Python 的 `dict` 和 `set` 都与哈希表密切相关。

核心思想：

```text
key
 ↓
hash(key)
 ↓
定位候选槽位
 ↓
比较并找到目标
```

因此平均查找、插入、删除通常接近 O(1)。

### 为什么 key 必须可哈希？

哈希表需要一个在对象参与字典存储期间保持合理稳定的哈希值和相等关系。

列表可原地修改，因此通常不可哈希；字符串、整数等不可变对象常可哈希。

---

## 7. 树 Tree

树是层次结构。

常见二叉树节点：

```python
class TreeNode:
    def __init__(self, value):
        self.value = value
        self.left = None
        self.right = None
```

常考遍历：

- 前序：根 → 左 → 右
- 中序：左 → 根 → 右
- 后序：左 → 右 → 根
- 层序：BFS

### 二叉搜索树 BST

典型性质：左侧值较小、右侧值较大（具体重复值策略取决于实现）。

平衡较好时查找可接近 O(log n)，极端退化成链表时可能 O(n)。

---

## 8. 堆 Heap

堆是一种满足特定堆序性质的完全二叉树结构，常用于优先队列。

Python 标准库：

```python
import heapq
```

`heapq` 默认实现最小堆。

```python
heap = []
heapq.heappush(heap, 3)
heapq.heappush(heap, 1)
heapq.heappush(heap, 2)
print(heapq.heappop(heap))  # 1
```

典型复杂度：

| 操作 | 复杂度 |
|---|---:|
| 看最小值 `heap[0]` | O(1) |
| push | O(log n) |
| pop 最小值 | O(log n) |

## 9. Top K 高频题

### 一亿个数找最大的 100 个

不必把所有数据完整排序。

可以维护大小为 100 的最小堆：

```python
import heapq


def top_k(data, k):
    heap = []

    for x in data:
        if len(heap) < k:
            heapq.heappush(heap, x)
        elif x > heap[0]:
            heapq.heapreplace(heap, x)

    return sorted(heap, reverse=True)
```

思路：

1. 堆里只保留当前最大的 k 个数；
2. 堆顶是这 k 个数中最小的；
3. 新数只有比堆顶大才有资格进入；
4. 空间只需要 O(k)。

整体时间大致 O(n log k)，当 k 远小于 n 时比全量排序更合适。

## 10. BFS 和 DFS

### DFS：栈/递归

```python
def dfs(node):
    if node is None:
        return
    visit(node)
    dfs(node.left)
    dfs(node.right)
```

### BFS：队列

```python
from collections import deque

q = deque([root])
while q:
    node = q.popleft()
    visit(node)
```

记忆：

- DFS 往深处走 → 栈；
- BFS 一层层走 → 队列。

## 11. 高频面试题

### Q1：数组和链表的区别？

🎯 数组随机访问快但中间插删常需搬移；链表随机访问慢，但如果已经定位到节点，改变链接即可完成插删。数组通常还有更好的缓存局部性。

### Q2：栈和队列的区别？

栈是 LIFO，后进先出；队列是 FIFO，先进先出。

### Q3：栈和堆有什么区别？

这个问题有歧义。

- 如果说“数据结构”：stack 是 LIFO，heap 是优先队列常用结构；
- 如果说“内存中的栈和堆”：这是程序运行时内存管理概念，和上述数据结构不是一回事。

面试时最好先确认面试官问的是哪一种。

### Q4：为什么 Top K 常用堆？

因为只需维护 k 个候选元素，每次更新 O(log k)，空间 O(k)，不需要对全部 n 个元素排序。

# Python 面试前速查表

> 适合面试前 20~30 分钟快速扫一遍。这里故意只保留结论，详细解释请回到 `docs/`。

## 1. 核心类型

| 类型 | 有序 | 可变 | 重复 | 典型用途 |
|---|---|---|---|---|
| list | ✅ | ✅ | ✅ | 动态序列 |
| tuple | ✅ | ❌ | ✅ | 固定记录 |
| set | 不依赖顺序 | ✅ | ❌ | 去重、集合运算 |
| dict | ✅ | ✅ | key 不重复 | 键值映射 |
| str | ✅ | ❌ | ✅ | 文本 |

- list 索引：O(1)
- list 中间插删：O(n)
- dict/set 查找：平均接近 O(1)
- `deque.popleft()`：适合队列

## 6. 默认参数陷阱

错误：

```python
def f(items=[]):
    ...
```

推荐：

```python
def f(items=None):
    if items is None:
        items = []
```

默认参数：**定义时求值一次。**

## 13. 装饰器

```python
@decorator
def f():
    pass
```

等价：

```python
f = decorator(f)
```

通用 wrapper：

```python
from functools import wraps


def deco(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        return func(*args, **kwargs)
    return wrapper
```

多个装饰器：

```python
@A
@B
def f(): ...
```

等价：

```python
f = A(B(f))
```

## 22. GIL

传统 CPython/GIL 模式：

```text
同一解释器进程中
同一时刻通常只有一个线程执行 Python 字节码
```

影响：

- I/O 密集：线程仍然有价值
- 纯 Python CPU 密集：多线程并行受限
- CPU 密集：常考虑多进程/释放 GIL 的底层库

注意：GIL 是 **CPython 实现相关**，现代 CPython 也存在 free-threaded 构建方向。

## 23. 线程 / 进程 / 协程

| 场景 | 常见选择 |
|---|---|
| I/O 密集 | Thread / asyncio |
| CPU 密集 | Process |
| 大量异步网络 I/O | asyncio |

### 线程

- 共享进程内存
- 通信方便
- 注意锁、竞态、死锁

### 进程

- 地址空间隔离
- 开销较高
- 可利用多核执行纯 Python CPU 任务

### 协程

- 用户态调度
- 事件循环
- 等待 I/O 时主动让出

## 24. `async` / `await`

```python
async def f():
    await something()
```

- `async def`：协程函数
- `await`：等待 awaitable，同时允许当前协程挂起

错误：

```python
async def f():
    time.sleep(5)
```

推荐：

```python
await asyncio.sleep(5)
```

# 图解复习与章节自测

这一目录与 `docs/` 的 12 个正文章节一一配套，但不是简单重复正文。

它的用途是：**看完一章正文 → 用图解把知识串起来 → 不看答案先口述/手写 → 点击“查看参考答案”核对。**

所有参考答案默认折叠，使用 GitHub 原生 `<details>` 组件，避免一眼看到答案。

## 使用方法

1. 先读对应的 `docs/` 正文；
2. 看本页 Mermaid 图，尝试自己解释每条箭头；
3. 做题时先停下来回答；
4. 再点击“查看参考答案”；
5. 如果答案能看懂但不能自己说出来，仍然算“未掌握”。

## 1. 这个模块解决什么

为 AI Application / Agent Engineer（AI 应用／Agent 开发工程师）建立 Python 语言、对象模型、结构化数据与 Runtime（运行时）基础。

先不要求你记住大量概念名，而是逐步具备四种解释能力：

```text
数据层：名字指向什么？容器怎样保存内容？修改影响到谁？
执行层：函数什么时候执行？名字在哪里查找？结果何时产生？
协作层：对象怎样提供行为？输入怎样验证？失败和资源怎样管理？
运行层：对象何时可释放？任务怎样并发？操作成本如何随规模增长？
```

每个知识点再沿同一条因果链展开：**为什么需要 → 准确定义 → 最小例子 → 执行／存储过程 → 适用边界 → 正确用法 → 面试表达**。不是先给结论，让读者再去别处补齐定义。

## 3. 固定课程原则

> **Writer like a reader：写作时站在第一次看到这些概念的读者一边。** 先问“读者到这里已经知道什么”，再决定下一段可以引入什么。

### 定义在关系之前，关系在结论之前

先分别定义变量、对象、类型、引用，再讲它们如何关联；先区分容器语义、底层结构和操作成本，再讨论为什么某种操作快或慢。Python 语言规则、CPython 实现细节与业务设计必须分开表述。

### 知识点不能因为重组而消失

允许合并重复说明、重新分组或把实现移动到前置知识已经齐备的章节；原有知识点、机制、适用边界和面试主题都要有明确去向。真人面经只调整复习权重、问法和追问深度，不反过来打乱初学者的主线。

### 代码用于解释，不制造新的阅读障碍

首次出现的重要英文术语带中文含义；代码说明变量代表什么、语句做什么、结果意味着什么。需要前文定义的片段说明依赖；完整示例补入口、输入与结果。错误示例紧跟正确写法，不能只强调“不能这样写”。

### 章末保持熟悉的使用方式

保留 **🎯 面试回答、⚠️ 易错点、本章自测** 的角色、图标与折叠交互。正文负责讲明白，面试回答负责压缩表达，易错点负责纠偏，自测负责主动回忆；不把它们统一改成术语清单。自测继续使用 `<details><summary>`，默认不展开答案。

研究条目与章节也保持不同层次：**Canonical Question（独立面试能力）** 不等于 **Capability Primitive（更细的机制）**，也不等于一个教材文件。15 道 Canonical 可以组织成 13 个完整学习章节，章节内部再用二级、三级标题建立层次。

## 4. 正式学习主线

```text
第一阶段｜数据与对象（01—03）
读懂代码 → 名字／对象／类型 → 容器与引用 → 共享／修改／拷贝
                         ↓
第二阶段｜执行与组织（04—07）
函数调用 → 参数与作用域 → 数据处理 → 迭代与暂停 → 包装行为与资源范围
                         ↓
第三阶段｜对象协作与输入边界（08—10）
自定义类 → 行为协议 → 异常传播 → 文件／模块 → 结构与业务校验
                         ↓
第四阶段｜运行机制与成本（11—13）
引用生命周期 → GC／GIL → 线程／进程／协程 → 任务收尾 → 数据结构选型
```

几个刻意安排的衔接：第 01 章先给出 `def`、`return`、`import` 的最小读法，让第 03 章的传参实验可以理解；第 04 章再系统讲调用与作用域。第 06、07 章先学如何使用迭代与资源协议，手写 `Counter`、`MyContext` 的完整类实现移到第 08 章，在学过 `class` 和 `self` 后再展开。第 06、07 章必要的异常语法就地解释，第 09 章再统一建立完整错误模型。

这不是要求初学者跳读，而是“先给当前所需的最小概念，再在主责章完整展开”。

## 9. 推荐学习方式

**第一遍只走正文主线。** 按 01 → 13 阅读。看到代码，先说出“输入是什么、这行改变了哪一层、输出应该是什么”，再运行验证。遇到概念断层，记录到具体小节，不要求靠额外搜索把每段代码拼懂。

**第二遍重建关系。** 打开 [Review](review/README.md)，先不看答案，用自己的话解释引用链、调用链、取值进度和任务生命周期。只觉得答案熟悉，还不等于能独立解释。

**第三遍训练面试。** 用章末 🎯 回答建立简洁表达，再用自测和集中题库追问“为什么、前提是什么、什么时候不成立”。项目复盘再映射自己的真实工作，不虚构经历。

整体学习节奏可参考 [Learning Path](../roadmap/learning-path.md)，不绑定固定天数。普通代码示例以 Python 3.11+ 为基础；当前参考文档主要为 Python／CPython 3.14，Pydantic 示例明确使用 v2。实现与构建差异在对应章节就地说明。

# Quality Audits｜质量审计

[↑ Guide](../README.md) · [↑ Handbook](../../README.md)

本目录保存对 Curriculum 与仓库整体质量的系统审计。当前状态与历史快照分开维护：

- [Final Quality Audit](final-quality-audit.md)：文档范围、证据层次与验证入口；
- [Curriculum Granularity Audit](curriculum-granularity-audit.md)：教材粒度与认知闭环；
- [Content Depth Audit](content-depth-audit.md)：正文深度标准与模块专项证据；
- [Foundation Status Audit](foundation-status-audit.md)：语言、接口、数据库、缓存与后端可靠性的前置关系；
- [Codex 源码与读者审查](codex-reader-source-review-2026-09-27.md)：限定 Codex 产品模块的源码依据、知识去向与分层验证；
- [Codex 讲解精修](codex-clarity-refinement-2026-09-27.md)：正常过程前置、可观察材料、工具与记忆顺序、三维暴露及分层验收；
- [DeepSeek Harness 讲解精修](deepseek-harness-clarity-refinement-2026-09-27.md)：正常路径前置、跨章职责、实验入口与发布事实；
- [RAG 讲解清晰度精修](rag-clarity-refinement-2026-09-27.md)：条件支持、发布交接、图检索、机制实验与显示验证；
- [Audit History](history/README.md)：旧版本审计快照，保留当时数字与结论。

审计文件用于验证结构、粒度、覆盖、深度与质量门，不替代 Curriculum 正文。

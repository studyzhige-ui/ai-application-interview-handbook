## 4. 关键技术事实与适用边界

所有正文实现引用均固定到 `67a709665ac7b50311b93e32612c9a8281684787`。以下是直接影响旧结论的核验点；完整入口见[固定源码索引](../../references/agent/codex-source-index-current.md)。

| 核验点 | 实现证据 | 不允许推出的结论 |
|---|---|---|
| 主循环迁至 `core/src/session/turn.rs` | `run_turn` 与 StepContext 捕获/工具后续 | 一个 Turn 等于一次模型调用；旧路径失效等于功能消失 |
| 记忆写入由 `memories/write/src/` 承担 | start、phase1、phase2 与 App Server 调用方 | 仅进程启动一次；写入与读取开关完全相同 |
| 记忆版本影响产物 | V1 重建 raw_memories；V2 对应分支不同 | 所有版本目录和文件清单相同 |
| 整理 Agent 的沙箱分支有条件 | phase2 的 Managed / Disabled / External 配置分支 | 所有父环境下都由 Codex 本地沙箱禁止网络 |
| ToolSearch 旧功能项为兼容空项 | features 与 `search_tool_enabled` | 所有模型、会话都能发现所有工具 |
| 错误分类与副作用独立 | registry、parallel、orchestrator | 所有错误都可继续；结果被阻止等于动作撤销 |
| 连接持续重试是独立条件分支 | responses_retry 与功能默认值 | 所有错误都无限重试，或所有重试都有统一次数上限 |
| 存储有不同返回承诺 | ThreadStore 的 PersistContext、flush、shutdown、discard | 接纳等于持久；本地持久化等于跨系统事务 |
| Agent 协作存在尽力语义 | AgentControl 接口注释和本地实现 | 消息接纳等于模型阅读；接口等于可靠远端实现 |

上游记忆 README 仍含旧编排位置描述；本稿优先采用真实实现和调用方，不把一份官方概述当作覆盖所有分支的保证。版本注册表的默认值也仅是源码默认值，不冒充任何用户安装环境的实际配置。

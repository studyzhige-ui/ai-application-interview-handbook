## 2. 问题到修改的闭环

| 审查问题 | 修改位置 | 完成方式与保留内容 |

| 工具正常调用出现偏晚 | 工具 `one-call`、`dispatch` | 先 c2 的命令、目录、退出与失败结果，再讲工具发现、Skill 等扩展 |

## 3. 技术、教学与面经的边界

本轮重新读取固定源码的 `tools/src/tool_executor.rs`、`core/src/session/step_context.rs`、`memories/write/src/start.rs`，核对暴露维度、摘录字段、记忆入口与版本选择。其余未改动实现结论沿用同一固定快照的已有源码依据，本轮没有重新逐文件审计全部 32 个源码入口，也未构建 Rust 或运行上游测试。

补充核对 OpenAI 2026-01-23 的 Agent Loop 文章，用于理解请求与工具结果的叙述方法；它不替代较后快照的实现证据。

请求清单、call_id、记忆材料和故障时间线均明确为教学示意；未伪造真实 API Schema、模型输出或 Codex 执行日志。记忆正常路径带前提；正文保留实际触发、默认关闭、读取条件、V1/V2、租约、沙箱条件和产物校验等边界。

本轮没有新增面经采集、全库检索或外部原帖复核。沿用原审查的机制映射，只调整知识位置与解释，不更改 HUMAN-A 准入、Frozen Canonical、Source Count、题目主责或历史统计。

## 范围与基线

审查以 `7a986794a031d400de2ae782b7f5af3385d8163e` 的 Coding 为内容基线，覆盖 01–09 全部正文、入口、Hot100 映射和配套练习。此记录是本次修订的历史快照，不代表以后课程状态永远保持不变。提交前应重新读取 main，保留同期无关改动。

问题不是只少了几个 API。旧内容存在基础知识分散、先用后讲、函数准备不足、预览缺少实际追踪、练习缺输入、伪代码与可运行程序混淆、算法与工具的教学位置不一致，以及只增加原则声明而不修改正文。此次按整体依赖和每章责任处理，不把反馈当作逐点补丁清单。

## 逐章决策与知识迁移

| 章节 | 判断 | 实际处理 |
|---|---|---|
| 01 | 执行模型与容器例题交错，函数和错误基础薄弱 | 先数值、输入、判断、循环、函数与 Traceback；容器组合例题移到 02；保留循环追踪与多文件读栈 |
| 02 | 同级容器覆盖不对称，基础 API 散落应用中 | 以 list、tuple、str/bytes、dict、set 建立完整操作模型，解包先于 enumerate/items，排序和拼接先于分组；最后再组合 Hot100 |
| 03 | 题目条件与答案混在一起，函数化突兀，Notebook 仅有少数题 | 函数前置由 01–02 负责；统一 22 道自包含题，显式测试与折叠答案，由正文生成 Notebook |
| 04 | 输入分解的主线可保留，但出现未讲的类包装、模糊 EOF 和片段 | 保留协议主线，新增 map 的消费语义；复用 02 的字符串与字节操作，给每类协议完整输入和精确输出 |
| 05 | 结构名称先于可操作模型，class/self 与图变量无铺垫 | 操作成本 → 标准库容器 → 栈队列 → 类与实例 → 链表/树 → 堆/图/Trie；不把结构介绍当成算法解锁 |
| 06 | 递归、DFS、BFS 与回溯直接给骨架，缺数据与执行过程 | 线性状态在前，递归返回在搜索前，搜索在回溯前；完整示例含输入、断言、状态含义、正确性依据及成本 |
| 07 | 学习状态与复习方法可以保留，前置映射和技巧承诺需修正 | 保留 L/S/A/R、专题到混合、Hard 分层、ACM 选择；补区间组合与异或应用，纠正树/图解锁位置 |
| 08 | 导入工具箱代替教学，抽象程序缺少具体任务 | 以固定窗口最大和贯穿契约、朴素优化、纯函数、完整程序、边界与对拍；工具表只回指已教学位置 |
| 09 | 工作流原则基本有效，但缺少可完成的工程练习 | 保留调查、计划、实现、测试、Debug、Review、交付；用三文件分页项目提供缺陷实现、8 个测试与折叠修复 |

九章文件名保持稳定，以减少外部入口失效；内部标题、内容职责与顺序按学习依赖调整。没有用保留旧小节编号作为继续混排知识的理由。Hot100 的 100 个题号保留，准备章节与实际练习解锁分别描述；不新增 100 份重复题解。

## 规则落点

通用架构原则写入 `guide/documentation-style-guide.md` 的 Writer like a reader 小节；Coding README 说明当前有效的主线与使用方式，不承载修订聊天纪要。`tools/build_coding_practice.py` 以第 03 章为唯一来源生成 Notebook，避免正文和练习文件分别修改后漂移。

`tools/validate_coding_curriculum.py` 做示例冷启动、输入输出检查、预期异常、参考答案、工程练习红绿结果、容器主责位置的词法回归、100 题唯一编号与本地导航检查。词法出现不能证明已经解释清楚，这只是防回归，不替代内容审查。

## 本地验证记录

环境为 Python 3.13.5。9 章结构检查通过；除第 03 章按练习角色单独验证外，125 个 Python 示例块在独立进程中冷启动执行，其中包含 14 个精确 stdout 检查、1 个预期异常检查与 128 条示例断言。没有把故意失败的示例当成正常成功。

分页练习的 8 个测试在初始缺陷实现上出现预期失败，在折叠参考实现上全部通过。Hot100 映射为 100 个不重复题号。Coding 范围内链接检查通过；范围导出没有包含的根 README、学习路线、Python/Agent 模块与 Git 指南，另通过 GitHub 读取核验目标存在。

复现命令：`python tools/build_coding_practice.py --check`、`python tools/validate_coding_curriculum.py`。对仅导出的 Coding 范围，可加 `--allow-external-navigation`，该选项只允许报告导出范围外的缺文件，不能忽略 Coding 内部坏链接。

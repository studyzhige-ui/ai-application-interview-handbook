# AI 应用开发 & Agent / 智能体研发｜非算法岗位 JD 市场库

> 初始基线：2026-09-19；由已整理的 JD 汇编转换为仓库原生 Markdown，后续在同一文件持续更新。
> 维护目标：尽可能接近公开互联网全量覆盖；只收 AI 应用/Agent 工程岗位，严格排除以模型训练、后训练、RL、NLP/CV 算法研究为主体的算法岗。

## 维护规则

- **分类**：`AI应用开发` 与 `Agent / 智能体研发` 两类；按 JD 主目标分类，不按单个关键词机械分类。
- **来源优先级**：A=公司官方招聘页/官方团队招聘；B=公司招聘人员/校招官方渠道/高校就业网官方简章；C=可核验招聘镜像/聚合页。
- **去重**：同公司 + 同岗位主体 + 高度相同职责视为同一 JD；城市/批次镜像不重复计数，保留来源更高、信息更完整者。
- **过期**：官方页明确关闭/下架、招聘批次结束且无新入口、或连续复核无法确认仍在招时，从 Active 主清单移除；历史可通过 Git 追溯。
- **边界**：职位平台明确归类为算法工程师的岗位，即使内容包含 Agent，也不进入 Active 非算法主清单。
- **覆盖目标**：大厂、中厂、AI 创业公司、互联网/软件/汽车/电商/内容/企业服务等公司；使用中英文岗位同义词扩大 Recall。

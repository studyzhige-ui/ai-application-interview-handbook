# Canonical Questions

这里不做“网上见过什么题就全部收进来”的题库。

## 唯一原则

Canonical Question 只允许由 **HUMAN-A 真人高质量第一人称面经**产生证据：

```text
真人面试官
+
候选人本人第一人称
+
高信息密度
+
AI Application / Agent 目标岗位
+
可稳定核验
+
非转载重复
```

任何不满足上述标准的来源都不能创建新的 Canonical Question、提高某题的面试频率或伪装成课程学习优先级。

## 正式一级板块

Canonical Question 现在严格按下面十个板块整理：

```text
Python
  ↓
FastAPI
  ↓
AI Backend Engineering
  ↓
MySQL
  ↓
Redis
  ↓
Vector DB
  ↓
LLM Foundation（应用工程深度）
  ↓
RAG
  ↓
Agent Harness / Runtime
  ↓
System Design
```

`Coding / Debug / AI Coding` 只作为 Question Type，不再单独成为一级板块。

## 与完整知识体系的关系

完整课程体系负责决定“应该学什么”；真人高质量面经只负责提供真实问法、真实追问深度、公司 / 岗位 / 轮次信号和学习优先级校准。

因此不会为了扩充问题库，把二次创作、题库、标准答案、合集或无法核验的内容转化成额外学习任务。

# Canonical Questions

这里不做“网上见过什么题就全部收进来”的题库。

## 唯一原则

Canonical Question 只允许由 **HUMAN-A 真人高质量第一人称面经**产生证据：

```text
真人面试官
+
候选人本人第一人称
+
高信息密度
+
AI Application / Agent 目标岗位
+
可稳定核验
+
非转载重复
```

任何不满足上述标准的来源都不能：

- 创建新的 canonical question；
- 提高某题的面试频率；
- 改变课程学习优先级；
- 作为“补充知识点”增加学习量。

## 与完整知识体系的关系

完整课程体系负责决定“应该学什么”；真人高质量面经只负责提供：

- 真实问法；
- 真实追问深度；
- 公司 / 岗位 / 轮次信号；
- 学习优先级校准。

因此不会为了扩充问题库，把二次创作、题库、标准答案、合集或无法核验的内容转化成额外学习任务。

## 当前状态

研究数据已按 HUMAN-A 标准重新建立干净基线。Canonical Question 将从当前干净来源重新累计，并在有足够独立真人证据后再建立正式索引。

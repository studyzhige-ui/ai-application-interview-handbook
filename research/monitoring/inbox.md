# 2026 AI 应用 / Agent 真人面经持续监控 Inbox

用途：保存自动监控新发现、但尚未归入正式 `batch-xx.md` 的 **HUMAN-A 候选来源**。

## 硬性规则

新的 Inbox 候选必须同时满足：

1. **真人面试官**：明确为人与人进行的技术面 / Leader 面；AI 自动面试、AI 模拟面试直接排除。
2. **A 级第一人称**：候选人本人复盘，具有日期 / 轮次 / 现场互动 / 回答状态 / 结果等自然痕迹，并有足够具体的技术追问。
3. **Role Scope Gate**：岗位属于 AI 应用开发、Agent 开发、大模型应用、RAG、AI 后端、AI 全栈、Applied AI、FDE、Agent Runtime / Harness / Coding Agent 等目标方向。
4. **可稳定核验**：正文和来源 URL 可以实际访问验证；只有标题、截图或搜索摘要的不进入正式 Inbox。

以下内容不写入正式 Inbox：B 级低信息密度复盘、合集 / 整理、`含完整答案` / 标准答案、SEO 博客、水短视频、二次创作、模拟题库、自动化面试，以及与目标 AI 岗无关的传统数据分析 / BI / 推荐 / 训练 Infra / 普通后端场次。

## 搜索范围

不局限于牛客，也持续检查：小红书、知乎、脉脉公开索引、CSDN / 掘金等技术社区、Bilibili、抖音及其他公开来源。

但：**平台覆盖率永远不能降低 HUMAN-A 门槛。** 非牛客来源若无法稳定证明正文、第一人称和真人属性，就只放弃，不为了数量升级。

每个候选来源记录：

- 发现日期；

- 公司 / 岗位；

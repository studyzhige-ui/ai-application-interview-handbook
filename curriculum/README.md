## 与 Products 的关系

Curriculum 维护可迁移的通用知识与 Primary Ownership；[Products](../products/README.md) 沿固定源码快照学习成熟系统怎样组合这些机制。

```text
Curriculum
→ 建立 Context / State / Database / Runtime / Evaluation 等稳定知识模型
→ Products
→ 沿真实数据结构、调用链与 Failure Path 验证完整系统怎样运行
```

Products 不作为第 11 个 Curriculum 模块，也不改变十模块的正式学习顺序与 Canonical Ownership。

市场证据来自 [Market](../market/README.md)，Canonical 归一化来自 [Interview](../interview/README.md)，技术事实校准来自 [References](../references/README.md)。它们会校准 Curriculum，但不会取代 Curriculum 的知识依赖。

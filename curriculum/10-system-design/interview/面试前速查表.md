# System Design｜面试前速查表

## 1. 拿到题先写这 8 个词

```text
Requirement
SLO
Scale
State
Flow
Failure
Security
Verification
```

---

## 2. 需求澄清

```text
谁用？

P99？

哪些写不能重复？

```

```text

```

---

## 3. Capacity 速算

```text
QPS ≈ daily operations / 86400 × peak factor
Storage ≈ records × avg size × retention × replica/index overhead
Bandwidth ≈ QPS × payload
Queue stable only if service rate >= arrival rate
```

别忘：HotKey / Hot Tenant / Burst。

---

## 4. State 三分法

```text
Primary
→ order / permission / task result

Derived
→ cache / search / vector / ranking

Ephemeral
→ session / lease / progress
```

先定 Source of Truth。

---

## 5. Sync / Async

```text
need immediate answer
→ Sync

long / bursty / retryable / decoupled
→ Durable Async
```

Async 必须继续讲：

```text
state machine
idempotency
retry
lease
backpressure
cancel
```

---

## 6. Cache

```text
why cache?
→ repeated read / expensive compute / stale acceptable
```

必须讲：

```text
SoT
TTL
invalidate
hot key
stampede
cache failure
permission/version in key
```

## 7. Partition

```text
Shard Key
= distribution + query routing + hotspot + lifecycle
```

不要只说 `hash(id)%N`。

跨 Shard：

```text
fan-out
merge
tail latency
partial failure
```

## 8. Correctness

```text
Business Invariant
→ Transaction / Constraint / CAS
→ Idempotency
→ Retry
→ Compensation
→ Reconciliation
```

Timeout ≠ definite failure。

## 13. 典型 Case 一句话抓重点

```text
秒杀
→ invariant + hot traffic + reservation + idempotency + compensation

排行榜
→ derived view + hot key + freshness

Feed
→ fan-out write vs read

Autocomplete
→ prefix/infix/fuzzy + debounce + low latency

Notification
→ durable delivery + provider id + retry + dedup

Migration
→ keyset batch + checkpoint + delta catch-up + validation

Large File
→ object storage direct upload + multipart + async processing

LLM Gateway
→ adapter + routing + quota + streaming + cost + failover

Enterprise RAG
→ lineage + permission + index generation + eval + freshness

Agent Backend
→ durable run + checkpoint + side-effect idempotency + worker lease
```

---

## 14. 结束前自问

```text
我有没有明确 SoT？
我有没有讲最危险 Failure？
我有没有讲 Hotspot / Scale？
我有没有讲 Retry 是否安全？
我有没有讲 Tenant / Permission？
我有没有讲怎么验证？
```

如果六个都答了，通常已经比“组件百科式 System Design”稳很多。

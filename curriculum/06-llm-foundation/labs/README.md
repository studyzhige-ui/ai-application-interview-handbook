[← 模块首页](../README.md) · [Review](../review/README.md)

本实验不下载模型、不调用 API，也不要求 GPU。用途是验证正文中的表示变换、采样分布、KV 容量、LoRA 增量和参数量、偏好比较与相关手算边界，不模拟一个真实推理服务，更不证明训练效果。

## 运行

使用 Python 3.10 或更高版本的标准库。在仓库根目录运行：

```bash
python curriculum/06-llm-foundation/labs/test_examples.py -v
```

也可以进入本目录运行 `python test_examples.py -v`。测试依据脚本位置定位正文，不依赖当前工作目录；每次读取三个带 `example` 标记的代码块，并在新的命名空间运行，因此不依赖上一轮状态。正常结束应显示全部测试通过、退出码为 0，不产生需要清理的数据或外部资源。

这里声明的 Python 版本范围是示例语法目标；实际执行版本和未运行的组合分别记录在 [系统优化记录](../../../guide/project/llm-foundation-reader-revision-2026-09-27.md) 与 [精修验收记录](../../../guide/project/llm-foundation-clarity-refinement-2026-09-27.md)，不把语法兼容检查当成所有版本已实测。

## 先预测，再运行

| 正文中的唯一实现 | 改变什么条件 | 应检查什么 |
|---|---|---|
| 第 05 章 `softmax` | 给所有 logits 加同一个数；改变正温度；输入零温度或非有限数 | 分布平移不变、排序与尖锐度的区别、明确异常 |
| 第 06 章 `kv-bytes` | 改变 KV 头数、所有请求长度、精度；输入负长度 | 容量单位、并发只计一次、输入校验 |
| 第 13 章 `lora-count` | 改变矩阵形状和秩 | 参数量公式与总训练显存并非同一件事 |

测试直接执行正文中的这三个函数，不在实验中重写第二套算法。其他检查保留 Attention、预算、分页、池化、评测分母和组内奖励的验算，并回读正文中标记的数值表，检查 FFN、归一化、RoPE、SFT 损失、LoRA 增量和 DPO 比较的结果。它们仍是公式验算，不是模型输出准确率或生产性能测试。

新增练习按“先预测、再验证”使用：第 03 章改变前馈输入，第 04 章改变两个位置的间距，第 13 章改变 LoRA 输入，第 14 章比较损失与绝对概率。先解释哪个规则改变了结果，再查看折叠答案。

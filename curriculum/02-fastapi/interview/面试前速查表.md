# FastAPI 面试前速查表

## 1. 一张图记住 FastAPI

```text
Client
→ Uvicorn / ASGI Server
→ Middleware
→ Router
→ Validation / Dependency
→ Handler
→ Service
→ DB / Redis / Vector / LLM / Agent
→ Response / SSE / WebSocket
```

## 2. 四个组件

```text
Uvicorn  = ASGI Server
Starlette = Web / ASGI primitives
FastAPI  = typed API + DI + OpenAPI
Pydantic = runtime validation / serialization
```

## 3. Middleware vs Dependency

```text
Middleware：全局横切
request_id / access log / timing / CORS / trace

Dependency：Route-aware
current user / tenant / db session / scope
```

## 4. Resource Lifecycle

```text
Lifespan
→ app-level client / pool

Yield Dependency
→ request/route-level resource

Streaming
→ 注意 cleanup 是否覆盖整个 stream
```

## 5. `def` vs `async def`

```text
async def + awaitable I/O
→ event loop concurrency

def path operation / dependency
→ FastAPI external thread pool

async def 里直接调用 sync helper
→ 不会自动 offload
```

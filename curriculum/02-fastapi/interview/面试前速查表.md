这是复习卡，不是首次学习教程。先能说清每个词后面的过程，再用短句回忆。技术基线为FastAPI0.141.1，具体版本变化见[官方资料](../../../references/fastapi/README.md)。

## 🧭 请求与组件

```text
客户端 → Uvicorn → FastAPI/Starlette → 输入/依赖 → 业务 → 响应
Uvicorn     服务器与网络入口
Starlette   Web/ASGI基础
FastAPI     类型驱动接口、依赖、OpenAPI
Pydantic    运行时数据校验与序列化
```

路径、Query、Header、Cookie、Body来源分清。JSON解析、结构、业务与授权不是同一检查。response_model不仅是文档，直接返回Response时注意处理边界。

## ♻️ 依赖与资源

```text
中间件          外层横切处理，后加在外层
依赖            路由需要的输入、身份、资源图
lifespan        应用级初始化与退出
yield/request   默认覆盖请求响应周期
yield/function  处理函数结束后、响应发送前清理
```

请求身份不存应用全局；后台任务拥有自己的资源范围。客户端/池常复用，会话和事务范围须明确。

## ⏱️ 执行、流与取消

```text
框架调用def        在线程执行
async内部普通helper 不自动转交
gather             并发聚合，不是限流
Semaphore          本地在途限制，不是全局速率
StreamingResponse  分块响应体
Polling            定期查询当前状态，按刷新延迟与请求成本取舍
SSE                event/data/id等事件协议
JSON Lines         每行一个完整JSON值
WebSocket          持续双向消息
```

SSE服务端可POST返回，浏览器EventSource的请求能力另有限制。流开始后不能改已发状态；没收到终止事件不默认成功。事件ID不等于业务确认或自动持久恢复；补历史与重取最新快照是不同要求。

```text
超时 ≠ 远端未执行
断开 ≠ 业务取消
cancel请求 ≠ 任意线程立刻停止
CancelledError继承BaseException，不被普通except Exception捕获
```

## 🔐 身份与任务

认证确认身份，授权判断动作，CORS是浏览器跨源机制。HTTPBearer只提取凭证，不自动验证任意JWT。可信tenant范围贯穿数据与工具，不靠提示词约束。

UploadFile使用临时文件，分块读取仍需入口限制。续传另外需要upload_id、已保存部分和完整性校验；失败产物按任务归属清理。BackgroundTasks是进程内响应后工作；202、task_id和UUID都不会自动提供持久与幂等。

## 🔍 测试与观测

输入、状态、输出、权限、下游失败、取消和释放都要有证据。dependency_overrides要恢复；TestClient用上下文触发生命周期，AsyncClient/ASGITransport不自动触发。

call_next返回不等于流发完。分开看连接等待、下游、首段与总时长；request_id放日志/Trace，不作为无限指标标签。

## 🚀 部署与完整服务

worker有独立内存和池；总资源看副本×进程×每进程配额。存活与就绪服务不同决策。平台摘流、服务器drain与lifespan清理各有责任和时间预算。

```text
POST /agent/runs                         创建执行
GET  /agent/runs/{id}                    查询状态
GET  /agent/runs/{id}/events             观察事件
POST /agent/runs/{id}/cancel             请求取消
POST /agent/runs/{id}/approvals/{action}  批准或拒绝具体动作
```

这是可选API组织示意，不是所有系统强制路径。FastAPI负责Web边界，Runtime负责循环、工具、上下文、记忆和恢复。

## 用一条问题唤起全链路

```text
权威来源、适用时间与权限
→ 按格式解析，保留结构、条件与位置
→ 合适粒度的块及可回取关系
→ 在授权范围内保留原问题并检索
→ 多路融合，按预算重排
→ 去重、补全、再次授权与上下文装包
→ 生成，核对引用、条件与支持关系
```

A 给出 14 天的一般规则，B 给出专属资源例外。只找到 A 不等于已答完整；答出人工复核不等于已经提交退款。

## 容易混在一起的对象

| 两个概念 | 核心区别 |
|---|---|
| 文档身份与文档版本 | 同一逻辑对象，与它某次具体内容不同。 |
| 当前内容与当前授权 | 内容可回滚，撤权和删除不能被旧内容版本恢复。 |
| 检索块与上下文块 | 定位粒度可以较小，解释粒度可按关系补全。 |
| 相关性与充分性 | 看起来有关，不等于覆盖全部必要事实。 |
| 改写与分解 | 前者重述同一需求，后者拆开不同信息需求。 |
| Dense 与词项 | 语义表示与精确术语信号互补。 |
| 融合与重排 | 多路线索合并，与重新评估问题—候选相关性不同。 |
| 忠实与正确 | 基于给定证据，与符合适用事实不同。 |
| 无命中与执行失败 | 检索完成后的结果，与检索未正常完成不同。 |

## 公式要连同口径一起说

RRF：对每个候选累加各路 `1/(c+rank)`，排名从 1 开始，未出现贡献 0。不同路线先使用一致身份，不能按整份文档去重而丢掉其他条件。

固定窗口：步长 `S−O`，要求 `0≤O<S`；非空长度 N≤S 时一块，否则 `1+ceil((N−S)/(S−O))` 块。单位先说清；这是位置计算，不保证语义完整。

Recall@K：前 K 中相关数量 / 全部已知相关数量。Precision@K：前 K 中相关数量 / K，本实验短结果也用固定 K。空相关集合不计算 Recall，转为不可回答与拒答评测。

RR@K：首个相关结果位于 r≤K 时为 `1/r`，否则为 0；MRR 是多个适用问题的 RR 均值。NDCG：分级增益按位置折扣，再除以全部已知标签构成的理想排序分数。Hit 与 RR 都不能代替全部必要证据覆盖。

## 更新、回滚与缓存

```text
发现变化 → 构建新版本 → 验证 → 补齐期间增量
→ 确认各必要存储可查询 → 切换一致知识代号
→ 保留允许的回滚窗口 → 清理不再需要的派生物
```

**不是先删掉可服务的旧版本再尝试建新版本。** 但来源删除、紧急撤权需要独立阻止可见，不能为了可用性继续暴露。幂等解决重复任务；源版本检查解决旧任务晚写。缓存复用依赖问题条件、知识代号、模型配置、会话和当前授权，不只依赖一句相似问题。

## 错误定位顺序

适用原文有答案吗？解析和切分保住了吗？正确证据进入合法候选了吗？被重排、去重或预算丢掉了吗？已进入上下文后，模型是否正确解释并引用？找到第一处缺口，再用受控完整证据检查后续阶段，不假设只存在一个错误。

对照实验固定来源、问题、权限、模型与其余参数。报告分母、百分点、新增正确与退化类别，联合比较质量、尾延迟和每成功回答成本。真实服务、多连接并发和生产结果必须有对应实测，不能拿模拟测试代替。

## 复杂方案的选择

关系、路径或全库聚合问题可以评估图辅助；后续动作依赖中间证据时可以评估动态检索。两者都要与固定基线对照，保留来源、权限、预算与停止。最大步骤数不是成功标准，数据缺失也不是无限搜索的理由。

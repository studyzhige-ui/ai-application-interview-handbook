# MySQL｜从关系数据到高并发与数据演进

[← FastAPI](../02-fastapi/README.md) · [课程目录](../README.md) · [Handbook](../../README.md) · [Redis →](../04-redis/README.md)

本模块从关系模型和 SQL 出发，沿着执行、索引、性能诊断、事务并发、提交恢复与数据演进，建立一套能够解释 MySQL 行为并解决真实工程问题的知识模型。

## 学习目标

学完后应能够：

- 从业务事实设计关系表、约束与查询，并判断 SQL 结果是否正确；
- 从执行计划、B+Tree 与联合索引解释查询成本，并完成基于证据的性能诊断；
- 理解事务、隔离级别、MVCC、锁与死锁，处理并发读取和并发修改；
- 理解日志、故障恢复、复制、CDC，以及数据增长后的 Schema、索引、批处理与迁移问题。

## 学习与面试

首次学习按顺序阅读 `docs/`，重点理解每章的问题主线、机制关系和边界；完成一章后，使用章末总结与自测检查是否能独立解释和推导。忘记某个机制时回到对应正文，不需要额外维护一套重复的复习资料。

面试准备集中在 [MySQL 面试材料](../../interview/03-mysql/README.md)：[高频面试题](../../interview/03-mysql/01-高频面试题.md)、[易混易错点](../../interview/03-mysql/02-易混易错点.md)与[面试速查](../../interview/03-mysql/03-面试速查.md)。课程正文负责建立完整知识模型，面试材料负责回答、追问与快速调用。

## 版本与证据边界

课程当前以 MySQL Community 9.7 LTS、InnoDB 为主要技术边界。技术事实以各章引用的官方资料及其适用范围为依据；[Market](../../market/README.md)中的真实岗位与面试材料用于校准学习重点与深度，不代替技术证明。

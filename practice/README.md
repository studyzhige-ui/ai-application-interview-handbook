## Python 高频基础操作

[Python 基础操作小题](python-basics/Python高频Coding小题.md)聚焦容器处理、文本、排序、计数与常见 Python 写法。它用于巩固语言，不替代 [Python 课程](../curriculum/01-python/README.md)的对象、函数与执行原理，也不要求先学完整套算法。

## 数据库基础操作

[按操作目的选择入口](database-basics/README.md)：分开 SQL 查询与修改、Redis 命令与状态。

- [MySQL 操作与结果](../curriculum/03-mysql/examples/README.md)：查询、关联、更新和事务示例；[实验说明](../curriculum/03-mysql/examples/experiments.md)区分可观察结果与真实并发保证
- [Redis 命令与状态](../curriculum/04-redis/examples/README.md)：数据类型、过期与原子操作；[命令过程](../curriculum/04-redis/examples/labs.md)按输入、返回值和状态变化阅读

这些入口保留在知识模块旁边，方便核对正文。它们训练数据库的基础操作，不混入算法题的解锁链。

## Coding 独立顺序

[进入 Coding](coding/README.md)：程序执行 → Python 解题写法 → 基础小题 → 完整输入输出 → 数据结构 → 算法思路。后续 Hot100 与在线笔试用于延伸和综合应用，按兴趣及目标选用。Coding 自身解释所需的程序和算法前提，不要求与 Python 课程交叉跳读。

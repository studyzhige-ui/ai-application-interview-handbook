# 04｜完整输入输出：把数据协议翻译成程序

[← 上一章：基础练习](03-basic-exercises.md) · [Coding 首页](../README.md) · [下一章：数据结构 →](05-data-structures.md)


你已经能写 `two_sum(nums, target)`，给它一个列表和目标，它就能返回两个下标。但笔试页面可能只把两行文字交给程序：第一行写长度与目标，第二行写各个数字。**这些文字还不是函数需要的参数，谁来把它们变过去？**

这一章补上这段连接。把输入读成正确的数据，再把计算结果按要求输出，你才拥有一份能独立运行的完整程序。算法没有换一套，只是原来由平台代劳的工作，需要自己接过来了。

## 1. 函数模式与完整程序模式

两种模式的区别，在于平台已经替你完成了哪些工作：

| 模式 | 平台交给你什么 | 你负责什么 |
|---|---|---|
| 函数模式 | 已经构造好的 `nums`、`target` 等参数 | 计算并返回结果 |
| 完整程序模式 | 符合题目格式的输入文字 | 读取、转换、计算，再按要求输出 |

算法可以相同，但完整程序模式还要自己处理输入与输出。

先认识两个通道：

- **标准输入（stdin）**：程序从这里读取输入。可以来自键盘，也可以由评测系统提供。
- **标准输出（stdout）**：程序把结果写到这里。`print()` 默认使用这个通道。

```text
输入文字 → 解析为 Python 数据 → 算法函数 → Python 结果 → 格式化输出
```

LeetCode 有时给出的 `class Solution` 是平台约定的函数包装。此时先分清“平台怎样调用代码”与“算法怎样处理数据”，不需要为了理解输入输出，先展开整套面向对象语法。

## 2. 把一行数字拆开：先看过程，再看紧凑写法

给你字符串 `"10 20 30"`，想得到整数列表 `[10,20,30]`，一次 `int` 不能转换整行，因为里面有多个数字。先拆开，再逐项转换，事情就简单了。

```python
line = "10 20 30"
parts = line.split()       # ['10', '20', '30']
nums = []
for part in parts:
    nums.append(int(part))
print(nums)               # [10, 20, 30]
```

对照中间结果，代码分成三个步骤：

1. `split()` 把整行拆成 `["10", "20", "30"]`。
2. 每轮把一项传给 `int()`，分别得到整数 10、20、30。
3. 把这些整数追加到列表，得到 `[10, 20, 30]`。

> ⚠️ `int()` 一次转换的是一个数的文字表示。不能直接把包含多个数的 `"10 20 30"` 交给它。

同样的逐项转换可以交给 `map`：

```python
line = "10 20 30"
parts = line.split()
converted = map(int, parts) # 准备逐项调用 int
nums = list(converted)     # 取出转换结果，收集成列表
print(nums)                # [10, 20, 30]
```

`map(int, parts)` 表示：从 `parts` 逐项取数据，对每项应用 `int`。它先准备这个逐项转换过程，外面的 `list(converted)` 才会取完结果并收集成列表。

常见写法 `list(map(int, input().split()))` 可以按以下顺序读：

1. `input()` 读一行，得到字符串。
2. `.split()` 拆分字符串，得到字符串列表。
3. `map(int, ...)` 准备逐项转换。
4. `list(...)` 取得转换后的整数，组成列表。

> ⚠️ `map` 接收的是函数 `int`，不是立即调用后的 `int()`。前者告诉它每项怎样转换，后者会在当前位置先执行一次调用。

<details><summary>为什么同一个 map 再转一次 list，可能得到空列表？</summary>

map 的结果会逐项被取走。第一次 list 已经消费完同一个 map 对象，第二次不会自动重新生成：

```python
converted = map(int, ["10", "20"])
print(list(converted)) # [10, 20]
print(list(converted)) # []
```

需要反复使用数据，就保存第一次收集出的列表，而不是反复读取已经耗尽的同一个 `map`。

> ⚠️ 解包也会取走结果。`a, b = map(int, parts)` 要求恰好提供两项，项数多于或少于两项都会失败。

</details>

## 3. 单组输入：先定义每一行的意义

本例的输入输出约定是：

1. 第一行给出非负整数 `n`，表示数字个数。
2. 第二行给出恰好 `n` 个整数。
3. 输出这些数的和。

即使 `n = 0`，本练习也约定存在第二个空行。

输入样例：

```text
3
10 20 30
```

预期输出：

```text
60
```

<!-- run: {"stdin":"3\n10 20 30\n","stdout":"60\n"} -->
```python
n = int(input())
nums = list(map(int, input().split()))
assert len(nums) == n        # 本地核对协议；评测按题目保证的格式读取
print(sum(nums))             # 60
```

> ⚠️ 第一行只有一个数，不代表它一定是数组长度。它也可能是组数或目标值。先确定这个数在题目中的含义，再决定怎样读取后续数据。

## 4. T 组、EOF 与哨兵：三种结束依据

多组输入首先要确定结束依据：

| 结束依据 | 程序怎样判断 |
|---|---|
| 提前给出组数 `T` | 已经处理了 `T` 组 |
| EOF，输入源结束 | 已经没有下一行可读 |
| 哨兵值 | 读到了题目指定的结束数据，例如 `0 0` |

三种依据不同，循环的停止条件也不同。

### 4.1 已知组数

本例第一行给出组数 `T`，随后每行两个整数，共 `T` 行。每处理一行，就输出这一行两数之和。

本例输入如下。第一行的 3 不参与求和，只告诉程序后面要处理三组：

```text
3
1 2
5 6
10 20
```

<!-- run: {"stdin":"3\n1 2\n5 6\n10 20\n","stdout":"3\n11\n30\n"} -->
```python
T = int(input())
for _ in range(T):          # _ 是不用的循环变量，不是特殊语法
    a, b = map(int, input().split())
    print(a + b)
```

样例中 `T = 3`，循环恰好执行三轮，依次输出：

```text
3
11
30
```

> ⚠️ 每组独立的计数器、字典和结果列表，应在每轮处理该组时初始化。把它们放到循环外，可能把上一组的数据带到下一组。

### 4.2 不知道组数，读到输入源结束

**EOF（End Of File）表示输入源已经结束，没有下一行可读。** 它不是一行特殊的文字，也不是空白行。

本例每行两个整数，不提前给组数，也没有空行。输入如下：

```text
1 2
3 4
```

`import sys` 引入标准库的 `sys` 模块，`sys.stdin` 表示标准输入流。用 `for` 遍历它，就会逐行读取，在没有下一行时结束：

<!-- run: {"stdin":"1 2\n3 4\n","stdout":"3\n7\n"} -->
```python
import sys

for line in sys.stdin:
    a, b = map(int, line.split())
    print(a + b)
```

上面的例子输出 3、7，各占一行。

也可以使用 `input()` 读取，并在 EOF 时结束。这需要认识 `try / except`：

1. 先执行 `try` 中的读取操作。
2. 如果成功，继续执行后面的数据处理。
3. 如果读取抛出 `EOFError`，进入匹配的 `except`，再用 `break` 退出循环。

<!-- run: {"stdin":"1 2\n3 4\n","stdout":"3\n7\n"} -->
```python
while True:
    try:
        line = input()
    except EOFError:
        break
    a, b = map(int, line.split())
    print(a + b)
```

先区分读取对象，再判断结果的含义：

| 读取方式 | 读到空白行 | 已经没有输入 |
|---|---|---|
| `input()` | 返回空字符串 `""` | 抛出 `EOFError` |
| `sys.stdin.readline()` | 返回换行符 `"\n"` | 返回空字符串 `""` |
| `for line in sys.stdin` | 这一轮取得 `"\n"` | 循环自然结束 |

> ⚠️ 空行仍然是一行输入。不要把所有读法中的 `""` 都当作 EOF。上面的 `except` 只捕获 `EOFError`；数字格式不合法引起的 `ValueError` 不应被假装成“输入正常结束”。

### 4.3 读到了特殊数据才结束

本例约定每行两个整数，读到 `0 0` 就停止，不输出这一行的和。输入保证包含这个结束标记：

```text
1 2
3 4
0 0
```

<!-- run: {"stdin":"1 2\n3 4\n0 0\n","stdout":"3\n7\n"} -->
```python
while True:
    a, b = map(int, input().split())
    if a == 0 and b == 0:
        break
    print(a + b)
```

先读取一行，再检查这一行是否为 `0 0`。命中就退出，没有命中才输出和。因此样例只输出 3、7。

> ⚠️ `0 0` 是实际读到的数据，叫哨兵值。它不表示输入源一定已经结束，只表示题目要求程序到这里停止处理。

## 5. 数组、矩阵、字符串与边列表

### 5.1 矩阵：先行数列数，再逐行读取

读一张两行三列的表，程序要先知道有几行，再把每行读成一个列表，逐行放入外层列表。这样第一层下标选行，第二层下标选这一行的列。

本例约定：

- 第一行是行数 `n` 和列数 `m`。
- 接下来有 `n` 行，每行 `m` 个整数。
- 输出所有元素的总和。

输入样例：

```text
2 3
1 2 3
4 5 6
```

预期输出为 21。

<!-- run: {"stdin":"2 3\n1 2 3\n4 5 6\n","stdout":"21\n"} -->
```python
n, m = map(int, input().split())
matrix = []
for _ in range(n):
    row = list(map(int, input().split()))
    assert len(row) == m
    matrix.append(row)
answer = 0
for row in matrix:
    answer += sum(row)
print(answer)                 # 21
```

第一次读行得到 `[1, 2, 3]`，追加到 `matrix`；第二次读行得到 `[4, 5, 6]`，再追加。最终 `matrix` 是 `[[1, 2, 3], [4, 5, 6]]`。

`matrix[r][c]` 先选择第 `r` 行，再选择这一行的第 `c` 项。

> ⚠️ 外层读取次数是行数 `n`，不是列数 `m`。是否允许零行、零列，应以题目约定为准。

### 5.2 字符串里的空格是否有意义

**契约：** 读取一行文字，原样输出。样例保留首尾空格。

<!-- run: {"stdin":"  hello world  \n","stdout":"  hello world  \n"} -->
```python
text = input()
print(text)
```

`.strip()` 会去掉文字两端的空白，不会去掉中间的空格。只有题目说这些首尾空白可以忽略时，才应该使用它。

> ⚠️ 本题要求保留首尾空格，因此不能调用 `.strip()`，也不能先 `.split()` 再随意连接。选择读取操作前，先检查它会不会丢掉题目要求保留的信息。

### 5.3 图先作为边的数据读取

本例只练习读取关系数据：

- 第一行给出点数 `n` 和边数 `m`。
- 随后 `m` 行，每行的 `u v` 表示点 `u` 与点 `v` 之间有一条无向边。
- 读取后输出边的数量。

输入样例：

```text
4 3
1 2
2 3
2 4
```

预期输出为 3。

<!-- run: {"stdin":"4 3\n1 2\n2 3\n2 4\n","stdout":"3\n"} -->
```python
n, m = map(int, input().split())
edges = []
for _ in range(m):
    u, v = map(int, input().split())
    edges.append((u, v))
print(len(edges))              # 3
```

读关系数据前，至少确认三件事：

1. 边有方向吗，还是两边都能走？
2. 每行只有两个节点编号，还是还有一个权重？
3. 节点从 0 编号，还是从 1 编号？

> ⚠️ 树也没有统一的输入模板。父子边、层序序列、左右孩子编号代表不同格式。先看题目怎样描述关系，不能只因为都是整数就按数组读取。

## 6. 输出与程序入口

### 6.1 输出列表元素，而不是列表的显示形式

假设题目要求输出 `1 3 5`，不能直接用列表的显示形式 `[1, 3, 5]` 代替。

`print(*nums)` 中的 `*` 会把列表元素展开为多个参数。本例相当于调用 `print(1, 3, 5)`：

```python
nums = [1, 3, 5]
print(*nums)  # 1 3 5
print(" ".join([str(x) for x in nums]))  # 1 3 5
```

第二种写法先把每个整数转成字符串，再用空格连接。两种写法的结果相同，但中间过程不同。

> ⚠️ `*nums` 在函数调用中展开参数，`a, b = pair` 则在赋值时拆给变量。不要仅仅因为都叫“展开”或“解包”，就把语法位置混用。

### 6.2 按要求保留小数位数

格式化字符串以 `f` 开头，花括号里放需要显示的值。`.2f` 表示以小数形式保留两位：

```python
x = 3.14159
print(f"{x:.2f}")  # 3.14
```

> ⚠️ 格式化改变的是输出形式，不会让浮点数计算变成精确的十进制计算。

### 6.3 把完整流程放进 solve，再从入口调用

`solve()` 可以集中放置读取、调用算法和输出的过程。定义函数之后，还需要调用它，程序才会执行这些步骤。

文件底部常见的 `if __name__ == "__main__":`，用于区分两种启动方式：

- 直接运行这个文件：条件为真，调用 `solve()`。
- 被其他文件导入：条件为假，不会因为导入就开始读取输入。

下面用两数之和串起完整过程。

输入输出约定：

1. 第一行是 `n` 和 `target`，第二行是 `n` 个整数。
2. 有解时保证唯一，输出两个不同下标。
3. 无解时输出 `-1 -1`。

输入样例为：

```text
4 9
2 7 11 15
```

预期输出为 `0 1`。

<!-- run: {"stdin":"4 9\n2 7 11 15\n","stdout":"0 1\n"} -->
```python
def two_sum(nums, target):
    seen = {}
    for i, x in enumerate(nums):
        need = target - x
        if need in seen:
            return seen[need], i
        seen[x] = i
    return -1, -1

def solve():
    n, target = map(int, input().split())
    nums = list(map(int, input().split()))
    assert len(nums) == n
    i, j = two_sum(nums, target)
    print(i, j)

if __name__ == "__main__":
    solve()
```

从文件底部的调用开始追踪：

1. 直接运行文件，进入 `solve()`。
2. 读取并解析两行输入，得到 `nums` 和 `target`。
3. 调用 `two_sum()`，取得两个下标。
4. 用 `print(i, j)` 按要求输出。

输入读错，就检查前两行读取；下标算错，就单独测试 `two_sum`；格式不对，就检查最后的打印。

## 7. 数据很多时，再考虑一次读取

按行读懂题目以后，如果输入量较大，而且换行本身没有意义，可以一次读取。它是输入方式的选择，不是每道题必须使用的“高级模板”。

<details><summary>需要大量数值输入时再看：read 与 bytes</summary>

这句读取分为三层：

1. `sys.stdin.buffer`：取得二进制形式的标准输入流。
2. `.read()`：读取剩余全部内容，得到 `bytes`（字节），例如 `b"10 20"`。
3. `.split()`：按空白拆成多个字节片段，再把各项交给 `int` 转成整数。

这里不是普通字符串 `str`，但 `int` 同样支持符合整数格式的字节片段。

**契约：** 所有内容都是整数，只需要它们的总和，换行不区分记录。

<!-- run: {"stdin":"1\n2 3\n4\n","stdout":"10\n"} -->
```python
import sys

tokens = sys.stdin.buffer.read().split()
nums = list(map(int, tokens))
print(sum(nums)) # 10
```

> ⚠️ 一次读取会占用较多内存，也会失去逐行处理的便利。如果换行区分记录，就不能随意全部拆开。交互输入尚未结束时，`read()` 还可能继续等待，不能把“在等待输入”误判成算法死循环。

</details>

## 8. 本章小结与面试怎么答

输入格式本质上是双方的约定：哪些行是组数，哪些字段是数据，什么时候结束，怎样表示结果。每次 input 消费了哪一行、转换以后是什么类型，说清这些就能写出完整程序。

**问：LeetCode 函数题会做，为什么换成 ACM 模式还可能失败？**

> 🎯 函数模式由平台构造参数并读取返回值；完整程序还要自己解析标准输入、处理多组与结束条件，并按格式输出。算法不变，但输入和输出也成为正确性的一部分。

## 9. ⚠️ 容易混淆的地方

- 第一行一个整数不一定是 n，也可能是 T、目标值或其他参数，含义只能来自题面。
- EOF、空行、哨兵值是三件事；不要把不同输入协议套成同一个循环。
- 字符串中的空格可能就是数据，split 与 strip 都可能丢掉不该丢的信息。
- 算法返回列表，不代表输出可以带 Python 的方括号；输出格式必须单独核对。

## 10. 章节自测与动手练习

**任务：** 第一行给出组数 `T`。之后每组先给 `n`，再给一行 `n` 个整数。每组输出这些数的和。

输入样例：

```text
2
3
1 2 3
2
4 5
```

预期输出：

```text
6
9
```

<details><summary>查看完整答案</summary>

<!-- run: {"stdin":"2\n3\n1 2 3\n2\n4 5\n","stdout":"6\n9\n"} -->
```python
T = int(input())
for _ in range(T):
    n = int(input())
    nums = list(map(int, input().split()))
    assert len(nums) == n
    print(sum(nums))
```

</details>

**口述自测：**

1. EOF 和空行有什么区别？
2. 为什么不能给所有 `input()` 都加上 `.strip()`？
3. 为什么图和树的输入不能直接照抄数组模板？

<details><summary>查看参考答案</summary>

1. EOF 表示已经没有数据，空行仍是成功读到的一行。
2. 首尾空白可能是题目要求保留的文字内容，`.strip()` 会删除它们。
3. 图和树的输入在描述关系，不只是数字列表。要先看清每个字段表示什么。

</details>

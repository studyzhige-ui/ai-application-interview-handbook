# 07｜Hot100 综合训练：把专题知识变成可调用能力

[← 上一章：算法推导](06-problem-solving-and-algorithms.md) · [Coding 首页](../README.md) · [100 题映射](../hot100-map.md) · [下一章：在线笔试 →](08-online-assessment.md)


昨天跟着“滑动窗口”专题能写出来，今天把题目单独拿出来，却不知道该从哪下手。可能忘掉的不是代码，而是：**当题目没有提前告诉你用什么方法时，怎样自己作出选择。**

本章把熟悉的题重新打散，让你从题意、约束和重复工作出发。我们也会看几种专题之间的组合：比如排序怎样帮助扫描，输入的特殊保证怎样允许更省空间的解法。做过题只是起点，能够重新推导，才会在陌生场景里用得上。

本章是扩展使用指南，只完整讲解下文选取的综合例子。题库里的拓扑排序、单调队列与各类 DP 等新增方法，应按对应题目另行学习；[映射表](../hot100-map.md)已将这些题标作扩展，不表示第 06 章覆盖了全部解法。

## 1. 怎样把“介绍过”与“掌握了”分开

同样一个“做过”的勾，可能代表看懂了答案，也可能代表关掉答案独立写过。这两种状态差得很远。可以用四个简单标记把它们分开：

| 标记 | 实际意味着什么 |
|---|---|
| L：理解 | 能解释题意与参考解法 |
| S：独立实现 | 关掉答案后写出并通过 |
| A：完整程序 | 适合的题能自己处理输入输出 |
| R：间隔后重建 | 过一段时间仍能分析和重写 |

这些标记用来选择下一步，而不是要求一次全部打勾：

- 题意和过程还说不清：继续理解，不急着记为 L。
- 看懂答案却写不出：练空白重写，补足 S。
- 当天能写，隔一段时间就忘：安排间隔重写，检查 R。
- 算法能写，输入输出仍卡住：对适合的题练完整程序，补足 A。

例如两数之和在第 02 章学习推导，在第 03 章独立写，在第 04 章做完整程序，到了本章再混合抽题。移动零先理解返回新列表与修改原列表，再消除额外空间。重复出现有不同的训练目标，不是把同一答案抄四遍。

## 2. 扩展时按知识关系选择，不按题号机械推进

第一遍可以按几个阶段推进：

1. **先把数据操作写熟。** 练基础容器应用、线性扫描、栈和队列。
2. **再处理连接与搜索。** 从链表连接进入递归、树、图搜索和回溯。
3. **继续练状态选择。** 学习堆与 Top K、贪心、动态规划，再进入综合难题。

这不是严格锁死的时间表。已熟悉的专题可以并行，但不要为了完成题单，跳过理解解法所必需的前提。

> ⚠️ 认识树节点，不等于已经会遍历树。做中序遍历、最大深度或岛屿搜索之前，还要能解释递归怎样返回、访问标记何时更新。映射表中的结构准备与实际解题前提要分开看。

第一次接触新模式，可以先看最小讲解，手工追踪，再关掉重写。第二道同类题逐步减少提示。

卡住时，先定位具体问题：是没读懂题意，不会某个语言操作，还是不知道状态怎样更新？例如循环都能写，却无法解释 `left` 何时移动，就应补窗口状态，而不是重新背一遍全部 Python 语法。

## 3. 补齐跨专题连接：题目为什么会同时用到两种工具

### 3.1 区间合并：排序给扫描建立前提

**任务：** 合并重叠的闭区间。约定每个区间的起点不大于终点，端点相接也算重叠。输入可以为空，函数不修改原输入。

例如 `[[1, 3], [2, 6], [8, 10]]` 应得到 `[[1, 6], [8, 10]]`。

处理分为两步：

1. 按左端点排序，让之后的区间不会出现在已处理区间的左边。
2. 依次扫描，只比较当前区间和最后一段合并结果。能合并就延长末端，不能合并就增加一段。

```python
def merge_intervals(intervals):
    def start_of(interval):
        return interval[0]
    ordered = sorted(intervals, key=start_of)
    merged = []
    for start, end in ordered:
        if not merged or start > merged[-1][1]:
            merged.append([start, end])
        else:
            merged[-1][1] = max(merged[-1][1], end)
    return merged

intervals = [[1,3], [2,6], [8,10]]
assert merge_intervals(intervals) == [[1,6], [8,10]]
assert intervals == [[1,3], [2,6], [8,10]]
assert merge_intervals([[1,4], [4,5]]) == [[1,5]]
assert merge_intervals([]) == []
```

先按左端点排好以后，后来的区间不可能跑到已处理区间的更左边。所以当前区间若还会重叠，只需要和最后一个合并结果比较，不必回头检查全部历史。

这个样例的扫描过程是：

| 当前区间 | 判断 | merged 的结果 |
|---|---|---|
| [1, 3] | 还没有结果，加入第一段 | [[1, 3]] |
| [2, 6] | 起点 2 不大于上一段终点 3，合并 | [[1, 6]] |
| [8, 10] | 起点 8 大于上一段终点 6，新增一段 | [[1, 6], [8, 10]] |

合并时取两个终点的最大值，是为了处理“新区间完全包含在上一段内”的情况，不能把终点直接改成当前的 end。

> ⚠️ 代码重新创建 `[start, end]`，没有直接把输入里的小列表加入结果。否则修改结果的终点时，可能连带改掉原输入。

排序与扫描合计时间为 O(n log n)，额外存储为 O(n)。本题明确端点相接算重叠，所以开始新段的条件是 `start > merged[-1][1]`，不是 `>=`。

### 3.2 位运算应用：把相同项抵消

计数字典当然能找出只出现一次的数字。不过本题有更强的保证：其余数字不是任意重复，而是**恰好出现两次**。这时可以认识一个刚好有用的运算：异或 `^`。

异或按二进制位运算，每一位独立比较：

| 两个对应位 | 结果位 |
|---|---:|
| 相同：0 和 0，或 1 和 1 | 0 |
| 不同：0 和 1，或 1 和 0 | 1 |

例如 `5 ^ 3`，将二进制 `101` 与 `011` 对齐，逐位得到 `110`，也就是十进制 6。

> ⚠️ `^` 表示异或，不是乘方。Python 的乘方运算符是 `**`。

本题只需要理解两条性质：

- `x ^ x` 得到 0：相同数字的每一位都相同，因此全部抵消。
- `x ^ 0` 得到 x：与 0 异或不会改变原来的位。

异或还允许交换、结合运算顺序。因此相同数字即使不相邻，也能在整体计算中抵消，留下只出现一次的数字。

**任务：** 非空整数列表中，只有一个数字出现一次，其余数字恰好出现两次。`[4, 1, 2, 1, 2]` 返回 4。

计数字典可以解决这个问题。下面利用“其余数字都成对”的保证，只保留一个累积异或结果。

```python
def single_number(nums):
    answer = 0
    for x in nums:
        answer ^= x
    return answer

assert single_number([4,1,2,1,2]) == 4
assert single_number([-2,1,1]) == -2
```

`answer ^= x` 就是把 `answer ^ x` 的结果重新交给 answer。虽然输入不相邻，两个 1、两个 2 仍能凭交换与结合性质配对抵消，最后留下 4。

> ⚠️ 这个做法依赖“其他数字恰好出现两次”。出现三次时，相同数字不能全部抵消，不能照搬这段代码。

按常见整数成本模型，时间为 O(n)，额外空间为 O(1)。Python 极大整数的位长还会影响实际运算成本。

### 3.3 一个陌生工具出现时，只学习当前需要的部分

例如要列出不超过 n 的正完全平方数。`n = 10` 时，候选是 1、4、9，下一项 16 已经太大。

这里需要确定的是“候选根最大可以是多少”。`math.isqrt(n)` 返回不超过 n 的平方根的最大整数，要求 n 是非负整数。本例返回 3，因此只枚举 1 到 3。

```python
import math

n = 10
limit = math.isqrt(n) # 3：最大的整数 r，使 r*r 不超过 n
squares = [x * x for x in range(1, limit + 1)]
print(squares)        # [1, 4, 9]
```

`range(1, limit + 1)` 提供候选根，推导式把每个根平方，得到 `[1, 4, 9]`。

这个工具只确定枚举范围。如果题目还要求“最少用几个平方数凑成 n”，仍需要另外设计求解过程，不能把生成候选当成已经解完题。

## 4. 专题复习要回答共同问题，不是背同一段代码

复习同类题时，使用同一组问题比较它们：

| 专题 | 要能回答的问题 |
|---|---|
| 哈希 | 下一步查询什么历史，字典的键和值分别是什么？ |
| 双指针 | 两个位置各表示什么，移动为什么不会漏解？ |
| 窗口 | 什么时候不合法，怎样恢复合法？ |
| 二分 | 有序性来自哪里，这轮排除哪段候选？ |
| 搜索 | 当前状态和邻居是谁，何时标记，返回什么？ |
| 动态规划 | 每个状态表示什么，依赖哪些已经求出的状态？ |

可以拿最熟悉的一题做对比：两数之和用字典，和为 K 的子数组也用字典，但前者存下标，后者存前缀次数。一样的容器不等于一样的状态。这类比较把题目连成知识网络，而不是用专题标题替你选择答案。

## 5. 混合抽题：去掉目录提示以后还能否开始

从已经学过的题里随机选少量题，遮住专题标签，依次做：

1. 复述题意和约束，手算样例。
2. 给出一个朴素解，指出其中的重复工作。
3. 说明准备保存什么状态，为什么这样能减少工作。
4. 写代码并测试，再与自己的解释核对。

卡住时记录具体缺口。没能定义窗口状态，应补这个定义，不必靠新增更多陌生题来绕开它。

短解题卡只需保留四组信息：

- 题号、输入输出和关键约束。
- 朴素做法、瓶颈和优化依据。
- 状态含义、更新规则和最终复杂度。
- 易错边界，以及 L、S、A、R 的实际状态。

记录的是下次怎样重建解法，不是再复制一份完整题解。

看过题解以后，先关掉重写，再检查普通、最小和容易混淆的输入。之后安排一次间隔重写，观察还记得的是状态依据，还是只记得代码外形。

> ⚠️ 一边看答案一边补完代码，不能据此记为独立实现。复习间隔可以按遗忘情况调整，不必机械套用固定天数。

## 6. Hard 与组合题：拆解前置知识，避免卡死主线

难题经常把几种已学能力组合起来。先检查对应前提：

| 题目 | 开始之前应能解释 |
|---|---|
| 42 接雨水 | 双指针如何排除候选，或单调栈如何确定边界 |
| 76 最小覆盖子串 | 窗口中的需求计数，何时扩展、何时收缩 |
| 25 K 个一组翻转链表 | 怎样安全地重连一段链表 |
| 124 二叉树最大路径和 | 向父节点返回的路径，与整棵树的最佳答案有什么区别 |
| 84 柱状图中最大的矩形 | 单调栈怎样找到左右边界 |
| 4 寻找两个正序数组的中位数 | 每次二分能排除什么、为什么 |
| 72 编辑距离 | 二维状态表示什么，操作对应哪种转移 |

可以分三个目标完成一题：

1. 读懂问题，能说明朴素解怎样做、为什么成本高。
2. 理解优化依据，能手工推演关键状态。
3. 关掉答案，重建实现并验证。

没有第一次独立想到最优解，不代表前两步毫无价值。但只读懂说明，也不能直接标记为 S。

其他综合题可以从[映射表](../hot100-map.md)进入，但使用技巧前仍要读清约束。

> ⚠️ 例如，多数元素投票法得到的是候选。只有题目保证多数元素存在时，才可直接把候选当答案。把数组转成带环的连接关系，也依赖值域与下标范围满足相应条件。不能只根据题名决定套什么代码。

## 7. 哪些题值得改成完整程序

优先选择输入能直接表达为数值、数组、字符串、矩阵或边列表的题。比如最大子数组和、合并区间、螺旋矩阵、岛屿数量和爬楼梯。

改写时多承担三个责任：

1. 明确输入协议，例如第一行是长度、第二行是数组。
2. 把读到的文字解析成算法需要的数据。
3. 按规定输出结果，而不是只返回给平台。

> ⚠️ 复杂链表、树节点，以及 LRU、Trie 这类交互式结构题，不必为练习输入输出额外设计一套复杂序列化。先明确本次训练目标，避免把大量时间花在无关的输入构造上。

## 8. 本章小结与面试怎么答

专题是复习导航，不是选择答案的依据。拿掉题目标签以后，还能从输入条件推出朴素做法、看到重复工作、定义需要保存的状态，才算把题目转成了能力。

**问：两道题都使用字典，为什么不能说它们是同一种解法？**

> 🎯 要看字典保存什么和下一步查询什么。两数之和存数字到下标，前缀和计数存前缀值到次数。容器相同，状态含义、更新时机与正确性依据可能不同。

## 9. ⚠️ 容易混淆的地方

- 看过题解不等于独立实现；一次 AC 也不代表隔一段时间仍能重建。
- 某个技巧成立依赖输入保证。异或抵消要求其他数字成对，不能只记题目关键词。
- 新方法无需为了“基础完整”全部提前学；当前任务用到的输入、结果、边界要解释清楚。

## 10. 章节自测与复写

**练习：** 从两数之和、无重复子串、爬楼梯中任选两道，关掉正文，依次完成：

1. 写出约束、朴素解和最终状态定义。
2. 实现代码，准备三个能检查不同情况的测试。
3. 从中选一道，改写成完整输入输出程序。

<details><summary>查看验收要点</summary>

- **两数之和：** 不能重复使用同一下标，字典先查再记录。
- **无重复子串：** 要求连续，遇到重复可能需要收缩多次。
- **爬楼梯：** n 为正整数，先说明每个状态代表的方法数，再讨论空间压缩。

> ⚠️ 三个样例通过，不意味着全部边界和复杂度自动正确。还要说明为什么你的状态更新适用于题目允许的输入。

</details>

整套 Hot100 的目标是映射表中每题知道问题与思路，大多数基础和中等题能独立重写，代表题隔一段时间仍能分析，适合的题能完成完整程序。不要把每题背下最短代码设为唯一标准。

通过本章后应从“这题我见过吗”转向“问题要求什么、最直接怎么做、重复工作在哪里、状态与成本是否符合约束”。这才是进入在线笔试的准备。

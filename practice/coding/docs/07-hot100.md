# 07｜Hot100 综合训练：把专题知识变成可调用能力

[← 上一章：算法推导](06-problem-solving-and-algorithms.md) · [Coding 首页](../README.md) · [100 题映射](../hot100-map.md) · [下一章：在线笔试 →](08-online-assessment.md)

> 前六章建立执行、容器、练习、输入输出、数据结构和算法模型。本章不另建 100 份题解，而是补足专题之间的连接、明确练习顺序，并检验脱离目录提示后能否自己选择方法。题目集合沿用映射表注明的快照，不把外部题量当作永久事实。

## 1. 怎样把“介绍过”与“掌握了”分开

每题保留四种状态：L 是读懂题意和解法，S 是关掉答案独立实现并通过，A 是适合的题完成完整输入输出，R 是隔一段时间再遇到仍能分析和重写。它们衡量的不是同一件事，不能仅用一个“做过”替代。

例如两数之和在第 02 章学习推导，在第 03 章独立写，在第 04 章做完整程序，到了本章再混合抽题。移动零先理解返回新列表与修改原列表，再消除额外空间。重复出现有不同的训练目标，不是把同一答案抄四遍。

## 2. 第一遍按依赖解锁，不按题号机械推进

推荐路线是基础容器应用 → 线性扫描状态 → 栈/队列 → 链表连接 → 递归与树 → 图搜索 → 回溯 → 堆/Top K → 贪心/DP → 综合难题。已熟悉的专题可并行，未学前置知识的题不因为在 Hot100 里就强行提前。

第 05 章的树节点和图表示属于结构准备，不代表读者已经能完成树遍历和岛屿搜索。94、104、226、102、200 等题的实际实现应在第 06 章递归与搜索之后。映射表区分这种“结构接触”与“解题解锁”，避免只给一个含糊的首次出现位置。

第一次接触新模式可以看最小讲解、手工追踪，再关掉重写。第二道同类题逐步减少提示。遇到卡点先区分是题意、语言操作、结构选择、状态定义还是边界，而不是统一归因于“算法不行”。

## 3. 补齐跨专题连接：题目为什么会同时用到两种工具

### 3.1 区间合并：排序给扫描建立前提

**任务：** 合并闭区间，端点相接也视为重叠；输入允许为空，不修改原输入。[[1,3],[2,6],[8,10]] 应得到 [[1,6],[8,10]]。

```python
def merge_intervals(intervals):
    def start_of(interval):
        return interval[0]
    ordered = sorted(intervals, key=start_of)
    merged = []
    for start, end in ordered:
        if not merged or start > merged[-1][1]:
            merged.append([start, end])
        else:
            merged[-1][1] = max(merged[-1][1], end)
    return merged

intervals = [[1,3], [2,6], [8,10]]
assert merge_intervals(intervals) == [[1,6], [8,10]]
assert intervals == [[1,3], [2,6], [8,10]]
assert merge_intervals([[1,4], [4,5]]) == [[1,5]]
assert merge_intervals([]) == []
```

sorted、key、解包、[-1]、append 都在第 02 章学过，新增的是排序后只需比较最后一个已合并区间。新建 [start,end] 避免后续修改通过共享内部列表影响原输入。复杂度 O(n log n) 时间、O(n) 额外存储；若题目采用半开区间，端点相接的规则必须重新确认。

### 3.2 位运算应用：把相同项抵消

第 01 章数值工具部分已经给出整数位运算。本例只使用异或 ^：相同位相异为 1，相同为 0，因而 x^x=0、x^0=x；交换和结合顺序不改变结果。

**任务：** 一个数字出现一次，其余数字恰好出现两次。nums=[4,1,2,1,2] 返回 4。计数字典版本已经在第 03 章完成，此处在更强输入保证下减少额外空间。

```python
def single_number(nums):
    answer = 0
    for x in nums:
        answer ^= x
    return answer

assert single_number([4,1,2,1,2]) == 4
assert single_number([-2,1,1]) == -2
```

这一技巧依赖“其他数字恰好成对”，不是任何“找唯一值”的通用模板。时间 O(n)，按常见定宽整数成本模型额外空间 O(1)；Python 大整数的位长仍影响实际位操作成本。

### 3.3 数学工具：按任务查，而不是只背 import

```python
import math

print(math.gcd(18, 24))    # 6：最大公约数
print(math.isqrt(10))      # 3：非负整数平方根向下取整
print(math.comb(5, 2))     # 10：组合数量
```

这些是标准库模块中的函数，传入的参数要符合定义。精确整数任务不要先转浮点再凭小数近似恢复；需要更多数学工具时，以具体任务及官方文档为依据，不在笔试章节突然列一排没有例子的导入。

## 4. 专题复习要回答共同问题，不是背同一段代码

哈希问“下一步反复查询什么历史”；双指针问“两个位置表示什么，移动为何不漏答案”；窗口问“何时恢复合法，为什么只能向前”；二分问“排除的是哪段，单调性来自哪里”；搜索问“状态、邻居、访问标记和返回值分别是什么”；DP 问“每格表示什么，依赖哪些更小状态”。

可以拿最熟悉的一题做对比：两数之和用字典，和为 K 的子数组也用字典，但前者存下标，后者存前缀次数。一样的容器不等于一样的状态。这类比较把题目连成知识网络，而不是用专题标题替你选择答案。

## 5. 混合抽题：去掉目录提示以后还能否开始

从已经学习的题里随机选少量题，不先看专题标签。先复述约束、手算样例、给朴素解，再说明瓶颈与优化方向，最后写代码。做不出来时定位缺口，不以不断新增陌生题掩盖基础不熟。

每题只保留一张短卡：题号、输入输出约束、朴素解和复杂度、瓶颈、优化依据、状态或不变量、最终复杂度、最容易错的边界、L/S/A/R 状态。记录的是“下次怎样重建”，不是复制完整题解。

看题解后必须关掉重写，至少检查普通、最小和容易混淆的输入。第二天复述，隔几天空白重写，再隔更久混合抽题，是可选的复习节奏；不把固定天数当作人人都适合的学习定律。

## 6. Hard 与组合题：拆解前置知识，避免卡死主线

42 接雨水先有双指针或单调栈，76 最小覆盖先有窗口与需求计数，25 分组翻转先能重连一段链表，124 最大路径和先理解递归返回“能向父节点延伸的路径”和全局答案的区别，84 最大矩形先理解单调栈边界，4 中位数先理解二分排除理由，72 编辑距离先定义二维 DP 状态。

可以分成理解问题与朴素边界、理解优化依据、关掉答案重建实现三个目标。不能第一次未独立发明最优解就认定整条路线失败，也不能只读过说明就标成 S。

其他综合技巧如 169 多数元素、75 颜色分类、31 下一个排列、287 寻找重复数，在[映射表](../hot100-map.md)中逐题查看约束。只有题目保证多数元素存在，投票候选才可直接当答案；只有值域与下标关系符合条件，环检测等结构化转化才成立。题意条件不是可以省略的装饰。

## 7. 哪些题值得改成完整程序

数组、字符串、矩阵、网格、图、二分、贪心与数值 DP 通常适合。例如 53、56、54、3、200、207、70、322 可以自己定义明确输入协议，再实现 parse → algorithm → output。

复杂链表和 TreeNode 构造、LRU、Trie 等题不强制额外设计序列化。ACM 改写训练输入输出责任，不应该让输入构造盖过当前算法目标。

## 8. 练习与验收

**练习：** 从两数之和、无重复子串、爬楼梯中任选两道，不查看正文，分别写约束、朴素解、状态定义、代码和三个测试。完成后再选一道改成第 04 章的完整输入输出形式。

<details><summary>查看验收要点</summary>

两数之和不能重复使用同一下标，字典先查再记录。无重复子串要区分子串与子序列，遇重复可能收缩多次。爬楼梯先定义状态与正整数范围，再讨论压缩。测试覆盖正确样例不意味着复杂度和输入边界自动正确。

</details>

整套 Hot100 的目标是映射表中每题知道问题与思路，大多数基础和中等题能独立重写，代表题隔一段时间仍能分析，适合的题能完成完整程序。不要把每题背下最短代码设为唯一标准。

通过本章后应从“这题我见过吗”转向“问题要求什么、最直接怎么做、重复工作在哪里、状态与成本是否符合约束”。这才是进入在线笔试的准备。

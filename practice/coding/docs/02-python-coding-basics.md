# 02｜数据类型与容器：给数据选一个合适的组织方式

[← 上一章：程序基础](01-programming-fundamentals.md) · [Coding 首页](../README.md) · [下一章：基础练习 →](03-basic-exercises.md)

只有一个成绩时，写 `score = 90` 就够了。如果有全班同学的成绩呢？如果还要通过姓名查成绩，或者只问“这个人是否已经签到”，同一种保存方式还方便吗？

**容器是组织数据的办法，选择取决于你需要保存什么关系。** 这一章会用到的五种类型，各有一个最直观的用途：

| 需要保存什么 | 适合先考虑的类型 |
|---|---|
| 按顺序排列的成绩 | `list`，列表 |
| 行号和列号这样的一组固定位置 | `tuple`，元组 |
| 姓名等文字 | `str`，字符串 |
| 姓名对应的成绩 | `dict`，字典 |
| 哪些人已经签到 | `set`，集合 |

这一章围绕这些常见任务，练习后续编程中反复要用的操作。每种容器先学清楚自己最重要的用法，再把它们组合起来解决两数之和、移动零和分组问题。目标是见到数据就知道如何下手，不是记完 Python 的方法目录。

## 1. 读一行操作时，分开看“改了什么”和“得到什么”

看一行容器操作时，需要区分三个问题：

1. **原来的对象变了吗？** 例如，`nums.append(3)` 会向原列表追加一个元素。
2. **这个操作返回什么？** 例如，`len(nums)` 返回元素数量，`append` 返回 `None`，不返回追加后的列表。
3. **屏幕上显示了什么？** 普通脚本中，上面两种操作本身都不会打印，需要用 `print` 显示结果。

函数和方法的调用形状也不同：`len(nums)` 是把列表传给函数；`nums.append(3)` 是通过列表对象调用它的方法。

> ⚠️ 有没有点号，不能用来判断操作是否修改数据。要看操作的具体含义。例如，有的方法修改原对象，也有的方法返回新对象。

下面每个例子都给出初始数据。代码右侧的注释会说明返回值或执行后的状态；真正要在屏幕上看到它，仍需要 `print`。

## 2. list：把一组数据按顺序放好

假设三次练习的得分依次是 10、20、30。你既关心分数，也关心它们出现的顺序，就可以用列表保存：

```python
nums = [10, 20, 30]
print(len(nums))    # 3：一共有三个元素
print(nums[0])      # 10：第一个元素
print(nums[1])      # 20：第二个元素
print(nums[-1])     # 30：最后一个元素
print(20 in nums)  # True：值 20 在列表里
```

方括号里放各个元素，逗号负责分开它们。**下标从 0 开始**，所以长度为 3 的列表，合法非负下标是 0、1、2；访问 `nums[3]` 就会越界。

`20 in nums` 问的是“值 20 是否在列表里”，不是“下标 20 是否合法”。

空列表写成 `[]`。当列表本身用作条件时：

- 空列表按假处理，所以 `if nums:` 不进入分支。
- 非空列表按真处理，所以 `if nums:` 进入分支。

> ⚠️ `[0]` 也是非空列表。这里检查的是有没有元素，不是元素本身是不是 0。

### 2.1 要一个元素，还是要连续的一段

下标取得一个元素，**切片**取得一段位置上的元素，组成新列表：

```python
nums = [10, 20, 30, 40]
print(nums[1:3])   # [20, 30]：包含位置 1，不包含位置 3
print(nums[:2])    # [10, 20]：从开头取到位置 2 之前
print(nums[2:])    # [30, 40]：从位置 2 取到末尾
print(nums[::-1])  # [40, 30, 20, 10]：反向构造新列表
```

可以把 `nums[1:3]` 想成“从位置 1 开始，在到达位置 3 前停下”。左边包含、右边不包含，与 `range` 的终点规则相呼应。

切片的完整形式是 `nums[start:stop:step]`：

- `start` 是开始位置。
- `stop` 是停止位置，不包含在结果中。
- `step` 是步长，省略时为 1。`nums[::2]` 每次前进两个位置，`nums[::-1]` 则从后往前取。

切片得到新列表，不修改原列表。有时选不到任何项，结果就是空列表。

> ⚠️ 单个下标和切片的边界行为不同。`nums[99]` 可能越界报错，`nums[:99]` 则只会取到实际末尾。不要把“切片能运行”当作某个下标一定合法。

### 2.2 改一个值、添一个值、取走一个值

列表可以修改。下面依次完成三个动作：把第二次成绩改成 99，追加新成绩 40，再取走最后追加的成绩。

```python
nums = [10, 20, 30]
nums[1] = 99           # nums 变成 [10, 99, 30]
result = nums.append(40) # nums 变成 [10, 99, 30, 40]
print(result)          # None：append 不返回列表
last = nums.pop()      # last = 40；nums 变回 [10, 99, 30]
print(last, nums)      # 40 [10, 99, 30]
```

对照每个操作看结果：

| 操作 | 原列表发生什么变化 | 得到什么结果 |
|---|---|---|
| `nums[1] = 99` | 第二项被替换 | 这是赋值语句 |
| `nums.append(40)` | 末尾多出一个 40 | 返回 `None` |
| `nums.pop()` | 最后一项被删除 | 返回删除的值 40 |

> ⚠️ 不要写 `nums = nums.append(40)`。右边返回 `None`，这会让名字 `nums` 关联到 `None`，而不是追加后的列表。

删除时还要分清“按位置”与“按值”：

```python
nums = [10, 20, 30, 20]
first = nums.pop(0)  # 返回 10，nums 变成 [20, 30, 20]
nums.remove(20)      # 删除第一个值为 20 的元素，nums 变成 [30, 20]
print(first, nums)   # 10 [30, 20]
```

`pop(0)` 按位置删除，并返回被取走的值。`remove(20)` 按值删除，只删除从前往后遇到的第一个 20。

> ⚠️ 空列表执行 `pop()` 会报错，`remove` 找不到指定值也会报错。需要过滤多个元素时，先构造新列表更容易追踪；边遍历边删除会移动后续位置，可能跳过元素。

一次加入多个元素时，另一个常用区别是“整体加入”还是“逐项加入”：

```python
a = [1]
a.append([2, 3])  # [1, [2, 3]]：把整个列表当成一个元素
b = [1]
b.extend([2, 3])  # [1, 2, 3]：把来源里的元素逐个加到末尾
print(a, b)       # [1, [2, 3]] [1, 2, 3]
```

### 2.3 遍历：要值、要下标，还是两者都要

如果只是逐个处理分数，直接取得元素值最自然：

```python
nums = [10, 20, 30]
for x in nums:
    print(x)             # 10、20、30，各一行
for i in range(len(nums)):
    print(i, nums[i])     # 0 10、1 20、2 30，各一行
```

这两种写法得到的信息不同：

- `for x in nums`：`x` 直接接收元素值 10、20、30。
- `for i in range(len(nums))`：`i` 接收下标 0、1、2，再用 `nums[i]` 取得值。

> ⚠️ 循环变量叫 `i`，不代表它一定是下标。写 `for i in nums` 时，`i` 接收的仍是元素值。

同时需要下标和值时，可以使用 `enumerate`。不过先看懂一对数据怎样分给两个名字，这个动作叫**解包**：

```python
i, x = [0, 10]  # 第一项交给 i，第二项交给 x
print(i, x)     # 0 10

nums = [10, 20, 30]
for i, x in enumerate(nums):
    print(i, x) # 0 10、1 20、2 30，各一行
```

`enumerate(nums)` 默认从 0 开始编号，每次提供一对“编号、元素值”。`for i, x in ...` 再把这对数据解包：第一项交给 `i`，第二项交给 `x`。

第一轮可以展开为：取得 `(0, 10)`，让 `i = 0`、`x = 10`，再执行循环体。下一轮取得 `(1, 20)`，重复同样的动作。

只需要值时用普通遍历，同时需要下标和值时用 `enumerate`。不必为了用某种写法，额外制造一个不需要的变量。

### 2.4 排序：拿一份新结果，还是改变原顺序

把分数从小到大排好时，先问：原来的时间顺序还需要保留吗？

```python
nums = [3, 1, 2]
ordered = sorted(nums)   # 返回新列表 [1, 2, 3]
print(nums, ordered)     # [3, 1, 2] [1, 2, 3]
returned = nums.sort()   # 原列表变成 [1, 2, 3]
print(nums, returned)    # [1, 2, 3] None
```

两种排序方式的区别是：

- `sorted(nums)`：返回排好序的新列表，原列表不变。
- `nums.sort()`：在原列表上排序，返回 `None`。

两者默认升序排列，也都可以用 `reverse=True` 指定降序。

> ⚠️ 需要保留原顺序时，不能直接对原列表调用 `.sort()`。先确认题目是否允许修改输入。

**反转不等于降序排序。** `reverse` 只把已有顺序倒过来。例如，`[3, 1, 2]` 反转后是 `[2, 1, 3]`，不是 `[3, 2, 1]`。

下面同时对照反转、降序排序和简单汇总的结果：

```python
nums = [3, 1, 2]
nums.reverse()          # nums 变成 [2, 1, 3]，不是降序排序
print(nums)             # [2, 1, 3]
print(sorted(nums, reverse=True)) # [3, 2, 1]
print(sum(nums))        # 6：求和
print(min(nums), max(nums)) # 1 3：最小值与最大值
```

`sum` 求和，`min` 和 `max` 分别取最小值、最大值。这些读取操作不会修改列表。

> ⚠️ `sum([])` 为 0，但没有指定默认值时，`min([])` 和 `max([])` 会报错。排序和极值比较还要求元素能够比较大小，整数与字符串不能直接混在一起作这样的比较。

当“排序依据”不是元素本身时，`key` 可以接收一个函数。下面按绝对值排，比较依据依次是 3、1、2，但结果保留原来的数字：

```python
nums = [-3, 1, -2]
print(sorted(nums, key=abs))  # [1, -2, -3]
```

`key=abs` 要传入的是函数本身。排序时，Python 对每个元素调用它，取得比较依据：-3 对应 3，1 对应 1，-2 对应 2。

依据从小到大是 1、2、3，所以原元素按 1、-2、-3 排列。**`key` 改变比较依据，不会把结果里的元素替换成依据值。**

> ⚠️ 这里写 `abs`，不是 `abs()`。前者把函数交给排序操作，后者是在当前位置立即调用函数，而且还缺少必需的参数。

### 2.5 构造结果：先会循环，再看推导式

从 `[1,2,3,4]` 里挑偶数，并把它们平方，最直白的过程是：取出一个值，判断，符合要求才加入结果。

```python
nums = [1, 2, 3, 4]
result = []
for x in nums:
    if x % 2 == 0:
        result.append(x * x)
print(result)  # [4, 16]
```

把同一个过程压在一行，就是列表推导式：

```python
nums = [1, 2, 3, 4]
result = [x * x for x in nums if x % 2 == 0]
print(result)  # [4, 16]
```

列表推导式可以按执行顺序读：

1. `for x in nums`：取出下一个元素。
2. `if x % 2 == 0`：判断是否保留它。
3. `x * x`：对保留的元素计算平方，放入结果列表。

代码虽然把 `x * x` 写在最前面，执行时仍要先取到 `x`、检查条件。

> ⚠️ 看不清紧凑写法时，先用普通循环。推导式只是同一过程的另一种表达，不是必须优先使用的写法。

### 2.6 复制与二维列表：为什么两处会一起变

前一章改变量 x，并不会把 old 一起改掉。但两个名字指向同一个列表时，修改列表会被它们共同观察到：

```python
nums = [1, 2]
alias = nums        # 不是复制，只是另一个名字指向同一列表
saved = nums.copy() # 新建一个外层列表
alias.append(3)
print(nums)         # [1, 2, 3]
print(saved)        # [1, 2]
```

先区分这里的两种关系：

- `alias = nums`：没有创建新列表。两个名字指向同一个对象，通过任何一个名字修改它，另一个名字也会观察到变化。
- `saved = nums.copy()`：创建一个新的外层列表，所以本例向原列表追加 3，不会改变 `saved`。

`copy()` 做的是**浅拷贝**，只保证外层新建，内部对象仍可能共享。`==` 比较内容是否相等，`is` 比较是否为同一个对象。

矩阵就是“列表里面还有列表”，两个下标分别取行和列：

```python
grid = [[1, 2, 3], [4, 5, 6]]
print(grid[0])     # [1, 2, 3]：第一行
print(grid[0][1])  # 2：第一行的第二个元素
```

初始化矩阵时，有一个与共享对象直接相关的坑，值得在这里弄懂：

```python
bad = [[0, 0]] * 2          # 两个位置引用的是同一行
bad[0][0] = 9
print(bad)                  # [[9, 0], [9, 0]]
good = [[0, 0] for _ in range(2)] # 每轮新建一行；_ 表示不用的循环变量
good[0][0] = 9
print(good)                 # [[9, 0], [0, 0]]
```

> ⚠️ `[[0, 0]] * 2` 重复保存的是同一行的引用，不是两份独立行。需要每行独立，就像 `good` 那样，在每一轮中创建新行。`[0] * 3` 用于保存三个整数零，不存在同样的可变行共享问题。

## 3. tuple：把几个位置的含义固定下来

坐标中的 3 表示行、5 表示列。它们是一个整体，却不是准备不断追加成绩的列表。这样的固定组合可以用元组表示：

```python
point = (3, 5)
print(point[0], point[1])  # 3 5
row, col = point          # row=3，col=5：与列表一样按位置解包
print(row, col)           # 3 5
single = (3,)             # 只有一项也要有逗号；(3) 只是整数 3
print(type(single))       # <class 'tuple'>
```

元组的读取方式与列表相通，可以使用 `len`、下标、切片、`in` 和普通 `for`。

关键区别是**元组不可变**：创建后不能把某个位置替换成别的值，也没有 `append` 这样的追加方法。坐标采用元组，表达的是“这几个位置合起来是一条记录”，而不是一个不断增减的队列。

解包也常见于交换变量和函数返回多个结果：

```python
a, b = 2, 5
a, b = b, a              # 先得到右侧两个旧值，再分别写到左侧
print(a, b)              # 5 2

def bounds(nums):
    return min(nums), max(nums) # 返回一对结果

low, high = bounds([3, 1, 5])
print(low, high)         # 1 5
```

交换变量时，右侧先取得旧的 `b` 和旧的 `a`，然后再分别赋给左侧。因此两个旧值都保留了下来。

> ⚠️ 先写 `a = b`，再写 `b = a`，第二行读到的已经不是旧 `a`，不能完成交换。普通解包还要求变量数量与数据项数匹配，否则会报错。

需要转换类型时，`list(point)` 得到新列表，`tuple([3, 5])` 得到元组。

> ⚠️ 元组不可变，不代表它引用的每个内部对象也不可变。元组里如果放着一个列表，不能替换这个位置，但仍可能修改那个列表的内容。

## 4. str：按顺序读文字，再构造需要的文字

字符串也有顺序，因此已经学会的下标、切片和遍历，不必重新理解一遍。只是每次取出的不是分数，而是一个字符。

```python
text = "hello"
print(len(text))      # 5
print(text[0])        # h
print(text[1:4])      # ell
print(text[::-1])     # olleh
print("ell" in text) # True：这里检查一段子串是否出现
for ch in text:
    print(ch)         # h、e、l、l、o，各一行
```

空字符串写作 `""`。字符串不可变，不能通过 `text[0] = "H"` 修改它。要把 hello 变成 Hello，应当构造新字符串：

```python
text = "hello"
changed = "H" + text[1:] # 用 H 接上后面的 ello
print(changed)           # Hello
print(text)              # hello：原字符串没有改变
```

这就是字符串与列表在“修改”上的区别。`+` 用于拼接新文字，而不是修改某个字符的位置。

### 4.1 split：一整行怎样变成几项

输入常常是一行文字 `"10 20 30"`，但你想逐个处理其中的数。`split` 先负责拆分，**不会顺便完成数值转换**。

```python
line = "10 20 30"
parts = line.split()
print(parts)             # ['10', '20', '30']
print(type(parts[0]))    # <class 'str'>
print("red,blue".split(",")) # ['red', 'blue']：明确用逗号拆分
```

两种调用分别适合不同格式：

- `.split()` 不带参数：按空白分隔，连续空白作为一处分隔，忽略两端的空白。
- `.split(",")`：明确按逗号分隔。适合 `red,blue` 这样的数据。

> ⚠️ 拆分结果是字符串列表。例如 `"10 20"` 拆成 `["10", "20"]`，不是 `[10, 20]`。需要整数时，仍要对每一项调用 `int()`。

### 4.2 join：几项文字怎样重新连成一项

**`join` 把多个字符串连接成一个新字符串。** 调用方式是 `分隔符.join(各项文字)`，点号前面指定相邻两项之间放什么：

```python
words = ["AI", "coding"]
print(" ".join(words))  # AI coding：中间放一个空格
print("-".join(words))  # AI-coding
print("".join(words))   # AIcoding：不放分隔符
```

对同一个 `words`：

- `" ".join(words)` 在两项中间加入一个空格。
- `"-".join(words)` 在两项中间加入一个连字符。
- `"".join(words)` 不插入分隔字符，直接连接。

> ⚠️ `join` 中的每一项都必须是字符串，不会自动把整数变成文字。需要连接数字时，先用 `str()` 转换各项。

如果想把一个单词的字符按顺序整理，也可以组合排序与拼接：

```python
chars = sorted("tea") # ['a', 'e', 't']：sorted 返回列表
key = "".join(chars)  # 'aet'
print(key)            # aet
```

对 `"tea"`，按下面的顺序处理：

1. `sorted("tea")` 得到新列表 `["a", "e", "t"]`。
2. `"".join(chars)` 把这些字符连接成新字符串 `"aet"`。

`"".join(sorted(word))` 就是把这两步写在一起。先认出内层返回字符列表，再理解外层怎样使用它。

## 5. dict：通过一个键找到对应的信息

名单与成绩若分别放在两个列表里，你还得先找姓名的位置。字典可以直接表达“姓名对应成绩”：

```python
scores = {"Alice": 90, "Bob": 85}
print(scores["Alice"])   # 90
print("Alice" in scores) # True：检查键，不是检查成绩
scores["Bob"] = 88       # 修改 Bob 的值
scores["Carol"] = 95     # 新增一个键及其值
print(scores["Bob"])     # 88
```

字典中的一条记录由键和值组成。例如 `"Alice": 90`：

- 左边的 `"Alice"` 是**键（key）**，用来定位记录。
- 右边的 `90` 是**值（value）**，是这条记录保存的信息。

同一个键只对应一个值。`scores["Bob"] = 88` 覆盖 Bob 的旧成绩，不会再增加第二条同名记录。空字典写成 `{}`。

> ⚠️ `"Alice" in scores` 检查的是键是否存在，不是检查某个成绩是否存在。

基础题里常用整数和字符串作键。字典的值没有相同限制，可以是列表，从而保存“一个特征对应一组单词”这样的关系。

> ⚠️ 字典的键需要可哈希。整数和字符串通常可以直接使用，列表不能。元组也不能一概视为合法键，要看里面的元素是否都可哈希。

### 5.1 可能没有这个键时，怎样读取

**`d.get(key, default)` 按键读取值；键不存在时，返回你提供的默认值。**

直接读不存在的 `scores["Dan"]` 会抛出 `KeyError`。任务允许“没找到就采用某个默认值”时，可以这样写：

```python
scores = {"Alice": 90}
print(scores.get("Alice", 0)) # 90：存在就取原值
print(scores.get("Dan", 0))   # 0：缺失时使用默认值
print("Dan" in scores)       # False：get 没有新增这个键
```

本例中的三个结果分别说明：

1. Alice 存在，读取她原来的成绩 90。
2. Dan 不存在，返回指定的默认值 0。
3. Dan 依然不在字典中，因为 `get` 没有新增记录。

> ⚠️ 默认值只能在任务允许时使用。如果“查不到姓名”应当被视为错误，就不能随意用 0 代替，否则会把缺失误认为真实成绩。

不再需要一条记录时，可以按键删除：

```python
scores = {"Alice": 90, "Bob": 85}
del scores["Bob"]       # 删除 Bob 这一条；不是把成绩改为 0
print(scores)           # {'Alice': 90}
```

`del` 是删除语句，键必须存在。

### 5.2 遍历：只要键、只要值，还是键值都要

先按任务决定需要哪种信息：

- 只看姓名，用 `keys()`，或直接遍历字典。
- 只看成绩，用 `values()`。
- 同时看姓名和成绩，用 `items()`，取得一对对的键和值。

```python
scores = {"Alice": 90, "Bob": 85}
print(list(scores.keys()))   # ['Alice', 'Bob']
print(list(scores.values())) # [90, 85]
print(list(scores.items()))  # [('Alice', 90), ('Bob', 85)]
```

外面的 `list()` 把这些项收集成普通列表，方便观察结果。不需要收集时，可以直接用 `for` 遍历这些方法提供的内容：

```python
scores = {"Alice": 90, "Bob": 85}
for name in scores:
    print(name)          # Alice、Bob，各一行：默认遍历键
for value in scores.values():
    print(value)         # 90、85，各一行
for name, value in scores.items():
    print(name, value)   # Alice 90、Bob 85，各一行
```

最后一种写法的第一轮先取得 `("Alice", 90)`，再解包为 `name = "Alice"`、`value = 90`，最后执行循环体。它复用了前面讲过的解包，不需要额外记一套赋值规则。

> ⚠️ `keys()`、`values()` 和 `items()` 返回的不是普通列表。要按列表下标使用，先转成 `list`。字典按插入顺序遍历，不会自动排序；遍历过程中也不要随意增删键。

### 5.3 计数：让每个字符对应“见过几次”

现在把“姓名 → 成绩”换成“字符 → 次数”，字典就可以统计 banana 中每个字符出现几次。

```python
text = "banana"
count = {}
for ch in text:
    old = count.get(ch, 0) # 以前没见过，就当作 0 次
    count[ch] = old + 1    # 增加一次，再写回
print(count)              # {'b': 1, 'a': 3, 'n': 2}
```

跟踪前四个字符，就能看见计数怎样变化：

| 本轮字符 | `get` 读到的旧次数 | 写回的新次数 | 写回后的 `count` |
|---|---:|---:|---|
| `b` | 0 | 1 | `{'b': 1}` |
| `a` | 0 | 1 | `{'b': 1, 'a': 1}` |
| `n` | 0 | 1 | `{'b': 1, 'a': 1, 'n': 1}` |
| `a` | 1 | 2 | `{'b': 1, 'a': 2, 'n': 1}` |

**无论字符是不是第一次出现，都先取旧次数，再把“旧次数加一”写回。** 默认值 0 让首次出现也能遵循这套步骤。

常见的一行写法 `count[ch] = count.get(ch, 0) + 1`，仍然按同样顺序执行：

1. `count.get(ch, 0)` 取得旧次数。
2. `+ 1` 算出新次数。
3. `count[ch] = ...` 把新次数写入字典。

> ⚠️ `get` 不会替字典加一。真正改变字典的是最后的赋值。

字典还能存位置，关键在于你给值赋予什么含义：

```python
nums = [5, 8, 5]
position = {}
for i, x in enumerate(nums):
    position[x] = i
print(position)  # {5: 2, 8: 1}：这里保存最后一次出现的位置
```

若想保存首次位置，就先检查 x 是否已经是键，已经有了便不要覆盖。写代码之前先说清楚“值代表次数还是下标”，比记住某段模板重要。

## 6. set：只问“有没有见过”

检查签到是否重复时，不一定需要知道每个人出现多少次，也不一定需要保存位置。集合只记录成员是否存在：

```python
seen = set()       # 创建空集合；{} 创建的是空字典
seen.add(10)       # 加入成员 10
seen.add(20)       # 加入成员 20
seen.add(10)       # 重复加入，不会多出一份 10
print(len(seen))   # 2
print(10 in seen)  # True
print(99 in seen)  # False
```

集合记录的是“有哪些成员”，因此有三个特点：

- 同一个成员只保留一份，不记录重复次数。
- 不提供下标，不能写 `seen[0]` 取得“第一个成员”。
- 遍历顺序不作保证，不能依赖某次显示出来的顺序。

> ⚠️ `set([3, 1, 3])` 能去重，但不保证保留首次出现顺序。集合成员还必须可哈希，列表不能直接放入集合。

需要把一个成员移出去时，常用 remove 或 discard：

```python
seen = {10, 20}
seen.remove(10)    # 现在只剩成员 20；10 必须存在
seen.discard(99)   # 99 不存在也不报错
print(20 in seen) # True
```

两者都用于移除成员，区别是成员不存在时的处理：

- `remove(x)`：不存在就抛出 `KeyError`。适合算法已经保证成员存在的情况。
- `discard(x)`：不存在也不报错。适合任务允许“本来就没有这个成员”的情况。

集合可以用普通 `for` 遍历，但不要赋予遍历顺序额外的含义。

把这些操作组合起来，就能判断是否有重复：

```python
def has_duplicate(nums):
    seen = set()
    for x in nums:
        if x in seen:
            return True
        seen.add(x)
    return False

assert has_duplicate([3, 1, 3]) is True
assert has_duplicate([3, 1]) is False
assert has_duplicate([]) is False
```

以 `[3, 1, 3]` 为例：

1. 第一个 3 不在集合中，把 3 加入集合。
2. 1 不在集合中，把 1 加入集合。
3. 第二个 3 已在集合中，说明它之前出现过，返回 `True`。

若走完整个列表都没发现重复，就返回 `False`。

> ⚠️ 必须先查询，再加入。`seen` 保存的是“这轮之前出现的成员”。先加入再查询，会把每个元素都误判成重复。

## 7. 跨容器组合：把已经会的操作接起来

### 7.1 两列数据一一对应时，用 zip 配对

姓名与成绩来自两列，想逐个一起处理，不需要自己同时维护两个下标：

```python
names = ["Alice", "Bob"]
scores = [90, 85]
pairs = list(zip(names, scores))
print(pairs)  # [('Alice', 90), ('Bob', 85)]
for name, score in pairs:
    print(name, score) # Alice 90、Bob 85，各一行
```

这里仍然是两个配合的动作：

1. `zip` 按位置配对，依次得到 `("Alice", 90)` 和 `("Bob", 85)`。
2. 循环头解包，把每一对分别交给 `name` 和 `score`。

> ⚠️ `zip` 默认在较短的一组耗尽时停止。任务要求一一对应时，要先确认两组长度一致，否则较长一组的剩余项不会被处理。

### 7.2 把列表交给函数：改原来的，还是返回新的

```python
def doubled(nums):
    return [x * 2 for x in nums]

def add_zero(nums):
    nums.append(0)

original = [1, 2]
answer = doubled(original)
print(answer, original) # [2, 4] [1, 2]
returned = add_zero(original)
print(original, returned) # [1, 2, 0] None
```

两个函数有不同的约定：

- `doubled` 构造新列表并返回，`original` 保持不变。
- `add_zero` 修改传入的列表，`original` 会多出一个 0，但调用结果是 `None`。

参数 `nums` 与外面的 `original` 可以关联同一个对象，所以通过参数修改这个对象，调用方能够看到。

> ⚠️ 函数内写 `nums = []` 只是让局部名字指向新列表，不等于修改调用方原来的列表，也不会替外面的 `original` 重新赋值。

做题前先确认要求的是哪一种。**“函数没有返回值”不等于“函数没有改变数据”。**

## 8. 两数之和：我真正需要找的是什么

给定 `nums=[2,7,11,15]` 与 `target=9`，返回两个不同下标，使对应的数相加等于 9，结果应为 `[0,1]`。本练习保证存在时只有一组答案，无解时扩展约定返回 `[]`。

最直接的办法是逐对检查。两层循环没有新语法，只是把上一章的编号配对换成通过下标读取数值：

```python
def two_sum_brute(nums, target):
    for i in range(len(nums)):
        for j in range(i + 1, len(nums)):
            if nums[i] + nums[j] == target:
                return [i, j]
    return []

assert two_sum_brute([2, 7, 11, 15], 9) == [0, 1]
assert two_sum_brute([3, 3], 6) == [0, 1]
```

例如，当前读到 7，目标是 9，那么另一个数只能是 `9 - 7 = 2`。不必再逐个试谁能凑成 9，只需要查询两件事：

1. 2 在此前是否出现过？
2. 如果出现过，它的下标是什么？

用字典保存“数字对应此前下标”，就能直接回答这两个问题。

```python
def two_sum(nums, target):
    seen = {}                      # 数字 → 此前出现的下标
    for i, x in enumerate(nums):
        need = target - x
        if need in seen:
            return [seen[need], i]
        seen[x] = i
    return []

assert two_sum([2, 7, 11, 15], 9) == [0, 1]
assert two_sum([3, 3], 6) == [0, 1]
assert two_sum([3], 6) == []
```

| 当前值 | 需要的值 | 查询前的 seen | 接下来做什么 |
|---:|---:|---|---|
| 2 | 7 | {} | 没有 7，记下 2 在位置 0 |
| 7 | 2 | {2: 0} | 找到了 2，返回它的位置 0 与当前位置 1 |

> ⚠️ 查询必须放在记录当前数字之前，否则可能把当前位置使用两次。例如 `[3]`、目标 6，没有两个不同位置，不能返回 `[0, 0]`。

集合只能回答有没有出现，字典还能给出答案所需的下标。

## 9. 移动零：同一个结果，两种交付方式

把 `[0,1,0,3,12]` 中的零放到末尾，非零数字保持原相对顺序，应得到 `[1,3,12,0,0]`。先不追求最省空间，只用熟悉的循环和列表操作完成它。

```python
def move_zeroes_copy(nums):
    result = []
    for x in nums:
        if x != 0:
            result.append(x)
    while len(result) < len(nums):
        result.append(0)
    return result

nums = [0, 1, 0, 3, 12]
assert move_zeroes_copy(nums) == [1, 3, 12, 0, 0]
assert nums == [0, 1, 0, 3, 12]
```

这个版本分两阶段完成：

1. **收集非零数字。** `for` 遇到 0 不追加，遇到 1、3、12 依次追加，得到 `[1, 3, 12]`。
2. **补齐长度。** 原列表长 5，新列表长 3。`while` 追加两个 0，得到 `[1, 3, 12, 0, 0]`。

每次补零都会让新列表长度增加一。长度等于原列表时，条件变为假，循环结束。

如果要求修改原列表，而不是返回新列表，应该把收集到的值写回去：

```python
def move_zeroes_inplace_basic(nums):
    non_zero = []
    for x in nums:
        if x != 0:
            non_zero.append(x)
    k = len(non_zero)
    for i in range(k):
        nums[i] = non_zero[i]
    for i in range(k, len(nums)):
        nums[i] = 0

nums = [0, 1, 0, 3, 12]
assert move_zeroes_inplace_basic(nums) is None
assert nums == [1, 3, 12, 0, 0]
```

这个版本先用 `non_zero` 保存非零数字，再改写原列表：

1. 前 `k` 个位置按顺序写入非零数字。
2. 从位置 `k` 开始，把剩余位置填成 0。

调用方能观察到原对象变化，但函数内部仍创建了额外列表。

> ⚠️ 修改原对象和只用常数额外空间是两个不同要求。这里满足前者，不满足后者。双指针的优化目标，是直接用原列表里的位置记录读写进度，省掉这份中间列表。

## 10. 字母异位词：先找出“同一组”的共同特征

`eat`、`tea`、`ate` 顺序不同，却使用相同的字母。要给单词分组，先问：能不能给同组单词算出一个相同的标记？

把字符排序再拼回字符串，这三个词都会变成 `aet`。于是字典可以保存“标记 → 这一组的单词列表”。下面先限定小写英文字母：

```python
words = ["eat", "tea", "tan", "ate", "nat", "bat"]
groups = {}
for word in words:
    chars = sorted(word)     # 'tea' → ['a', 'e', 't']
    key = "".join(chars)     # → 'aet'
    if key not in groups:
        groups[key] = []     # 第一次遇到这一组，先准备空列表
    groups[key].append(word) # 把原单词加到这一组，不是加入排序后的 key
answer = list(groups.values())
print(answer) # [['eat', 'tea', 'ate'], ['tan', 'nat'], ['bat']]
```

跟踪前两个词：

1. 读到 `eat`，算出标记 `aet`。字典里没有这组，先建空列表，再把原词 `eat` 加进去。
2. 读到 `tea`，标记仍是 `aet`。这次直接找到已有列表，追加原词 `tea`。
3. 处理完所有词后，只需要各组列表，不需要组名，所以用 `groups.values()` 取得这些值，再转成列表。

> ⚠️ 标记 `key` 用来找组，加入组里的应是原单词 `word`，不是排序后的标记。否则结果会丢失原单词。

这几步仍是已学过的排序、拼接、字典查询与列表追加。真正新增的是一种解题思路：**给同类数据构造相同的特征，再按特征聚在一起。**

## 11. 本章小结与面试怎么答

列表记顺序，元组记固定组合，字符串记文字，字典记对应关系，集合记成员。选容器之前先问“下一步最常需要知道什么”，操作时再区分原对象变化、返回值和输出。

两数之和从逐对尝试变成字典查询，也给复杂度一个直观入口：长度为 n 时，逐对检查约有 n(n-1)/2 对，按 O(n²) 增长；一次扫描配合平均 O(1) 的字典查询，平均时间可按 O(n) 估算，但额外保存了 O(n) 的历史信息。这里是常见成本模型，不是承诺任意字典操作都绝对常数时间。

**问：怎样选择 list、dict 和 set？**

> 🎯 需要按顺序或位置组织数据，用 list；需要通过键取得关联信息，用 dict；只关心成员是否存在，用 set。比如保序去重需要同时满足存在性和顺序，可以用 set 判断、list 收集，而不是直接把 set 转回 list。

**问：sorted(nums) 与 nums.sort() 有什么区别？**

> 🎯 sorted 返回新的排序列表，原列表保持不变；sort 修改原列表并返回 None。先确认是否允许改变输入，再选择用法。

## 12. ⚠️ 容易混淆的地方

- 下标和值是两种信息。`for x in nums` 已经取得值，不能再不加判断地拿它当下标。
- `.append()`、`.sort()` 返回 None；`.pop()` 返回取出的值。不要把所有修改方法的返回值都当作新容器。
- `{}` 是空字典，`set()` 才是空集合；集合不保证保留首次出现顺序。
- `get` 只读取；`count[x] = ...` 才写入。一个字典的值是次数还是下标，必须由任务明确。
- 浅拷贝只让外层独立。二维列表和回溯路径等场景，要检查内部可变对象是否仍在共享。

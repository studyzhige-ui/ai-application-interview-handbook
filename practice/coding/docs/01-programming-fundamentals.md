# 01｜程序基础：让 Python 一步一步替你做事

[← Coding 首页](../README.md) · [下一章：数据类型与容器 →](02-python-coding-basics.md)

买两本练习本，每本 12 元，一共多少钱？你大概立刻就能回答：24 元。

但让计算机做这件事，你需要把心里的计算过程写出来：记住单价，记住数量，算出总价，最后把结果显示出来。**编程的起点，就是把“我知道怎么做”变成“计算机能够照着执行的步骤”。**

这一章就从这笔小账出发。我们先看一行代码怎样产生结果，再让程序作判断、重复计算，最后把一个小任务写成可以多次调用的函数。遇到报错也不用绕开：读懂错误信息，本来就是学会编程的一部分。

## 1. 先让 Python 算一笔小账

下面四行就是一个小程序。先读它，不必急着记术语：

```python
price = 12               # 一本练习本的价格
quantity = 2             # 购买数量
cost = price * quantity  # 计算总价，cost 得到 24
print(cost)              # 屏幕显示 24
```

Python 从上到下执行这四行：

1. `price = 12`：让名字 `price` 关联单价 12。
2. `quantity = 2`：让名字 `quantity` 关联购买数量 2。
3. `cost = price * quantity`：先计算 `12 * 2`，再让 `cost` 关联结果 24。
4. `print(cost)`：读取 `cost`，把 24 显示出来。

前三行准备和计算数据，第四行才产生屏幕输出。

这段程序里的三个动作，有各自的名称：

- **表达式**：计算后得到一个值，例如 `price * quantity` 得到 24。
- **赋值**：把一个名字与值关联起来，例如 `cost = price * quantity`。
- **函数调用**：请一个已有的操作处理数据，例如 `print(cost)` 负责显示结果。

`print` 是 Python 提供的函数。这里先学怎样调用它，不需要先学怎样编写函数。

### 1.1 怎样把这段文字运行起来

Python 解释器是负责读取并执行 Python 代码的程序。**保存**是把代码写进文件，**运行**才是请解释器执行文件里的步骤。

在已经安装 Python 3 的环境中，可以这样运行：

1. 新建一个纯文本文件，取名 `main.py`。
2. 把上面的四行代码放进去，保存文件。
3. 在文件所在目录打开终端，输入下面的命令。

文件名中的 `.py` 表示 Python 源代码文件。`main` 是我们取的名字，也可以换成 `shopping`。

```bash
python main.py
```

命令的意思是“请 Python 读取并执行 `main.py`”。有些环境使用的命令是 `python3 main.py`。

> ⚠️ `python main.py` 要输入在终端里，不要把它作为第五行追加到 Python 文件中。

使用 Jupyter 时，把四行代码放进一个代码单元，再运行该单元即可。代码的执行逻辑不变，只是启动方式不同。

代码里，`#` 后面到本行末尾的文字是**注释**，只给人看，不参与计算。`# 屏幕显示 24` 是说明，真正产生输出的是 `print(cost)`。

> ⚠️ 普通 `.py` 文件不会自动显示每个表达式的值。这里需要 `print`。Jupyter 能显示单元最后一个表达式的值，是编辑环境提供的便利，不是每行代码都会打印。

**试一下：** 把数量改成 3，先预测结果，再运行。应该显示 36。价格没变，只是这一轮执行时，`quantity` 关联了另一个值。

## 2. 数字与运算：先把日常计算写出来

本数 2 是整数，价格 12.5 带有小数。Python 用不同的类型区分它们：

- `int`：整数类型，例如 `2`、`0`、`-3`。
- `float`：浮点数类型，例如 `12.5`。

`type(value)` 用来查看一个值的类型。先看类型，再试四则运算：

```python
print(type(12))    # <class 'int'>
print(type(12.5))  # <class 'float'>
print(7 + 2)      # 9：加法
print(7 - 2)      # 5：减法
print(7 * 2)      # 14：乘法
print(7 / 2)      # 3.5：除法
```

做整数题时，还有两个特别常用的操作。把 7 个苹果每 2 个分一组，能分几整组？还剩几个？这正好对应 `//` 和 `%`。

```python
print(7 // 2)     # 3：向下取整后的商
print(7 % 2)      # 1：余数
print(2 ** 3)     # 8：乘方，2 的三次方
print(abs(-7))    # 7：绝对值，也就是到 0 的距离
```

于是，判断整数 `x` 是否为偶数，就可以检查 `x % 2 == 0`。不是因为这是一句模板，而是“除以 2 没有余数”正是偶数的含义。

乘除先于加减。需要改变计算顺序时，用括号，例如 `(7 + 2) * 3`。

> ⚠️ `//` 是向下取整，不是直接去掉小数。`-7 / 2` 是 -3.5，向下取整后 `-7 // 2` 是 -4。除数为 0 时，`/`、`//` 和 `%` 都会报错。

浮点数不能精确表示所有十进制小数。涉及小数结果比较时要考虑这个限制，不能把整数计算的判断方式直接照搬过去。

## 3. 变量：名字相同，关联的值也可以改变

“已经给 `quantity` 赋过值，为什么还能再赋一次？”因为变量不是数学中永远固定的未知数。它是程序运行时使用的名字，当前关联哪个值，要看已经执行过哪些语句。

```python
x = 10
old = x           # old 也关联整数 10
x = x + 1         # 先用旧 x 算出 11，再让 x 关联 11
print(x, old)     # 11 10
x += 1            # 对这里的整数，相当于 x = x + 1
print(x)          # 12
```

`x = x + 1` 不是数学中的等式。它要求 Python 做两个有先后顺序的动作：

1. 读取旧的 `x`，计算 `10 + 1`，得到 11。
2. 让名字 `x` 关联新结果 11。

**赋值先计算右边，再更新左边。** 这一行没有给 `old` 重新赋值，所以 `old` 仍关联 10。

第 02 章会说明另一种情况：两个名字关联同一个可变列表时，修改列表对象会被两边同时观察到。先记住这个区别的根源：**给名字换一个对象，与修改它所关联的对象，不是同一个动作。**

> ⚠️ `=` 用来赋值，`==` 才用来比较值是否相等。读取名字之前还要先定义它。把 `quantity` 拼成一个未定义的名字，会得到 `NameError`，Python 不会自动纠正拼写。

## 4. input：读取一行文字，需要数字时再转换

**Python 3 的 `input()` 每次读取一行输入。成功读取后，返回值始终是 `str`，也就是字符串。** 它不会看见数字就返回整数，也不会看见 `True` 就返回布尔值。

可以把字符串先理解为一段文字。下面的引号用来表示字符串的内容，不是要求你在输入时也敲引号：

| 你输入的内容 | `input()` 返回的值 | 类型 |
|---|---|---|
| `18` | `"18"` | `str` |
| `2.5` | `"2.5"` | `str` |
| `True` | `"True"` | `str` |
| `hello` | `"hello"` | `str` |
| 什么也不输入，直接回车 | `""`，空字符串 | `str` |

所以，更准确的理解不是“先识别出各种类型，再把它们转换成字符串”，而是：**`input()` 读取的本来就是文字，不负责识别其中的数字或其他类型。**

### 4.1 先观察读取结果

运行下面的代码，在等待输入时敲 `18` 并回车：

<!-- run: {"stdin":"18\n","stdout":"18\n<class 'str'>\n"} -->
```python
age_text = input()     # 读取一行，得到字符串 "18"
print(age_text)        # 18
print(type(age_text))  # <class 'str'>
```

执行过程只有三步：

1. `input()` 等待一行输入，把读到的文字返回。
2. `age_text` 接收返回的字符串 `"18"`。
3. 两个 `print` 分别显示它的内容和类型。

> ⚠️ `print` 显示字符串内容时，不会显示表示字符串的两侧引号。因此字符串 `"18"` 和整数 `18` 都可能在屏幕上显示成 `18`。需要确认类型时，用 `type()`，不要只看显示出来的内容。

> ⚠️ `input()` 会去掉输入行末尾的换行符，但不会自动删除其他空格。直接回车得到空字符串，不等于“输入已经结束”。如果读取时已经没有任何输入，会抛出 `EOFError`，而不是返回一个数字或 `None`。

### 4.2 要做数字计算，显式调用 int

假设要根据输入的年龄计算明年的年龄。读取文字之后，还需要把它转换成整数：

<!-- run: {"stdin":"18\n","stdout":"<class 'str'>\n<class 'int'>\n19\n"} -->
```python
age_text = input()     # 输入 18，得到字符串 "18"
age = int(age_text)    # 根据文字内容，得到整数 18
print(type(age_text))  # <class 'str'>：原变量仍是字符串
print(type(age))       # <class 'int'>：新结果是整数
print(age + 1)         # 19
```

这里是两个不同的操作：

- `input()` 负责读文字。
- `int()` 负责把符合整数格式的文字转换成整数。

`int(age_text)` 返回一个新结果，并不会把 `age_text` 本身改成整数。把两步合在一行，就是常见的 `age = int(input())`：先执行里面的 `input()`，再把结果传给外面的 `int()`。

> ⚠️ `int("hello")` 和 `int("2.5")` 都会抛出 `ValueError`，因为这些文字不是整数格式。这是转换失败，不是 `input()` 读取失败。

### 4.3 print：显示一个或多个结果

`print` 负责输出，不负责读取或转换输入。需要同时观察几个变量时，把它们用逗号隔开放进括号：

```python
price = 12
quantity = 2
print(price, quantity)   # 12 2：默认用空格分开
print(price * quantity)  # 24：默认在末尾换行
```

## 5. if：条件为真时，才执行对应分支

程序有时需要按条件选择动作。例如，购买数量达到 3 本就提示可以参加优惠，否则按普通购买处理。

先把这个要求拆开：`quantity >= 3` 负责判断，`if` 负责决定是否执行下面的语句。

### 5.1 比较表达式得到 True 或 False

**布尔类型 `bool` 只有两个值：`True` 表示真，`False` 表示假。** 比较表达式会得到其中一个结果。

```python
quantity = 3
print(quantity >= 3)  # True：3 确实大于或等于 3
print(quantity < 3)   # False：3 不小于 3
print(quantity == 3)  # True：两个值相等
print(quantity != 3)  # False：3 与 3 相等，所以“不相等”为假
```

常见比较符号可以分为三组：

- `==`、`!=`：相等、不相等。
- `>`、`>=`：大于、大于或等于。
- `<`、`<=`：小于、小于或等于。

### 5.2 if 和 else 分别在什么时候执行

对于上面的比较结果：

- 得到 `True`，执行 `if` 下面缩进的代码。
- 得到 `False`，跳过 `if` 分支。如果写了 `else`，就执行 `else` 分支；没写，就继续执行分支之后的代码。

<!-- run: {"stdout":"可以参加优惠\n购买流程结束\n"} -->
```python
quantity = 3
if quantity >= 3:
    print("可以参加优惠")
else:
    print("普通购买")
print("购买流程结束")
```

本例先计算 `3 >= 3`，结果是 `True`，所以显示“可以参加优惠”，不执行 `else`。最后一行没有缩进，属于分支之后的代码，因此还会显示“购买流程结束”。

把 `quantity` 改为 2，再运行一次：条件变成 `False`，此时会显示“普通购买”，最后仍显示“购买流程结束”。

> ⚠️ 冒号后面缩进的语句，才属于该分支。通常缩进四个空格。`else` 与 `if` 对齐；分支之后要继续执行的语句，也要退回相应层级。缩进会改变执行逻辑，不只是排版。

### 5.3 elif：前一个条件不成立，再检查下一个

有三种以上的情况时，可以写 `if / elif / else`。**Python 从上到下判断，只执行第一个条件为真的分支。**

```python
age = 16
if age >= 18:
    print("adult")
elif age >= 13:
    print("teen")  # teen
else:
    print("child")
```

这次的判断顺序是：

1. `16 >= 18` 是 `False`，跳过第一个分支。
2. `16 >= 13` 是 `True`，显示 `teen`。
3. 已经选中分支，不再执行 `else`。

> ⚠️ 连续写多个独立的 `if`，每个条件都会分别判断，不等于一个 `if / elif` 条件链。

### 5.4 and、or、not：组合或反转条件

当一次判断涉及多个要求时，可以组合布尔条件：

- `and`：两个条件都为真，组合条件才为真。
- `or`：至少一个条件为真，组合条件就为真。
- `not`：把真变成假，把假变成真。

```python
age = 20
has_ticket = True
print(age >= 18 and has_ticket)  # True：成年，而且有票
print(age < 18 or has_ticket)    # True：虽然不是未成年人，但有票
print(not has_ticket)           # False：不是“没有票”
```

Python 会在结果已经确定时停止判断后面的条件，这叫**短路**。例如，`and` 左边为假时，右边不必再判断；`or` 左边为真时，也不必再判断右边。

本节先用比较结果和布尔值组合条件。`if` 也能判断数字等对象的真假：0 按假处理，非零数字按真处理。`None` 是表示“没有结果”等情况的特殊值，也按假处理。这里的“真”不是要求对象必须是字面上的 `True`，而是按 Python 的真假规则判断。

## 6. for：让一个名字依次接住数据

现在不只要算一次：你想依次打印 1、2、3。写三个 `print` 当然可以，但要打印到 1000，就不适合逐行复制了。

```python
for x in range(1, 4):
    print(x)           # 1、2、3，各一行
print("done")          # done：循环结束后才执行
```

这一句有两部分，各自承担一个动作：

- `range(1, 4)`：依次提供 1、2、3，不包含终点 4。
- `for x in ...`：每轮取出下一项，让名字 `x` 关联这一项，再执行缩进的循环体。

**`x` 的值来自被遍历的数据，不是 Python 根据变量名猜出来的。**

| 轮次 | 这一轮取得的值 | 执行的操作 |
|---|---|---|
| 第一轮 | `x = 1` | 显示 1 |
| 第二轮 | `x = 2` | 显示 2 |
| 第三轮 | `x = 3` | 显示 3 |
| 遍历结束 | 没有下一项 | 离开循环，显示 `done` |

把 `x` 改名为 `number`，整个过程不会变。

### 6.1 range：起点包含，终点不包含

```python
for i in range(3):
    print(i)  # 依次显示 0、1、2，各一行
for i in range(2, 5):
    print(i)  # 依次显示 2、3、4
for i in range(5, 0, -2):
    print(i)  # 依次显示 5、3、1
```

三种写法的对应关系是：

| 写法 | 含义 | 本例依次提供 |
|---|---|---|
| `range(stop)` | 从 0 开始，步长为 1 | `range(3)` 提供 0、1、2 |
| `range(start, stop)` | 指定起点，步长为 1 | `range(2, 5)` 提供 2、3、4 |
| `range(start, stop, step)` | 指定起点、终点和步长 | `range(5, 0, -2)` 提供 5、3、1 |

终点不包含在内。因此，要打印 1 到 5，用 `range(1, 6)`。

> ⚠️ `range(5, 0)` 不会自动倒着走。它仍使用默认步长 1，因此没有任何项。要递减，需要指定负步长；步长不能为 0。

在循环体内重新给 `i` 赋值，也不会改变 `range` 下一轮提供的数字。

### 6.2 不只打印，还可以把已经处理的结果记住

要算 1+2+3，循环负责依次取数，还需要一个名字记住“到目前为止的和”。

```python
total = 0
for x in range(1, 4):
    total += x
print(total)            # 6
```

| 轮次 | 本轮 x | 原来的 total | 加上 x 后 |
|---:|---:|---:|---:|
| 1 | 1 | 0 | 1 |
| 2 | 2 | 1 | 3 |
| 3 | 3 | 3 | 6 |

`total` 表示已经处理部分的和。开始时还没处理任何数字，所以把它设为 0。每轮加上当前的 `x`，循环结束时就得到了总和。

> ⚠️ `total = 0` 应放在循环外。放在循环体内，会在每轮开始时清掉之前的累加结果。

**先说清变量要记住什么，再决定在哪里初始化和更新。**

## 7. while：只要还满足条件，就再做一轮

`for` 适合从一组数据里依次取值；`while` 则关心“这件事是否还需要继续”。例如，从 1 开始打印，只要没有超过 3 就继续：

```python
x = 1
while x <= 3:
    print(x)           # 1、2、3，各一行
    x += 1
print(x)               # 4：用这个值重新判断时，条件不成立
```

`while` 按下面的顺序重复执行：

1. 先检查 `x <= 3`。
2. 条件为真，进入循环体，先打印 `x`，再让 `x` 加一。
3. 循环体执行完，回到顶部重新判断。
4. 条件为假，退出循环，继续执行循环后的语句。

本例最后一轮打印 3，然后把 `x` 改成 4。回到顶部时，`4 <= 3` 为假，循环才结束。

> ⚠️ `while` 只在回到条件处时重新判断，不会在循环体每执行一行后都自动检查。

检查这个循环为什么能结束，只需追踪 `x`：它从 1 开始，每轮加一，最终会超过 3。

更一般地，要看条件依赖的状态是否在推进。状态可以由循环体直接更新，也可以由循环里调用的函数更新，不限于某种固定的赋值写法。

> ⚠️ 把更新语句放到循环后面，不能解决循环一直不退出的问题。程序只有先退出循环，才有机会执行那条更新语句。

### 7.1 break 与 continue：结束循环，还是跳过本轮

```python
x = 0
while True:
    x += 1
    if x == 4:
        break         # 结束最近一层循环
    if x == 2:
        continue      # 本轮不再往下走，回到下一次判断
    print(x)          # 输出 1、3
print("end")          # end
```

把它们分开理解：

- `break`：结束最近一层循环，继续执行循环后面的代码。本例到 `x == 4` 时退出。
- `continue`：跳过本轮剩余语句，开始下一轮。本例到 `x == 2` 时不打印 2，但循环继续。

所以这里依次打印 1、3，最后打印 `end`。`while True` 的条件始终为真，但仍可以通过 `break` 正常退出。

> ⚠️ `continue` 可能跳过本轮剩余的更新语句，造成循环无法推进。本例先执行 `x += 1`，再判断是否跳过，因此不会卡在 2。

函数中的 `return` 会结束整个函数调用，也会离开其中的循环。异常同样可能打断执行，但不能把报错当作正常的退出方案。

## 8. 函数：写好一个任务，以后给不同数据调用

两次求和不必复制两份计算过程。可以先给“把两个数相加”取一个名字 `add`，以后需要时，把两个数交给它。

```python
def add(a, b):
    result = a + b
    return result

first = add(2, 3)
second = add(10, 20)
print(first, second)    # 5 30
```

跟着第一次调用，分清三个时刻：

1. **定义函数。** 执行 `def add(a, b):`，Python 记住函数的名称和函数体，此时还没有计算这次加法。
2. **调用函数。** 执行 `add(2, 3)`，进入函数。`a` 接收 2，`b` 接收 3，计算后 `result` 得到 5。
3. **返回结果。** 执行 `return result`，把 5 交回 `add(2, 3)` 所在的位置。外面的 `first` 接收 5，再继续执行下一行。

第二次调用重复同一套步骤，但传入的数据变成了 10 和 20。

`a` 和 `b` 是定义时接收数据的名字，叫**形参**。`2` 和 `3` 是调用时实际传入的数据，叫**实参**。

> ⚠️ 每次函数调用有自己的局部变量。函数里的 `result` 不会自动成为函数外也能读取的变量。要把结果交出来，需要 `return`，再由调用方接收。

### 8.1 屏幕出现了结果，不等于函数返回了结果

```python
def show_double(x):
    print(x * 2)

def get_double(x):
    return x * 2

value = show_double(3)  # 函数内部打印 6
print(value)           # None：函数没有显式返回结果
answer = get_double(3) # 本行没有打印，answer 接收返回的 6
print(answer + 1)      # 7
```

这两个函数对调用方的影响不同：

- `show_double(3)` 在函数内部打印 6，但没有返回这个 6，所以 `value` 得到的是 `None`。
- `get_double(3)` 返回 6，不在内部打印。外面的 `answer` 接收到 6，可以继续计算 `answer + 1`。

**显示结果用 `print`，把结果交给后续代码用 `return`。**

执行 `return` 会立即结束这次函数调用。走到函数末尾却没有执行带返回值的 `return`，或只执行了单独的 `return`，调用结果都是 `None`。

> ⚠️ `None` 是一个特殊值，不是数字 0，也不是字符串 `"None"`。判断它通常写 `value is None`。普通数值的相等比较仍用 `==`，不要把 `is` 当作通用的相等运算符。

### 8.2 给函数一个默认值，再用测试核对它

```python
def can_enter(age, minimum=18):
    if age < minimum:
        return False
    return True

print(can_enter(16))              # False：minimum 默认是 18
print(can_enter(16, minimum=16))  # True：这次调用明确传入 16
```

这里有两个容易看起来相似、实际位置不同的写法：

- 定义中的 `minimum=18`：调用方没提供这个参数时，使用默认值 18。
- 调用中的 `minimum=16`：这一次明确按参数名传入 16，替代默认值。

> ⚠️ 调用时传错参数名、少传必需参数或多传不接受的参数，都可能得到 `TypeError`。先对照函数定义，不要只看函数体。

已经知道预期结果时，可以让程序自动核对，这就是测试的起点：

```python
def add(a, b):
    return a + b

assert add(2, 3) == 5  # 成立就继续，不打印；不成立会抛 AssertionError
assert add(-2, 2) == 0
```

`assert 条件` 叫**断言**：条件为真，程序继续执行；条件为假，抛出 `AssertionError`。本课程用它自动检查练习结果。

> ⚠️ 测试失败时，先比较实际值与预期值，不要直接删掉断言。正式服务的输入校验也不能只靠 `assert`，因为优化运行选项可能关闭断言。

## 9. 两层循环：先走完里面，再推进外面

想枚举编号 0、1、2 中所有不同的两两组合，应该得到 `(0,1)`、`(0,2)`、`(1,2)`。可以先固定第一个编号，再把它后面的编号逐一配上：

```python
for i in range(3):
    for j in range(i + 1, 3):
        print(i, j)   # 依次输出 0 1、0 2、1 2
```

| 外层的 `i` | 内层的范围 | 本轮输出 |
|---|---|---|
| 0 | `range(1, 3)`，取得 1、2 | `0 1`，然后 `0 2` |
| 1 | `range(2, 3)`，取得 2 | `1 2` |
| 2 | `range(3, 3)`，没有任何项 | 无输出 |

内层的范围会在每一轮外层循环中重新确定。

让 `j` 从 `i + 1` 开始，有两个作用：

- 不让同一个位置与自己配对。
- 不重复计算 `(0, 1)` 与 `(1, 0)` 这样的同一对位置。

这里的两个循环不是同时推进，而是**内层走完一遍，外层才推进一次**。

## 10. Traceback：把一段红字读成可以调查的线索

程序报错时，先别急着改代码。Python 往往已经把“走到哪里失败了”写出来，只是你还不熟悉它的表达方式。

下面是一个**故意出错**的完整程序：想求平均值，却把数量设成了 0。

<!-- run: {"error":"ZeroDivisionError"} -->
```python
count = 0
average = 10 / count
```

保存为 `main.py` 运行时，会看到类似内容：

```text
Traceback (most recent call last):
  File "main.py", line 2, in <module>
    average = 10 / count
ZeroDivisionError: division by zero
```

这段日志包含三类信息，先认清它们的含义：

| 日志中的内容 | 告诉你什么 |
|---|---|
| `Traceback (most recent call last)` | 以下是调用轨迹，最近的一层放在最后 |
| `File "main.py", line 2, in <module>` | 当时执行到 `main.py` 第 2 行，位置在文件最外层 |
| `average = 10 / count` | 对应的源码行 |
| `ZeroDivisionError: division by zero` | 冒号前是异常类型，后面是具体信息：除数为 0 |

实际排查时，可以按这个顺序读：

1. 看最后一行，确定这里发生了除零错误。
2. 看对应源码，确定失败的运算是 `10 / count`。
3. 检查变量，确定 `count` 在这一刻为什么等于 0。

`in <module>` 表示文件最外层。如果这里写的是函数名，就表示当时正在执行那个函数。某些 Python 版本还会用箭头或波浪线标出失败表达式的更小部分。

### 10.1 文件很多时，先找到失败点，再追它的来路

下面是一段用于练习阅读的日志，不是需要逐行执行的 Python 代码：

```text
Traceback (most recent call last):
  File "main.py", line 8, in <module>
    run()
  File "service.py", line 12, in run
    average = calculate(10, 0)
  File "math_ops.py", line 3, in calculate
    return total / count
ZeroDivisionError: division by zero
```

从上往下看，是程序的调用过程：

1. `main.py` 调用 `run()`。
2. `service.py` 中的 `run()` 调用 `calculate(10, 0)`。
3. `math_ops.py` 中的 `calculate()` 执行除法，因除数为 0 而失败。

调查时可以反过来走。先确认 `calculate` 里的 `count` 是 0，再回到上一层，发现调用参数就是 0。接下来才追问：这个 0 是用户输入、查询结果，还是程序设置的默认值？

> ⚠️ 抛错位置不一定是应该修改的位置。计算函数可能完全按约定工作，真正缺失的是上游对“没有数据”的处理。最下面一层是第三方库，也不表示一定是库的错误。

长日志中的 `During handling ...` 或 `direct cause ...` 可能把多个异常块连在一起。每一块先单独读，再理解前一个错误为什么引出了后一个，不要把它们误读成同一条调用链。

### 10.2 常见异常：先用类型缩小调查范围

| 异常 | 优先调查什么 |
|---|---|
| `SyntaxError` / `IndentationError` | 代码有没有缺冒号、括号或错缩进；可能尚未正常运行 |
| `NameError` | 名字是否定义、拼写是否正确、是否能在这里读取 |
| `TypeError` | 这类值能否做这个操作，函数参数是否传对 |
| `ValueError` | 类型能接受，但内容是否符合要求，如 `int("hello")` |
| `IndexError` / `KeyError` | 访问的位置或键是否存在 |
| `AssertionError` | 哪条测试预期不成立，实际得到什么 |

修复后既重跑刚才失败的输入，也试一组正常输入。只把错误藏起来，或者删除失败测试，并没有解决原因。

## 11. 本章小结与面试怎么答

一个程序首先是一条执行路线：从已有状态读取数据，计算或判断，改变状态，再决定往哪里走。循环让步骤重复，函数让任务可以反复调用，输入输出把程序与外界连接起来。读代码时，始终可以回到“这一行之前是什么，之后变成什么”。

**问：print 与 return 有什么区别？**

> 🎯 `print` 产生输出，`return` 把值交回调用者并结束当前函数调用。屏幕上出现一个数，不表示函数返回了这个数；没有显式返回值时，调用结果是 `None`。

**问：面对很长的报错，你怎样开始排查？**

> 🎯 先看异常类型和信息，再定位直接失败的表达式，恢复当时的变量状态，最后沿调用链追查数据从哪里来。修改应针对原因，而不是机械地修改最后一个文件。

## 12. ⚠️ 容易混淆的地方

- `=` 不是相等判断。赋值先计算右侧，再更新左侧；`==` 才是在比较值。
- `for x in ...` 中的 x 来自每轮取得的数据；变量名叫 i，也不自动代表下标。
- `continue` 只是跳过本轮剩余代码；`break` 才结束最近一层循环。检查必要的更新有没有被跳过。
- `return` 的缩进会改变结果：放在循环内可能第一轮就返回，放在循环后才会等所有轮次结束。

## 13. 章节自测

**动手题：** 写 `sum_to(n)`，返回 1 到非负整数 n 的总和，不使用 `sum`。n=3 返回 6，n=0 返回 0。先在纸上追踪前三轮，再写函数。

<details>
<summary>查看参考答案与验证</summary>

```python
def sum_to(n):
    total = 0
    for x in range(1, n + 1):
        total += x
    return total

assert sum_to(3) == 6
assert sum_to(0) == 0
assert sum_to(5) == 15
```

终点不包含，所以用 n+1。total 初始化在循环外，return 也在循环外。n=0 时循环不执行，仍返回已经准备好的 0。

</details>

<details>
<summary>为什么输入 18 后，不能只看 print 的输出就判断它是整数？</summary>

`input()` 正常返回字符串，打印时不显示两侧引号。因此文字 `"18"` 与整数 `18` 都能显示为 18；应该用 `type` 检查，需要计算时再做 `int` 转换。

</details>

<details>
<summary>while True 能正常结束吗？为什么循环之后的 x += 1 不能避免死循环？</summary>

可以通过 break 结束，所在函数执行 return 也会离开循环。放在循环后面的更新只有退出后才会执行，因此不能帮助一个始终为真、又没有退出路径的循环推进状态。

</details>

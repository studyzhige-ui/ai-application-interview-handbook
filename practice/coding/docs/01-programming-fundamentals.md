# 01｜程序基础：让 Python 一步一步替你做事

[← Coding 首页](../README.md) · [下一章：数据类型与容器 →](02-python-coding-basics.md)

买两本练习本，每本 12 元，一共多少钱？你大概立刻就能回答：24 元。

但让计算机做这件事，你需要把心里的计算过程写出来：记住单价，记住数量，算出总价，最后把结果显示出来。**编程的起点，就是把“我知道怎么做”变成“计算机能够照着执行的步骤”。**

这一章就从这笔小账出发。我们先看一行代码怎样产生结果，再让程序作判断、重复计算，最后把一个小任务写成可以多次调用的函数。遇到报错也不用绕开：读懂错误信息，本来就是学会编程的一部分。

## 1. 先让 Python 算一笔小账

下面四行就是一个小程序。先读它，不必急着记术语：

```python
price = 12               # 一本练习本的价格
quantity = 2             # 购买数量
cost = price * quantity  # 计算总价，cost 得到 24
print(cost)              # 屏幕显示 24
```

第一行给 12 起了个名字 `price`，第二行给 2 起名 `quantity`。第三行读出这两个名字关联的值，计算 `12 * 2`，再把结果交给 `cost`。第四行才负责把结果显示出来。

这里已经有三个值得区分的动作。`price * quantity` 是**表达式**，计算后得到一个值；`cost = ...` 是**赋值**，把名字和计算结果关联起来；`print(cost)` 是**函数调用**，把数据交给一个现成的操作。此时 `print` 由 Python 提供，你不需要先知道怎样编写它。

### 1.1 怎样把这段文字运行起来

代码是写给解释器读取的文字；**运行**，才是让解释器真正执行这些步骤。保存文件和运行文件是两件事。

在已经安装 Python 3 的环境里，可以新建一个纯文本文件，取名 `main.py`，把上面的四行放进去并保存。`.py` 表示这是 Python 源代码文件，`main` 只是我们取的名字，不是必须背的特殊单词。

随后在这个文件所在目录打开终端，输入下面这条命令；它是终端命令，不是要追加到 Python 代码里的第五行：

```bash
python main.py
```

有些环境使用 `python3 main.py`。命令的意思是“请 Python 读取并执行这个文件”。使用 Jupyter 时，也可以把四行放进一个代码单元运行；你仍然是在让 Python 执行代码，只是编辑和启动的方式不同。

`#` 后面是给人看的注释，不参与计算。所以 `# 屏幕显示 24` 只是说明，真正产生输出的是 `print(cost)`。在普通 `.py` 文件里，单写一个表达式不会自动打印它；Jupyter 显示单元最后一个表达式，是编辑环境提供的便利。

**试一下：** 把数量改成 3，先预测结果，再运行。应该显示 36。价格没变，只是这一轮执行时，`quantity` 关联了另一个值。

## 2. 数字与运算：先把日常计算写出来

Python 用 `int` 表示整数，例如本数 2；用 `float` 表示浮点数，例如价格 12.5。`type(value)` 可以查看一个值的类型。

```python
print(type(12))    # <class 'int'>
print(type(12.5))  # <class 'float'>
print(7 + 2)      # 9：加法
print(7 - 2)      # 5：减法
print(7 * 2)      # 14：乘法
print(7 / 2)      # 3.5：除法
```

做整数题时，还有两个特别常用的操作。把 7 个苹果每 2 个分一组，能分几整组？还剩几个？这正好对应 `//` 和 `%`。

```python
print(7 // 2)     # 3：向下取整后的商
print(7 % 2)      # 1：余数
print(2 ** 3)     # 8：乘方，2 的三次方
print(abs(-7))    # 7：绝对值，也就是到 0 的距离
```

于是，判断整数 `x` 是否为偶数，就可以检查 `x % 2 == 0`。不是因为这是一句模板，而是“除以 2 没有余数”正是偶数的含义。

乘除先于加减，不确定时用括号明确顺序。`//` 是向负无穷取整，`-7 // 2` 为 -4，不是直接去掉小数；除数为 0 则会报错。浮点数也不是所有十进制小数都能精确表示，不过整数基础题先不需要展开浮点表示的细节。

## 3. 变量：名字相同，关联的值也可以改变

“已经给 `quantity` 赋过值，为什么还能再赋一次？”因为变量不是数学中永远固定的未知数。它是程序运行时使用的名字，当前关联哪个值，要看已经执行过哪些语句。

```python
x = 10
old = x           # old 也关联整数 10
x = x + 1         # 先用旧 x 算出 11，再让 x 关联 11
print(x, old)     # 11 10
x += 1            # 对这里的整数，相当于 x = x + 1
print(x)          # 12
```

`x = x + 1` 不是声称“一个数等于它自己加一”。赋值的顺序是：**先算右边，再更新左边**。执行后，`old` 仍关联 10，因为这一行没有给 `old` 重新赋值。

第 02 章会说明另一种情况：两个名字关联同一个可变列表时，修改列表对象会被两边同时观察到。先记住这个区别的根源：**给名字换一个对象，与修改它所关联的对象，不是同一个动作。**

另外，`=` 用来赋值，`==` 用来比较值是否相等。读取一个名字之前必须先给它赋值；例如把 `quantity` 拼成另一个名字，Python 不会猜你的意思，而会报告 `NameError`。

## 4. 输入与输出：让用户决定算什么

前面的数量写死在代码里。每次买的本数不同，难道都要改程序吗？可以让程序等用户输入，再继续计算。

运行下面代码时，输入 `18` 并回车。先留意：看起来像数字的内容，不一定已经是数字类型。

<!-- run: {"stdin":"18\n","stdout":"18\n<class 'str'>\n<class 'int'>\n19\n"} -->
```python
age_text = input()       # 读取键盘输入的一行，得到字符串 "18"
print(age_text)          # 18
print(type(age_text))    # <class 'str'>
age = int(age_text)      # 把数字的文字表示转换成整数 18
print(type(age))         # <class 'int'>
print(age + 1)           # 19
```

`str` 是字符串类型，可以先理解为一段文字。`"18"` 是用文字写的 18，整数 `18` 才能直接参与这里的加法。`print` 打印字符串时不显示两侧引号，因此不能只凭屏幕上的 `18` 判断类型；`type` 让区别变得可见。

常见的 `int(input())` 只是把两步合在一起：先执行里面的 `input()`，再把返回的字符串交给 `int`。转换必须符合内容：`int("hello")` 和 `int("2.5")` 都不会成功。它不是“看到任何文字都能变出一个整数”。

输出也可以一次显示多个值：

```python
price = 12
quantity = 2
print(price, quantity)  # 12 2：默认用空格分开，最后换行
print(price * quantity) # 24
```

现在，最小程序已经形成了完整的数据流：**取得输入 → 转成适合计算的类型 → 处理 → 输出**。初学时，先把这条线看清，比把几层括号压在一起更重要。

## 5. 判断：同一份代码，也能走不同的路

假设购买数量达到 3 本就提示可以参加优惠，否则按普通购买处理。程序需要的不是重复计算，而是先回答一个“是或不是”的问题。

```python
quantity = 3
print(quantity >= 3)       # True
if quantity >= 3:
    print("可以参加优惠")   # 本例执行这里
else:
    print("普通购买")
```

`True` 和 `False` 是布尔类型 `bool` 的两个值，表示真和假。比较运算 `==`、`!=`、`<`、`<=`、`>`、`>=` 会给出这样的结果。`if` 根据结果决定是否进入它下面的代码块。

冒号后的缩进告诉 Python：哪些语句属于这个分支。通常使用四个空格；`else` 与 `if` 对齐，表示前面的条件不成立时怎么办。缩进不是为了好看，它决定代码归谁管理。

多于两种情况时，可以加入 `elif`，表示“前面不满足，再试这个条件”。整个条件链只执行第一个满足的分支：

```python
age = 16
if age >= 18:
    print("adult")
elif age >= 13:
    print("teen")       # teen
else:
    print("child")
```

需要组合条件时，`and` 表示同时满足，`or` 表示至少满足一个，`not` 表示把判断反过来：

```python
age = 20
has_ticket = True
print(age >= 18 and has_ticket)  # True
print(age < 18 or has_ticket)    # True
print(not has_ticket)           # False
```

`and/or` 会在结果已经确定时跳过右侧，这叫短路。先用它们组合清楚的判断，不必急着写成复杂的一长行。`None` 表示没有值或结果；`bool(0)`、`bool(None)` 为 False，非零数字按 True 处理。容器是否为空也能用来判断，届时会直接放进相应的数据场景理解。

## 6. for：让一个名字依次接住数据

现在不只要算一次：你想依次打印 1、2、3。写三个 `print` 当然可以，但要打印到 1000，就不适合逐行复制了。

```python
for x in range(1, 4):
    print(x)           # 1、2、3，各一行
print("done")          # done：循环结束后才执行
```

先把这一句拆成两部分：`range(1, 4)` 提供 1、2、3；`for x in ...` 每轮取出下一项，并让名字 `x` 关联它。**不是 Python 猜到了 x 应该是多少，而是循环语句本身在做“取下一项并赋值”的工作。**

第一轮取得 1，执行一次 `print(x)`；第二轮取得 2，再执行一次；第三轮取得 3，再执行一次。没有下一项时，才离开循环，执行没有缩进的 `print("done")`。把 `x` 换成 `number` 不会改变过程，变量名没有特殊魔法。

### 6.1 range：起点包含，终点不包含

```python
for i in range(3):
    print(i)  # 依次显示 0、1、2，各一行
for i in range(2, 5):
    print(i)  # 依次显示 2、3、4
for i in range(5, 0, -2):
    print(i)  # 依次显示 5、3、1
```

三种写法分别是：只给终点；给起点和终点；再给一个步长。步长为 -2，表示每次减 2。

终点总是不包含的。因此打印 1 到 5，要用 `range(1, 6)`。默认步长为 1，`range(5, 0)` 不会自动倒着走，而是没有任何项；步长不能为 0。重新给循环变量赋值，也不会改变 `range` 下一轮提供的数字。

### 6.2 不只打印，还可以把已经处理的结果记住

要算 1+2+3，循环负责依次取数，还需要一个名字记住“到目前为止的和”。

```python
total = 0
for x in range(1, 4):
    total += x
print(total)            # 6
```

| 轮次 | 本轮 x | 原来的 total | 加上 x 后 |
|---:|---:|---:|---:|
| 1 | 1 | 0 | 1 |
| 2 | 2 | 1 | 3 |
| 3 | 3 | 3 | 6 |

`total` 表示已经处理部分的和，所以先从 0 开始，每轮在原结果上增加。若把 `total = 0` 放到循环体内，每轮都会忘记之前的结果。**先说清变量要记住什么，再决定在哪里初始化和更新。**

## 7. while：只要还满足条件，就再做一轮

`for` 适合从一组数据里依次取值；`while` 则关心“这件事是否还需要继续”。例如，从 1 开始打印，只要没有超过 3 就继续：

```python
x = 1
while x <= 3:
    print(x)           # 1、2、3，各一行
    x += 1
print(x)               # 4：用这个值重新判断时，条件不成立
```

每轮路线都是：检查条件，条件为真才进入，执行循环体，再回到顶部检查。它不会在循环体的每一行之后都自动检查。最后一轮打印 3，再把 x 改成 4；下一次检查失败，循环才结束。

判断能否结束时，问：条件依赖哪个状态？一轮之后它怎样变化？这里 x 不断加一，因此会超过 3。状态也可以通过循环里调用的函数间接改变，不是必须写某种固定的赋值语句；但放在循环**后面**的语句，救不了一个始终不退出的循环，因为程序还走不到那里。

### 7.1 break 与 continue：结束循环，还是跳过本轮

```python
x = 0
while True:
    x += 1
    if x == 4:
        break         # 结束最近一层循环
    if x == 2:
        continue      # 本轮不再往下走，回到下一次判断
    print(x)          # 输出 1、3
print("end")          # end
```

`break` 像“事情已经办完，不再继续”，`continue` 像“这一项不处理，换下一项”。因此 `while True` 也可以结束，不必让条件本身变成 False。函数内的 `return` 还会结束整个函数调用；异常也可能中断正常执行，但不能把报错当成正常的终止设计。

使用 `continue` 时尤其要留意：它有没有把必要的更新语句跳过去？上面的 `x += 1` 放在前面，因此即使跳过 2，也会继续推进。

## 8. 函数：写好一个任务，以后给不同数据调用

两次求和不必复制两份计算过程。可以先给“把两个数相加”取一个名字 `add`，以后需要时，把两个数交给它。

```python
def add(a, b):
    result = a + b
    return result

first = add(2, 3)
second = add(10, 20)
print(first, second)    # 5 30
```

要分清三个时刻。执行 `def` 时，Python 建立这个函数，但还没有算任何一次和。执行 `add(2, 3)` 时，才进入函数：参数名 a 接收 2，b 接收 3，局部变量 result 得到 5。执行 `return result` 后，5 回到调用位置，`first` 接住它，程序再继续下一行。

`a、b` 是定义时的**形参**，`2、3` 是调用时提供的**实参**。先记住“名字接收实际数据”这个关系，不要只背两个名词。每次调用有自己的局部状态，函数里的 `result` 不会自动变成文件外层也能读取的变量。

### 8.1 屏幕出现了结果，不等于函数返回了结果

```python
def show_double(x):
    print(x * 2)

def get_double(x):
    return x * 2

value = show_double(3)  # 函数内部打印 6
print(value)           # None：函数没有显式返回结果
answer = get_double(3) # 本行没有打印，answer 接收返回的 6
print(answer + 1)      # 7
```

`print` 是把内容显示出去；`return` 是把值交回调用者。调用者想继续计算，就需要返回值，而不是只能看见一行屏幕输出。

执行 `return` 会立即结束这次函数调用。没有写返回值就走到末尾，或者只写 `return`，结果都是 `None`。判断缺少结果常写 `value is None`；一般数值比较仍用 `==`，不要用 `is` 代替它。

### 8.2 给函数一个默认值，再用测试核对它

```python
def can_enter(age, minimum=18):
    if age < minimum:
        return False
    return True

print(can_enter(16))              # False：minimum 默认是 18
print(can_enter(16, minimum=16))  # True：这次调用明确传入 16
```

`minimum=18` 表示没提供这个参数时用 18；调用中的 `minimum=16` 是按参数名提供实际值。参数数量或名字传错，会得到 `TypeError`，而不是由 Python 自动纠正。

已经知道预期结果时，可以让程序自动核对，这就是测试的起点：

```python
def add(a, b):
    return a + b

assert add(2, 3) == 5  # 成立就继续，不打印；不成立会抛 AssertionError
assert add(-2, 2) == 0
```

`assert 条件` 叫断言。本课程用它检查练习结果，失败时要查看实际值与预期差在哪里。它不是正式服务的输入校验替代品，因为某些优化运行选项会关闭断言。

## 9. 两层循环：先走完里面，再推进外面

想枚举编号 0、1、2 中所有不同的两两组合，应该得到 `(0,1)`、`(0,2)`、`(1,2)`。可以先固定第一个编号，再把它后面的编号逐一配上：

```python
for i in range(3):
    for j in range(i + 1, 3):
        print(i, j)   # 依次输出 0 1、0 2、1 2
```

当 i=0 时，内层完整执行 j=1 和 j=2，才轮到 i=1。此时内层重新从 `i+1` 开始，只执行 j=2。到 i=2，后面已经没有编号，内层为空。

因此 j 从 i+1 开始，一次解决两个问题：不拿同一位置和自己配对，也不把 `(0,1)` 与 `(1,0)` 重复计算。关键不是两个循环同时往前跑，而是**内层走完一遍，外层才推进一次**。

## 10. Traceback：把一段红字读成可以调查的线索

程序报错时，先别急着改代码。Python 往往已经把“走到哪里失败了”写出来，只是你还不熟悉它的表达方式。

下面是一个**故意出错**的完整程序：想求平均值，却把数量设成了 0。

<!-- run: {"error":"ZeroDivisionError"} -->
```python
count = 0
average = 10 / count
```

保存为 `main.py` 运行时，会看到类似内容：

```text
Traceback (most recent call last):
  File "main.py", line 2, in <module>
    average = 10 / count
ZeroDivisionError: division by zero
```

先看最后一行。冒号前的 `ZeroDivisionError` 是**异常类型**，提示与除零有关；后面的 `division by zero` 是更具体的信息。再看上一行源码，失败的是 `10 / count`，于是调查问题缩小为：**执行到这里时，count 为什么是 0？**

中间一行也可以拆开读：`File "main.py"` 是文件，`line 2` 是行号，`in <module>` 表示文件最外层的代码。如果末尾是函数名，就表示当时位于那个函数中。

第一行 `Traceback (most recent call last)` 则告诉你：下面是调用轨迹，最近的一层在最后。某些版本会额外显示箭头或波浪线，帮助标出更小的表达式，不影响这个基本结构。

### 10.1 文件很多时，先找到失败点，再追它的来路

下面是一段用于练习阅读的日志，不是需要逐行执行的 Python 代码：

```text
Traceback (most recent call last):
  File "main.py", line 8, in <module>
    run()
  File "service.py", line 12, in run
    average = calculate(10, 0)
  File "math_ops.py", line 3, in calculate
    return total / count
ZeroDivisionError: division by zero
```

从上往下，它在讲发生过程：`main.py` 调用 `run()`，`run()` 调用 `calculate()`，最后除法失败。从下往上调查，则是先确认 count=0，再回到上一层发现调用时传入了 0，然后问这个 0 是输入、查询结果，还是某个默认值。

**抛错位置不一定是应该修改的位置。** 数学函数也许完全按约定执行，真正缺失的是上游对“没有数据”的处理。最下面若是第三方库，也不能仅凭这一点断定库有问题。

长日志中的 `During handling ...` 或 `direct cause ...` 可能把多个异常块连在一起。每一块先单独读，再理解前一个错误为什么引出了后一个，不要把它们误读成同一条调用链。

### 10.2 常见异常：先用类型缩小调查范围

| 异常 | 优先调查什么 |
|---|---|
| `SyntaxError` / `IndentationError` | 代码有没有缺冒号、括号或错缩进；可能尚未正常运行 |
| `NameError` | 名字是否定义、拼写是否正确、是否能在这里读取 |
| `TypeError` | 这类值能否做这个操作，函数参数是否传对 |
| `ValueError` | 类型能接受，但内容是否符合要求，如 `int("hello")` |
| `IndexError` / `KeyError` | 访问的位置或键是否存在 |
| `AssertionError` | 哪条测试预期不成立，实际得到什么 |

修复后既重跑刚才失败的输入，也试一组正常输入。只把错误藏起来，或者删除失败测试，并没有解决原因。

## 11. 本章小结与面试怎么答

一个程序首先是一条执行路线：从已有状态读取数据，计算或判断，改变状态，再决定往哪里走。循环让步骤重复，函数让任务可以反复调用，输入输出把程序与外界连接起来。读代码时，始终可以回到“这一行之前是什么，之后变成什么”。

**问：print 与 return 有什么区别？**

> 🎯 `print` 产生输出，`return` 把值交回调用者并结束当前函数调用。屏幕上出现一个数，不表示函数返回了这个数；没有显式返回值时，调用结果是 `None`。

**问：面对很长的报错，你怎样开始排查？**

> 🎯 先看异常类型和信息，再定位直接失败的表达式，恢复当时的变量状态，最后沿调用链追查数据从哪里来。修改应针对原因，而不是机械地修改最后一个文件。

## 12. ⚠️ 容易混淆的地方

- `=` 不是相等判断。赋值先计算右侧，再更新左侧；`==` 才是在比较值。
- `for x in ...` 中的 x 来自每轮取得的数据；变量名叫 i，也不自动代表下标。
- `continue` 只是跳过本轮剩余代码；`break` 才结束最近一层循环。检查必要的更新有没有被跳过。
- `return` 的缩进会改变结果：放在循环内可能第一轮就返回，放在循环后才会等所有轮次结束。

## 13. 章节自测

**动手题：** 写 `sum_to(n)`，返回 1 到非负整数 n 的总和，不使用 `sum`。n=3 返回 6，n=0 返回 0。先在纸上追踪前三轮，再写函数。

<details>
<summary>查看参考答案与验证</summary>

```python
def sum_to(n):
    total = 0
    for x in range(1, n + 1):
        total += x
    return total

assert sum_to(3) == 6
assert sum_to(0) == 0
assert sum_to(5) == 15
```

终点不包含，所以用 n+1。total 初始化在循环外，return 也在循环外。n=0 时循环不执行，仍返回已经准备好的 0。

</details>

<details>
<summary>为什么输入 18 后，不能只看 print 的输出就判断它是整数？</summary>

`input()` 正常返回字符串，打印时不显示两侧引号。因此文字 `"18"` 与整数 `18` 都能显示为 18；应该用 `type` 检查，需要计算时再做 `int` 转换。

</details>

<details>
<summary>while True 能正常结束吗？为什么循环之后的 x += 1 不能避免死循环？</summary>

可以通过 break 结束，所在函数执行 return 也会离开循环。放在循环后面的更新只有退出后才会执行，因此不能帮助一个始终为真、又没有退出路径的循环推进状态。

</details>

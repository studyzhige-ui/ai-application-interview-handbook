# Python 基础写法实践

[实践总览](../README.md) · [Python 知识主线](../../curriculum/01-python/README.md) · [Coding 方法与算法](../coding/README.md)

[Python 高频 Coding 小题](Python高频Coding小题.md)保留去重、文本处理、分组、排序、生成器等常用写法，适合按需要查阅或动手对照。它不是读完 Python 的通关条件，也不替代语言规则讲解。

每道题先看输入契约：空值、重复、顺序和可哈希条件是否允许。语言机制对应 Python 的[容器](../../curriculum/01-python/docs/02-核心数据类型与容器.md)、[函数](../../curriculum/01-python/docs/04-函数-参数-作用域-闭包.md)、[迭代](../../curriculum/01-python/docs/06-迭代器-生成器-yield.md)和[数据结构](../../curriculum/01-python/docs/13-常见数据结构与复杂度.md)；算法专题可独立进入 Coding。

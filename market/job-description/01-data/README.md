# 官方岗位原文与索引

- [岗位索引](岗位JD.md)：按公司列出本轮纳入岗位，点击岗位名阅读官网详情。
- [当前正式岗位库](official-jds.json)：完整职责与任职要求、招聘ID与地点、类型与届次、模型判断和覆盖记录。
- [非当前观察与历史保全](source-observations.json)：排除及不完整来源的核验记录，以及未重新取得的历史一手事实。

当前库的 `companies[].jobs` 是本轮完整阅读后纳入的岗位。保全文件的 `companies[].other_observations` 记录排除、不完整或访问失败的事实及原文哈希；`historical_observations` 是未重新取得的一手历史材料，不计当前岗位数量。当前库用文件名、字节数与SHA-256引用保全文件，检查时一起加载；两份文件各负其责，不重复保存岗位正文。历史记录可能只披露部分字段，不一律称完整JD。

岗位库正文保留官方措辞、完整资格和投递说明；小米3条浏览器结构树已提取为实际可见正文。`body_sha256` 校验存储正文，发生结构树提取的条目另以 `source_capture_sha256` 保留原页面快照哈希，两种基准分别记录；其余原文不作重拼裁切。清洁排版不会把未披露信息补成事实。

# 官方岗位原文与索引

- [岗位索引](岗位JD.md)：按公司列出本轮纳入岗位，点击岗位名阅读官网详情。
- [当前正式岗位库](official-jds.json)：公司覆盖、完整职责与任职要求、招聘ID与地点、类型与届次、模型判断；其中字节跳动岗位通过哈希引用下列分片。
- [字节跳动当前岗位](bytedance-jds.json)：该公司的完整当前岗位正文。按公司分开存储以保持文件可传输，不另建第二套岗位库存。
- [非当前观察](source-observations.json)：排除、不完整和访问失败的核验记录。
- [历史一手材料](historical-jds.json)：未重新取得的原始事实，不计当前岗位数量。

当前库的 `companies[].jobs` 是本轮完整阅读后纳入的岗位；字节跳动公司的 `jobs_file` 引用同一快照下的完整数组。保全文件的 `companies[].other_observations` 记录非当前观察，`historical_file` 引用历史一手材料。所有引用均校验固定文件名、字节数、SHA-256和快照，检查时恢复同一逻辑岗位库；每份正文仅存一处。历史记录可能只披露部分字段，不一律称完整JD。

岗位库正文保留官方措辞、完整资格和投递说明；小米3条浏览器结构树已提取为实际可见正文。`body_sha256` 校验存储正文，发生结构树提取的条目另以 `source_capture_sha256` 保留原页面快照哈希，两种基准分别记录；其余原文不作重拼裁切。清洁排版不会把未披露信息补成事实。

## 2. 正式纳入 Gate

必须同时满足：

1. **2027**：官方职位、官方项目或官方 JD 明确证明属于 2027 届正式校园招聘；
2. **第一手**：公司官网 / 官方 ATS / 官方招聘 API；
3. **工程岗**：软件、后端、全栈、客户端、平台、Agent Runtime/Harness/Infra 等工程研发；
4. **岗位主责**：Agent / 智能体 / AI Application / 大模型应用 / Coding Agent / RAG Application / AI Native；
5. **非算法主体**：预训练、后训练、SFT/DPO/RLHF/RL、模型研究、搜广推算法等不是岗位主责。

同公司、职责高度相同而仅城市/职位 ID 不同的岗位合并为一个 **Role Family**。

# 市场材料与分析

保管真实岗位描述与完整一手面试流程，从可以回读的事实形成分析与学习策略。

- [岗位描述](job-description/README.md)：官方来源、完整JD、公司和岗位状态，以及采集处理。
- [面试经历](interview-experience/README.md)：完整招聘流程、原始题序与追问，以及注明来源和覆盖范围的模型整理结果。

两条业务均使用五层：01-data 保存事实与必要规范化数据，02-analysis 保存分析结果，03-strategy 说明现行策略，04-scripts 执行业务处理，05-logs 保存采集记录。

[面试准备](../interview/README.md)使用这里的证据整理回答与复习；[课程](../curriculum/README.md)按知识依赖组织学习。已确认的分析帮助判断学习重点，技术答案以适用条件和官方事实为依据。

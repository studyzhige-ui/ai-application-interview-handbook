# 面经来源质量准入规则

更新日期：2026-09-09

本策略只约束面试样本准入与频率统计；课程正文仍以官方技术事实和教学组织保证正确性与可理解性。

本面经业务研究能够真实校准 **AI 应用开发 / Agent 开发** 求职方向的高质量真人面经。

> **平台不是质量标准。** 来源可以来自牛客、小红书、知乎、脉脉、Bilibili、抖音、CSDN、个人博客或其他公开平台，但无论来自哪里，都必须满足完全相同的准入条件。

## 1. 正式样本唯一标准：HUMAN-A

正式来源必须同时满足：

1. **Human Interviewer**：明确属于真人面试官参与的技术面 / Leader 面 / 项目深挖；
2. **First-person**：候选人本人第一人称复盘；
3. **A-grade Quality**：信息密度高，有具体技术追问和真实现场痕迹；
4. **Role Scope**：岗位属于 `role-scope-policy.md` 定义的 AI Application / Agent / RAG / AI Backend / AI Full-stack / Agent Runtime 等目标方向；
5. **Verifiable**：正文和原始 URL 可稳定核验；
6. **Deduplicated**：不是转载、合集或同一场跨平台重复。

```text
任意公开平台
      ↓
真人面试官？
      ↓
候选人本人第一人称？
      ↓
高信息密度且有真实现场痕迹？
      ↓
目标 AI Application / Agent 岗？
      ↓
可稳定核验且非转载重复？
      ↓
HUMAN-A
```

任意一项不满足，都不进入正式 Batch、Canonical Question、频率统计和课程优先级分析。

## 2. 高质量第一人称的判断标准

正式来源原则上应同时具备：

- **公司 / 岗位明确**，最好还能确认日期、轮次、时长或业务团队；
- **真人互动痕迹**，例如面试官追问、引导、打断、反问、现场讨论、手撕、画图；
- **候选人状态痕迹**，例如哪里答得不好、被追问住、约下一轮、挂了、OC；
- **技术问题具体且有上下文**，通常至少 5～8 个有信息量的问题，或少量但非常深入的连续追问；
- **问题顺序具有真实面试流**，常见是项目 → 追问 → 基础 → 场景 / Coding，而不是异常整齐的题库分类；
- **正文以面试经历和问题为主体**，不是标准答案、高手答法或教学解析包装出来的内容。

## 3. 平台无差别原则

- 牛客上的整理帖不会因为平台是牛客就升级；
- 小红书上的候选人高质量第一人称长文可以进入；
- 知乎 / CSDN / 个人博客的真实候选人复盘也可以进入；
- 抖音 / Bilibili 只有在能够稳定核验候选人本人、真人技术面和完整具体问题时才进入；
- 任何平台只要只能看到标题、截图、二次转述或标准答案，一律排除。

**平台只影响是否容易核验，不影响质量标准。**

## 4. 默认排除

以下内容不进入正式研究，也不贡献任何面试题：

- AI 自动面试 / AI 模拟面试 / 自动化题库；
- 低信息密度复盘；
- 整理 / 合集 / 搬运；
- 标准答案、面试宝典、高频题解析、模拟题；
- SEO 博客和资源导流内容；
- 只有标题、截图、搜索摘要或评论区传言的线索；
- 无法找到候选人原帖的二次转载；
- 多家公司问题拼接、无法判断原场次的内容；
- AI 批量生成痕迹明显、没有真实经历上下文的内容；
- 付费墙只露出极少内容、无法核验来源真实性与问题上下文的页面；
- 与目标 AI Application / Agent 岗位不匹配的面经。

临时搜索线索只允许用于寻找真正的 HUMAN-A 原帖；**线索本身不贡献任何题目。**

## 5. 去重

同一候选人可能把同一场面试发布到多个平台：

- 公司、日期、岗位、问题高度一致 → 视为同一场；
- 镜像页 / 推荐页 / 搬运页 → 只保留原帖；
- 两个独立候选人遇到语义相同的问题 → 计为两个独立真人命中。

## 6. Canonical Question 的唯一来源

Canonical Question 不是知识体系本身，而是**高质量真人面经的真实问法归一化层**。

因此：

1. 每个 Canonical Question 必须有 HUMAN-A 来源；
2. 不因为低质量内容提出了“看起来很高级的问题”就增加学习任务；
3. MySQL / Redis / Vector DB / RAG / Agent Harness 等完整课程由各自知识体系保证完整性；
4. 真人面经只负责校准哪些知识被真实问到、怎么问、追到多深；
5. 没有 HUMAN-A 证据的问题不进入面经问题层。

```text
完整知识体系 = 决定应该学什么
HUMAN-A 面经 = 真实问法 + 追问深度 + 学习优先级
非一手面试材料不贡献面试样本频率
```

## 7. 搜索优先级

1. 最近 30～60 天的真人高质量第一人称技术面；
2. 目标公司 / 目标岗位的完整一面、二面、三面或 Leader 面复盘；
3. 同一场同时覆盖 Agent / RAG 与 Python / FastAPI / MySQL / Redis / Backend 的高质量样本；
4. Agent Harness / Runtime / Coding Agent 等少见深挖；
5. 任何平台都必须通过完全相同的 HUMAN-A 标准。

**平台覆盖率、Batch 数量、来源数量和题目数量都不能高于来源质量。**

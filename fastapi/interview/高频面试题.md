# FastAPI 高频面试题

> 教材是 16 个知识小板块；面试题保持更细粒度。下面优先覆盖冻结 HUMAN-A 的 4 道 FastAPI Canonical，并补完整 AI Service 工程追问。

---

## 1. FastAPI、Starlette、Uvicorn、Pydantic 分别做什么？

**答：** Uvicorn 是 ASGI Server；Starlette 提供 Request/Response/Routing/Middleware/WebSocket 等 ASGI Web 基础；FastAPI 在其上提供类型驱动 API、Dependency、OpenAPI 等；Pydantic 负责 Runtime Validation / Serialization。

## 2. ASGI 是什么？

**答：** ASGI 是 Python 异步 Server 与 Application 之间的协议边界，可用 `scope / receive / send` 理解 HTTP、WebSocket、Lifespan 事件流。

## 3. 一个请求从 Uvicorn 到 Handler 大致经历什么？【FASTAPI-001】

**答：** ASGI Server 接收网络事件 → Middleware → Router → 参数解析/Validation → Dependency Graph → Path Operation → Service → Response/Stream。

## 4. FastAPI 为什么适合 AI Service？

**答：** 类型 Contract、async I/O、Dependency/Lifecycle、Streaming/SSE/WebSocket、OpenAPI 与 Python AI 生态结合自然；但它不是 RAG/Agent Runtime 本体。

## 5. Middleware 与 Dependency 的区别？【FASTAPI-002】

**答：** Middleware 是 Application 级横切层；Dependency 是 Route-aware 的输入/资源/前置条件图。Request ID/CORS/全局 timing 更适合 Middleware；Current User/DB Session/Tenant 更适合 Dependency。

## 6. 多个 Middleware 的执行顺序？

**答：** 新添加的 Middleware 包在更外层；请求从外到内，响应从内到外。

## 7. `yield` Dependency 解决什么问题？

**答：** 把 acquire/cleanup 绑定成结构化生命周期，例如 DB Session；`yield` 前获取资源，`finally` 中释放。

## 8. `Depends(scope="function")` 和默认 request scope 的区别？

**答：** function scope 在 Path Operation 结束后、Response 发送前 cleanup；request scope 围绕整个 Request/Response 生命周期。Streaming 时要特别考虑资源是否仍被 Stream 使用。

## 9. Lifespan 和 Dependency 有什么区别？

**答：** Lifespan 管 Application startup/shutdown 级共享资源；Dependency 通常管 Request/Route 级资源和上下文。

## 10. 为什么不能每个请求创建一个新的 LLM HTTP Client？

**答：** 会失去连接复用，重复 TCP/TLS 建连，增加 socket/latency 抖动；Client/Pool 通常应在 Application Lifespan 复用。

## 11. `async def` 一定比 `def` 快吗？

**答：** 不一定。async 主要让可 await I/O 在等待时释放执行机会；CPU-heavy 或同步阻塞代码包成 async 仍会卡 Event Loop。

## 12. FastAPI 如何执行普通 `def` Endpoint？

**答：** FastAPI 会把普通 `def` Path Operation / Dependency 放入外部 Thread Pool 执行并 await 结果。

## 13. 在 `async def` Endpoint 里直接调用同步 helper 会自动进 Thread Pool 吗？

**答：** 不会。那只是普通 Python 调用，可能直接阻塞 Event Loop。

## 14. `asyncio.gather()` 会自动限流吗？

**答：** 不会。它负责并发等待/聚合，不控制并发上限；大量调用仍需 Semaphore、Pool 或更高层限流。

## 15. Request Model、ORM Model、Response Model 要不要共用？

**答：** 不应默认共用。它们服务 API Contract、Persistence 和输出安全等不同边界。

## 16. `response_model` 有什么作用？

**答：** 用于响应验证、序列化、OpenAPI，并按输出模型过滤字段，可减少内部敏感字段意外暴露。

## 17. Pydantic Validation 能替代业务校验吗？

**答：** 不能。Pydantic 验结构和字段约束；订单状态、额度、资源 ownership、权限等属于 Business/Authorization Validation。

## 18. FastAPI + SSE 怎样推 Agent 中间事件？【FASTAPI-004】

**答：** Runtime 先产生 typed event，API Adapter 映射成 SSE event，通过 `EventSourceResponse` 推给前端；还要有 stable schema、error/terminal event、心跳、disconnect/cancellation。

## 19. 当前 FastAPI SSE 只能 GET 吗？

**答：** 不能这样说。当前官方 SSE 支持可用于不同 HTTP Method，包括 POST。

## 20. Stream 已经发出 200 后失败怎么办？

**答：** 通常不能再改 Status，需要在 Stream Protocol 里发 `error` / terminal event。

## 21. SSE 和 WebSocket 怎么选？

**答：** 主要是服务端推送的 AI Chat 用 SSE 往往更简单；持续双向低延迟交互、Realtime Voice/游戏/控制更适合 WebSocket。

## 22. Client Disconnect 是否意味着后端任务停止？

**答：** 不一定。Transport 断开和 Business Cancellation 要分开；Durable Agent Run 可能继续执行。

## 23. `BackgroundTasks` 能代替 Celery/MQ 吗？

**答：** 不能。它适合当前进程里的轻量响应后任务，不提供完整持久化、跨进程调度、Worker Recovery、Lease 等语义。

## 24. `bytes` 和 `UploadFile` 怎么选？

**答：** bytes 会把整个文件读入内存，适合小文件；UploadFile 使用 spooled temporary file，更适合大文件。

## 25. 大型 RAG Ingestion API 怎么设计？

**答：** Upload/Store 后创建持久 task，返回 202 + task_id，由 Queue/Worker 处理 Parse/OCR/Chunk/Embedding/Index，再提供 Poll/SSE Progress。

## 26. FastAPI 测试怎么替换认证或 DB Dependency？

**答：** 使用 `app.dependency_overrides` 将原 Dependency 映射到测试实现，结束后清空 overrides。

## 27. 为什么 P99 高不能只看 Handler 耗时？

**答：** 还可能在 Thread Pool、DB/HTTP Pool acquire、LLM/Vector 下游、Queueing、Serialization、Proxy 或 Stream First Byte。

## 28. 多 Worker 为什么不能共享全局 dict？

**答：** Worker 是独立进程，各自有独立内存；共享 Session/Run State 应外置或有明确路由。

## 29. 只会 GET/POST 为什么不足以构建 Agent Service？【FASTAPI-005】

**答：** 还必须处理 typed contract、Auth/Dependency、Resource Lifecycle、async/blocking、Streaming/Event、Cancellation、Long-running Task、Session/Run、Observability、Deployment，并和 Agent Runtime 正确分层。

## 30. FastAPI 与 Agent Harness 的边界？

**答：** FastAPI 管 HTTP/SSE/WebSocket、API Contract 和 Request Lifecycle；Agent Harness 管 Loop、Tool、Context、Memory、State、Checkpoint、Permission 等执行语义。

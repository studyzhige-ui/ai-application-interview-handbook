## 与 Curriculum、Products、Market 的边界

```text
References → Technical Evidence：事实、版本、规范与源码依据
Curriculum → Knowledge Model：可迁移的通用机制与知识依赖
Products   → System Understanding：成熟系统怎样组合这些机制
Market     → Hiring Signal：岗位需求、真实问法与追问深度
```

同一份成熟源码可以同时被 References 与 Products 使用，但职责不同：References 负责证明“这个版本确实这样实现”，Products 负责把实现组织成可阅读的完整系统学习路径。

官方资料和源码不能证明“面试出现频率有多高”，也不能增加 HUMAN-A Source Count。

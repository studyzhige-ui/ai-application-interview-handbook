## 与 Market 的边界

```text
References → Technical Truth
Market     → Hiring Signal
```

官方资料和源码可以证明“机制是什么、工程上怎样实现”，但不能证明“面试出现频率有多高”，也不能增加 HUMAN-A Source Count。

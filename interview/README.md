## 两种“面试资料”不要混淆

`interview/canonical/`：

- 由 HUMAN-A 市场证据归一化；
- 管理 QID、Ownership、Source Count、Depth；
- 服务跨模块统计与课程校准。

`curriculum/<module>/interview/`：

- 面向学习者直接复习；
- 高频面试题、易错点、面试前速查；
- 是教材的使用层，不是市场统计数据库。

因此中央 Canonical 与模块 Interview 是 **Evidence Model → Learning Material** 的关系，而不是重复文件。

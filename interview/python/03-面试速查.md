## 30秒口述卡

完整回答与样本范围见[第2题](01-高频面试题.md#2-gil意味着python线程完全不能并行吗)、[第3题](01-高频面试题.md#3-async函数调用后会立即执行吗await做了什么)、[第7题](01-高频面试题.md#7-装饰器是什么闭包又是什么)、[第10题](01-高频面试题.md#10-list与tuple有何区别dict如何组织数据)。

| 题目 | 核心回答 | 不能漏的限制 |
|---|---|---|
| GIL | 常见CPython构建限制同一时刻执行Python字节码的线程 | I/O、释放GIL的扩展、可选自由线程构建不同；业务仍需同步 |
| 协程 | 在可挂起点协作推进等待任务 | async声明不把同步阻塞或CPU计算搬走 |
| gather/任务组 | 先讲结果组织与失败/取消语义 | 并发组合不自动限流，部分成功策略由业务决定 |
| 可变默认参数 | 定义时创建的对象被后续调用复用 | 用哨兵表达缺省，别误改调用者传入的空容器语义 |
| 浅拷贝 | 新外壳，内部引用仍可能共享 | 深拷贝也不适用于所有资源对象 |
| 装饰器 | 接收对象并替换原绑定 | 包装器要透传参数、保留元信息、区分同步异步 |
| 上下文管理器 | 进入/退出管理资源 | 是否抑制异常要明确；不能提供断电保证 |
| 生成器 | 延迟产生值并保留执行状态 | 一次性消费、延迟异常、资源关闭 |
| dict/set | 依赖哈希与相等语义组织键 | 平均性能不是最坏情况保证；键的契约须稳定 |
| 内存排查 | 找存活引用、分配热点和资源生命周期 | 对象释放不保证RSS立刻下降 |

## 场景：并发抓取1000个页面

完整回答与样本范围见[第1题](01-高频面试题.md#1-线程进程协程分别解决什么问题)、[第4题](01-高频面试题.md#4-gatheras_completed和taskgroup怎样选)、[第17题](01-高频面试题.md#17-lockrlock和semaphore怎样选)。

先限制同时在途的请求；复用有上限的客户端池；为连接、读取和整体任务设预算；对可恢复错误有限重试；取消时回收任务与资源；结果按成功/失败明确记录。若解析页面成为CPU瓶颈，再独立测量并调整执行方式。不要直接生成1000个无预算线程或任务。

## 场景：缓存字典出现偶发错误

完整回答与样本范围见[第6题](01-高频面试题.md#6-赋值浅拷贝与深拷贝有什么区别)、[第10题](01-高频面试题.md#10-list与tuple有何区别dict如何组织数据)、[第11题](01-高频面试题.md#11-python怎样管理内存内存一直涨应如何排查)。

先检查缓存是否跨请求/线程共享；更新是否由多个步骤组成；value是否含嵌套可变对象；失效和读取是否存在竞态；容量是否无限增长。再决定锁、不可变快照、请求隔离或外部缓存，不先归咎于GC。

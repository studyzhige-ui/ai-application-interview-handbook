# RAG｜面试速查

[本域入口](README.md) · [课程](../../curriculum/08-rag/README.md)

## 用一条问题唤起全链路

```text
权威来源、适用时间与权限
→ 按格式解析，保留结构、条件与位置
→ 合适粒度的块及可回取关系
→ 在授权范围内保留原问题并检索
→ 多路融合，按预算重排
→ 去重、补全、再次授权与上下文装包
→ 生成，核对引用、条件与支持关系
```

A 给出一般期限，B 给出资源例外，是已知材料的教学标注。线上从用户问题提取产品、时间和资源状态，再检查各项是否得到支持；不知道 B 的存在，也能发现一般期限没有解释资源状态。答出人工复核不等于已经执行退款。

## 容易混在一起的对象

| 两个概念 | 核心区别 |
|---|---|
| 文档身份与文档版本 | 同一逻辑对象，与它某次具体内容不同。 |
| 当前内容与当前授权 | 内容可以有受控回滚，撤权和删除不随它恢复。 |
| 检索块与上下文块 | 定位粒度可小，解释粒度按关系补全。 |
| 相关性与充分性 | 片段相关，不证明已知条件都受支持，更不证明没有未知例外。 |
| 离线标签与线上判断 | 人工标签用于验收；线上依据问题、材料与检查策略发现缺口。 |
| 改写与分解 | 重述同一需求，与拆开不同信息需求不同。 |
| 融合与重排 | 合并路线索，与重新联合评分不同。 |
| 忠实与正确 | 忠于给定材料，不保证材料适用或事实正确。 |
| 无命中与执行失败 | 检索完成后的结果，与查询未完成不同。 |

## 公式要连同口径一起说

BM25：词的稀有性、词频饱和与长度归一化共同决定贡献。固定 IDF=1、k1=1.2、长度等于平均长度，本文公式为 `2.2×tf/(tf+1.2)`；tf 从 1 到 2，贡献从 1 到 1.375，不是翻倍。

RRF：累加各路 `1/(c+rank)`，名次从 1 开始，未命中贡献 0。常数、每路窗口和最终 K 是三个决定；同一片段合并，但不能按整份文档去重。

固定窗口：步长 `S−O`，要求 `0≤O<S`；非空长度 N≤S 时一块，否则 `1+ceil((N−S)/(S−O))` 块。位置覆盖不保证语义完整。

Recall@K：前 K 中相关数 / 全部已知相关数。Precision@K：本实验用前 K 中相关数 / K，短结果也用 K。空相关集合不算 Recall，转为有独立标签的不可回答评测。

RR@K 只看首个相关结果的位置，MRR 是多个适用问题的均值。NDCG 用分级增益与位置折扣，再除以全部已知标签形成的理想值。Hit、RR 不能代替全部必要事实覆盖。

## 支持关系与引用

```text
问题条件 → 当前材料支持到哪里 → 未支持项驱动补查
→ 有限结论 / 澄清 / 说明冲突或失败
```

引用分三层：ID 在本次包中、来源适用且可读、原文支持具体结论。政策支持规则，不自动核实用户订单事实；模型自报“完整”也不是独立证据。

## 更新、回滚与缓存

事件通知及时发现变化，定时核对补漏，二者进入同一版本处理路径。正文先构建验证，再切有效版本；幂等处理重复，修订条件检查处理旧任务晚到。

```text
g1 = e1 + v1 + s1 + c1
g2 = e2 + v2 + s2 + c2

快照100 → g2连续补到103 → 原子提交发布控制记录
→ 后续104发往g2；已绑定g1的请求仍用c1
```

原子更新的是控制记录，资源提前准备；绑定代际不等于内容快照。看到103不代表101、102都完成。发布前后失败分别读取真实已提交状态决定恢复，不能凭内存猜测。

撤权与删除独立约束所有内容和缓存。回滚旧代际前，还要检查它是否漏掉切换后的内容变化；保留旧索引不等于具备安全回滚条件。

## 错误定位顺序

适用原文有答案吗？解析切分保住了吗？进入合法候选了吗？在哪一步被重排、去重或预算删除？模型是否正确解释与引用？找到第一处缺口后，用受控完整证据检查后续阶段，不假定只有一个故障。

对照固定来源、问题、权限、模型及其余参数，报告分母、百分点、退化类别、尾延迟和每成功回答成本。确定性模拟不能代替真实服务验证。

## 复杂方案的选择

局部实体问题可用 Local Search 组合图关系与原文；跨主题问题可用 Global Search 分批从社区报告提取要点再汇总。报告数不等于独立事故数。

后续查询依赖中间证据时，评估受控 Agentic RAG；记录目标、未支持条件、已试查询、权限和预算。步骤用完只意味着停止，未完成部分仍要说明。
